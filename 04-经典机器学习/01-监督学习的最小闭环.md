## 本篇要回答的问题

1. 一次监督学习由哪五个对象组成？
2. 经验风险和「真实分布上的风险」差在用哪一批样本？
3. 二元逻辑回归为什么对 logit 的梯度是 `p - y`？
4. 准确率在什么数据分布上会把一个无用模型评得很高？
5. 用全量数据计算标准化的均值，泄漏进了哪一个估计？

## 五个对象

对一个要预测的问题，先把这五个写出来。

| 对象 | 在二元分类里的例子 |
| --- | --- |
| 数据 | 特征向量 `x`，标签 `y ∈ {0, 1}` |
| 假设 | `p = σ(w · x + b)`，`σ` 是 sigmoid |
| 损失 | 一条样本的负对数似然 |
| 更新 | 沿损失对参数的梯度走一步 |
| 评估 | 在没有参与更新的数据上计算的指标，加上决策阈值 |

五个里缺一个，后面的数字就没法解释。只看训练损失下降，缺少的是评估。只看准确率，缺少的是概率损失和阈值。

## 风险与经验风险

设样本从某个分布中独立抽出。风险是损失在这个分布上的期望。训练时分布未知，用训练集上的平均损失代替它，这就是经验风险。

最小化经验风险，是在已经看到的样本上把平均损失做小。它和真实风险之间的差距，来自样本有限、假设类选得不合适，以及数据划分被污染。偏差和方差那一篇会把「假设类太小 / 太灵活」分开写。本篇只要求能指出：训练损失是经验风险的一个估计，报告模型时要另给没参与更新的数据。

划分：

- 训练集更新参数。
- 验证集选择学习率、正则系数和是否早停。
- 测试集只在最后报告。

调参时反复查看的集合是验证集。把它叫测试集，报告就会把选择模型用过的信息说成一次独立考试。

## 逻辑回归

给定 `x`，令 logit `z = w · x + b`，预测正类概率

```text
p = σ(z) = 1 / (1 + exp(-z))
```

`σ` 把任意实数映到 `(0, 1)`。`z = 0` 时 `p = 1/2`。`z` 增大，`p` 增大。

一条样本的损失取负对数似然。`y` 为 1 时损失是 `-ln p`，`y` 为 0 时损失是 `-ln(1 - p)`，合成

```text
L = - y ln p - (1 - y) ln(1 - p)
```

分类错误个数也可以当评价，但它对参数几乎处处梯度为 0 或没有定义，不能用来做这一步的更新。训练损失用的是概率的对数。

推导 `dL/dz`。已知 `dp/dz = p (1 - p)`，并且

```text
dL/dp = -y / p + (1 - y) / (1 - p)
```

链式法则：

```text
dL/dz = dL/dp · dp/dz
      = [-y / p + (1 - y) / (1 - p)] · p (1 - p)
      = -y (1 - p) + (1 - y) p
      = p - y
```

梯度是预测概率减去标签。`p > y` 时 logit 应当减小，`p < y` 时 logit 应当增大。对参数：

```text
dL/dw = (p - y) x
dL/db = p - y
```

一步梯度下降是 `w ← w - η dL/dw`，`b` 同样。`η` 是学习率。

## 一步更新的数字

取 `x = (1, 0)`，`y = 1`，`w = (0, 0)`，`b = 0`，`η = 0.1`。

```text
z = 0
p = 1/2
dL/dz = 1/2 - 1 = -1/2
dL/dw = (-1/2) · (1, 0) = (-1/2, 0)
dL/db = -1/2
```

更新：

```text
w = (0, 0) - 0.1 · (-1/2, 0) = (0.05, 0)
b = 0 - 0.1 · (-1/2) = 0.05
z' = 0.05 · 1 + 0.05 = 0.10
p' = σ(0.10) ≈ 0.5250
```

标签是正类，更新之后概率从 0.5 升到大约 0.525。`x` 的第二维是 0，所以 `w₂` 这一步没有信息，保持 0。

`y = 1` 且 `z = 0` 时，损失对 `z` 的有限差分也约为 `-0.5`。脚本 `check_logistic` 同时检查这个解析梯度和更新后的概率。

## 从概率到一次决策

上线时若必须输出类别，取 `p ≥ τ` 为正类。`τ` 由两类错误的代价决定。准确率这个指标把 `τ` 固定在 0.5，并且把两类错误看成同样贵。

先看一个没有倾斜的计数。100 条样本里，真正例 40，假正例 10，假负例 20，真负例 30。

```text
精确率 = 40 / (40 + 10) = 4/5
召回率 = 40 / (40 + 20) = 2/3
准确率 = (40 + 30) / 100 = 7/10
```

精确率看的是「预测为正的里面有多少真为正」。召回率看的是「真的正类里有多少被找回来」。

再看倾斜：100 条里 99 条是负类。模型永远预测负类。准确率是 0.99，正类召回率是 0。准确率单独作为结论，会把这个模型说成几乎完美。报告里至少同时给正类的精确率和召回率，或者给一个写明了代价的阈值。

概率本身是否好用，是另一件事。若模型给出 0.8，含义应是：在它给出 0.8 的那些样本里，大约八成确实是正类。这叫校准。逻辑回归优化的是似然，评估时除了分类对错，还要看概率能不能这样解释。校准图留到后面的笔记，不在本篇把一种模型说成自动校准。

## 泄漏

泄漏是：训练时用到了在真正预测时不存在的信息，或用到了评价集合的信息。

例 1。预测「用户会不会购买」，特征里放了「本次订单金额」。订单金额在购买发生之后才有。模型学到的是结果伴随的字段，不是购买前能拿到的特征。把特征列表限制到决策时刻已经存在的字段。

例 2。先把所有样本的每个特征减均值、除标准差，再划分训练集和测试集。均值和标准差用到了测试集。测试集的位置信息进了训练用的变换。正确的顺序是：划分之后，只用训练折估计均值和标准差，再把这组数用到验证和测试。交叉验证时，每一折各自重新估计。

例 1 是特征穿越了时间。例 2 是预处理统计量看见了评价数据。检查管道时把这两类分开问。

## 容易算错的地方

- `dL/dz = p - y` 依赖的是上面的负对数似然，以及 `p = σ(z)`。换成别的损失，这一行要重推。
- 更新是减去学习率乘梯度。`p - y` 已经带了符号，再手写一个负号就会往错误方向走。本篇的数字里 `y = 1`、`p = 1/2`，梯度为负，减去负数才使 `z` 变大。
- 准确率 0.99 要和类别比例一起看。正类很少时，把召回率写进同一张表。
- 验证集参加了模型选择之后，它的分数是选择后的分数。最终一次报告用没参与选择的测试集。

## 练习

### 练习 1：重推 `p - y`

- 目标：不看正文完成从 `dL/dp` 到 `dL/dz` 的代数。
- 限制：纸笔。
- 题面：写出 `L`、`dp/dz`，化简 `dL/dz`。
- 完成标准：化简结果是 `p - y`，并且你能指出哪一步用了 `p(1-p)` 与分母相消。

<details>
<summary>参考解答</summary>

`dL/dz = [-y/p + (1-y)/(1-p)] p (1-p) = -y(1-p) + (1-y)p = -y + yp + p - yp = p - y`。相消用的是 `dp/dz = p(1-p)`。

</details>

### 练习 2：再走一步更新

- 目标：梯度符号和参数更新一致。
- 限制：纸笔。概率可以用计算器核对 `σ(0.10)`。
- 题面：用正文的初始条件，计算更新后的 `w`、`b` 和 `z`。说明 `w₂` 为什么不变。
- 完成标准：`w = (0.05, 0)`，`b = 0.05`，`z = 0.10`，`p ≈ 0.5250`。

<details>
<summary>参考解答</summary>

见正文「一步更新的数字」。`x₂ = 0`，所以 `dL/dw₂ = (p - y) x₂ = 0`。脚本 `check_logistic` 复核 `σ(0.10)` 四舍五入到四位小数是 0.5250。

</details>

### 练习 3：换一条标签

- 目标：看出梯度方向跟着 `y` 走。
- 限制：纸笔，只做梯度，不必算新的 sigmoid。
- 题面：其他初始值不变，把 `y` 改成 0。`dL/dz` 是多少？`b` 的更新是变大还是变小？
- 完成标准：给出 `dL/dz = 1/2`，并说明 `b` 减小，因为当前概率 0.5 高于标签 0。

<details>
<summary>参考解答</summary>

`p - y = 0.5 - 0 = 0.5`。`b ← 0 - 0.1 * 0.5 = -0.05`。logit 下降，概率会低于 1/2，与标签 0 一致。

</details>

### 练习 4：读一张计数表

- 目标：三个指标都从定义算出来。
- 限制：纸笔。
- 题面：真正例 40，假正例 10，假负例 20，真负例 30。计算精确率、召回率、准确率。
- 完成标准：结果是 `4/5`、`2/3`、`7/10`。

<details>
<summary>参考解答</summary>

精确率 `40/50 = 4/5`，召回率 `40/60 = 2/3`，准确率 `70/100 = 7/10`。脚本 `check_classification_counts` 用分数复核。

</details>

### 练习 5：写出一个准确率失效的模型

- 目标：给一个具体的预测规则和类别比例。
- 限制：不需要真实数据。
- 题面：100 条样本、99 条负类。构造一个准确率为 0.99 且正类召回率为 0 的预测规则。
- 完成标准：规则具体到「每条都预测什么」。

<details>
<summary>参考解答</summary>

每条都预测负类。99 条负类全部正确，1 条正类被算成假负例。准确率 0.99，正类召回率 0。

</details>

### 练习 6：指出泄漏并改顺序

- 目标：把统计量的估计限制在训练折。
- 限制：文字。
- 题面：某人先在全部数据上计算每个特征的均值和标准差，做完标准化再随机划分训练、验证、测试。写出问题，并写出应有的顺序。
- 完成标准：提到验证折和测试折的数值进了均值。

<details>
<summary>参考解答</summary>

均值和标准差看见了验证集和测试集，标准化之后的训练集含有评价数据的位置信息。应先划分，只用训练集计算均值和标准差，再变换验证集和测试集。交叉验证的每一折单独计算。

</details>

### 练习 7：订单金额

- 目标：用「决策时刻是否已经存在」检查特征。
- 限制：文字。
- 题面：预测用户是否会下单，特征包含本次订单金额。这个特征错在时间的哪一侧？什么样的金额字段可以留在决策之前？
- 完成标准：区分「这一次的订单金额」和「历史订单的统计」。

<details>
<summary>参考解答</summary>

本次订单金额在下单之后才出现，不能用来预测这次会不会下单。该用户过去已经完成的订单金额、过去的客单价，在这次决策前存在，可以作为特征。前提是这些历史统计的截止时间早于这次决策。

</details>

## 本篇之外

线性回归会把数学开篇的最小二乘和这篇的梯度下降放在同一个模型里。L2 正则、树、校准和 PCA 都还没有笔记。本篇不把某种模型说成在所有分布上都已校准。
