## 一棵树在划分什么

回归树把输入空间切成若干片。每一片是一个叶子，叶子里的预测是落在这片里的训练标签的平均。分类树的叶子则记下各类的个数：输出类别时取多数，输出概率时取叶内频率。

不变量：划分一旦定下来，叶子内部不再使用 `x`。这片里的每个点共用同一个数。树能拟合的形状，是这些常数拼起来的阶梯。

下面的回归例子都是一维的，样本已经按 `x` 升序排好。候选划分是「前 `k` 个点进左叶子，其余进右叶子」，`k` 从 1 取到 `n - 1`。左右平方和相同时，取最小的 `k`。新点用阈值 `(x_k + x_{k+1}) / 2`：小于等于阈值进左，大于阈值进右。训练点自己不会落在阈值上，因为阈值严格夹在两个训练 `x` 之间。

```python
def leaf_sse(values: list[float]) -> float:
    mean = sum(values) / len(values)
    return sum((value - mean) ** 2 for value in values)


def best_stump(y: list[float]) -> int:
    """y 已按 x 升序。返回左右 SSE 之和最小的 k；平局取最小的 k。"""
    best_k = 1
    best: float | None = None
    for k in range(1, len(y)):
        score = leaf_sse(y[:k]) + leaf_sse(y[k:])
        if best is None or score < best:
            best = score
            best_k = k
    return best_k
```

平方和写 SSE，先不除以 `n`。除以 `n` 之后才是上一篇里的平均损失。

## 回归树桩

四个点：

| 下标 | `x` | `y` |
| --- | --- | --- |
| 0 | 1 | 1 |
| 1 | 2 | 2 |
| 2 | 3 | 6 |
| 3 | 4 | 7 |

全体平均是 4。根节点的 SSE 是 `(1-4)² + (2-4)² + (6-4)² + (7-4)² = 26`。平均损失是 `26/4 = 13/2`。

三个候选：

| `k` | 左平均 | 右平均 | 左右 SSE |
| --- | --- | --- | --- |
| 1 | 1 | 5 | 14 |
| 2 | `3/2` | `13/2` | 1 |
| 3 | 3 | 7 | 14 |

`k = 2` 最小。阈值是 `(2 + 3) / 2 = 5/2`。`x ≤ 5/2` 预测 `3/2`，`x > 5/2` 预测 `13/2`。四个训练点的预测是 `3/2, 3/2, 13/2, 13/2`，SSE 是 1，平均损失是 `1/4`。

`k = 1` 的右叶子是 2、6、7，平均 5，平方和 `(2-5)² + (6-5)² + (7-5)² = 14`。`k = 3` 与它对称。树桩只比较这三行，不比较「感觉上 2 和 6 之间该有一刀」。

## 分到每个点自己的叶子

同一批点继续切，直到每个叶子只有一个训练点。根仍然取 `k = 2`，阈值 `5/2`。左边两个点只有一刀，阈值 `(1+2)/2 = 3/2`，叶子分别预测 1 和 2。右边阈值 `(3+4)/2 = 7/2`，叶子分别预测 6 和 7。

训练预测等于 `y`，SSE 是 0。

新点 `x = 1.6`，`y = 6/5`。深树先看 `5/2`：`1.6 ≤ 5/2`，进入左边；再看 `3/2`：`1.6 > 3/2`，进入 `x = 2` 那个叶子，预测 2。平方误差是 `(2 - 6/5)² = 16/25`。

树桩的阈值只有 `5/2`，`1.6` 进左边，预测 `3/2`。平方误差是 `(3/2 - 6/5)² = 9/100`。

| 模型 | 训练 SSE | 在 `(1.6, 6/5)` 上的预测 | 平方误差 |
| --- | --- | --- | --- |
| 树桩，`k = 2` | 1 | `3/2` | `9/100` |
| 每个点一个叶子 | 0 | 2 | `16/25` |

`16/25 = 0.64`，`9/100 = 0.09`。训练 SSE 更小的那棵树，在这个新点上更大。上一篇的分解在这里只取一个方向：把每个训练点孤立起来，预测会跟着这一份 `y` 走；树桩在一片里只能给出平均数，跟不了 1 和 2 的差别。一份新点不是偏差和方差本身，它只说明训练 SSE 的排序可以和这个点上的平方误差相反。

## 分类：Gini 和误分类率

十个点，一个二元特征 `a`。`a = 0` 的五个标签是四个正类、一个负类。`a = 1` 的五个标签是三个正类、两个负类。正类一共 7 个，负类一共 3 个。

二元 Gini 写成 `2p(1-p)`，其中 `p` 是叶内正类比例。它等于 `1 - p² - (1-p)²`。误分类率是：叶子按多数类预测时，分错的比例，也就是 `min(正类个数, 负类个数) / 叶子大小`。

```python
def gini_binary(n_pos: int, n_neg: int) -> float:
    total = n_pos + n_neg
    p = n_pos / total
    return 2 * p * (1 - p)
```

| 节点 | 正类 | 负类 | 误分类率 | Gini | 熵 |
| --- | --- | --- | --- | --- | --- |
| 父节点 | 7 | 3 | `3/10` | `21/50` | 0.6109 |
| `a = 0` | 4 | 1 | `1/5` | `8/25` | 0.5004 |
| `a = 1` | 3 | 2 | `2/5` | `12/25` | 0.6730 |

父节点 Gini：`2 · (7/10) · (3/10) = 21/50`。两个叶子各有一半的点，加权 Gini 是 `(1/2) · (8/25 + 12/25) = 2/5`。收益是 `21/50 - 2/5 = 1/50`。

误分类率：父节点 `3/10`。加权子节点 `(1/2)·(1/5) + (1/2)·(2/5) = 3/10`。收益是 0。两个叶子的多数类都仍是正类，按多数类数错的个数还是 3 个。

熵是 `-p ln p - (1-p) ln(1-p)`。父节点 0.6109，加权子节点 0.5867，收益 0.0242。这四位小数是 ln 的值再四舍五入。Gini 和熵都认为这一刀降低了不纯度，误分类率认为错误率没有变。

划分用 Gini 或熵。误分类率用来报告「已经按多数类决策之后错了多少」，不用来挑选这一刀：收益为 0 的划分会被它整刀丢掉，尽管两个叶子的纯度已经不同。

`a = 0` 的叶子若输出概率，正类频率是 `4/5`。这是这五个训练标签的比例。新点落进这片时，正类是否约占 `4/5`，是校准，留在后面的笔记。

## 袋外样本

有放回地抽 `n` 次，抽中的是下标。某个下标一次都没出现的概率是 `(1 - 1/n)^n`。`n = 4` 时是 `(3/4)^4 = 81/256`，约 0.3164。`n` 变大时这个概率靠近 `1/e`，约 0.3679。一次抽样里袋外下标个数的期望是 `n · (1 - 1/n)^n = 81/64`。

袋外指的是次数为 0。抽到两次的下标仍在袋内。

仍用上面四个 `y`：`1, 2, 6, 7`。两次抽样：

| 抽样 | 抽到的下标 | 袋外 | 深度 0 的预测 |
| --- | --- | --- | --- |
| A | `(0, 0, 2, 3)` | `{1}` | `15/4` |
| B | `(1, 1, 2, 2)` | `{0, 3}` | 4 |

深度为 0 的树不划分，预测是抽到的 `y` 的平均，重复的下标按次数计入。A 的平均是 `(1+1+6+7)/4 = 15/4`。B 的平均是 `(2+2+6+6)/4 = 4`。谁在袋外只取决于抽样；换成会划分的树，集合还是这两行，变的是预测值。

| 点 | 袋外预测来自 | 预测 | 平方误差 |
| --- | --- | --- | --- |
| 0 | B | 4 | 9 |
| 1 | A | `15/4` | `49/16` |
| 2 | 没有 | | |
| 3 | B | 4 | 9 |

点 0 的 `y` 是 1，`(1-4)² = 9`。点 1 的 `y` 是 2，`(2 - 15/4)² = 49/16`。点 3 的 `y` 是 7，`(7-4)² = 9`。点 2 两次都在袋内，没有袋外预测。

只对有袋外预测的点取平均：`(9 + 49/16 + 9) / 3 = 337/48`。

先在每棵树内部平均，再对树平均：树 A 只有点 1，误差 `49/16`；树 B 是 `(9+9)/2 = 9`。两棵树再平均是 `(49/16 + 9) / 2 = 193/32`。

`337/48` 和 `193/32` 不相等。袋外误差要写明平均的是点还是树。把点 2 的空位当成 0 再对四个点平均，得到 `(9 + 49/16 + 0 + 9) / 4 = 337/64`，那是第三个数。

## 平均之后方差停在哪里

固定一个 `x`。`B` 棵树的预测记为 `T_1, …, T_B`，每棵的方差都是 `σ²`，任意两棵的相关系数都是 `ρ`。这里的 `σ²` 和 `ρ` 是假设，不是从上面四个点估计出来的。

平均 `T̄ = (T_1 + … + T_B) / B`。方差展开成对角上的 `B` 个 `σ²`，以及非对角上的 `B(B-1)` 个协方差 `ρσ²`：

```text
Var(T̄) = (1/B²) [ B σ² + B(B-1) ρ σ² ]
        = ρ σ² + (1 - ρ) σ² / B
```

`ρ = 0` 时，方差是 `σ² / B`，树越多越小。`ρ = 1` 时，方差保持 `σ²`，平均没有把重复的同一棵树变得更稳。`ρ` 停在中间时，`B → ∞` 剩下 `ρσ²`。

取 `σ² = 4`，`ρ = 1/2`：

| `B` | 方差 |
| --- | --- |
| 1 | 4 |
| 100 | `101/50` |
| 趋于无穷 | 2 |

`B = 100` 时，`2 + (1/2) · 4 / 100 = 2 + 1/50 = 101/50`。再把 100 换成更大的数，第二项还能变小，第一项 2 还在。随机森林在每个划分上只查看一部分特征，是为了让树不总是先用同一个强特征，从而把 `ρ` 压低。`ρ` 本身仍要由数据和 `m` 决定，公式只说明地板在乘积 `ρσ²`。

## 每次只看一个特征

四个点，`y = x₁ + x₂`：

| 点 | `x₁` | `x₂` | `y` | 只用 `x₁` | 只用 `x₂` | 两棵树的平均 |
| --- | --- | --- | --- | --- | --- | --- |
| A | 0 | 0 | 0 | `1/2` | `1/2` | `1/2` |
| B | 0 | 1 | 1 | `1/2` | `3/2` | 1 |
| C | 1 | 0 | 1 | `3/2` | `1/2` | 1 |
| D | 1 | 1 | 2 | `3/2` | `3/2` | `3/2` |

只用 `x₁`：左边 `x₁ = 0` 的标签是 0 和 1，平均 `1/2`，SSE 是 `1/2`；右边同样 `1/2`。合计 SSE 是 1。只用 `x₂` 对称，SSE 也是 1。全体平均是 1，根 SSE 是 `(0-1)² + (2-1)² = 2`。

两棵树的平均与 `y` 的差是 `1/2, 0, 0, -1/2`，SSE 是 `1/2`。平均之后的训练 SSE 低于每一棵单独的树。

若一棵树可以先按 `x₁` 分，再在每一边按 `x₂` 分，四个叶子各剩一个点，预测等于 `y`，训练 SSE 是 0。允许看两个特征的深树，在这四个训练点上比两棵受限树的平均更贴。平均改善的是「每棵树只能看见一个特征」这一组预测，不代替一次能使用两个特征的划分。

两棵树的训练 SSE 相同，是因为在这四行里 `x₁` 和 `x₂` 的角色对称。这个相等不表示其中某一个特征导致了 `y`。

## 梯度提升：拟合残差

平方损失下，当前预测是 `F`，残差是 `y - F`。下一步的树拟合残差，再把树的输出乘 `ν` 加回 `F`。叶子里的值取这片残差的平均：在平方损失下，一个常数最贴合一串数的方式就是取平均。

```python
def apply_stump(y: list[float], k: int, nu: float, current: list[float]) -> list[float]:
    """当前预测加上 ν 乘「在残差上、按这个 k 取出的叶子平均」。"""
    residual = [y[i] - current[i] for i in range(len(y))]
    left = sum(residual[:k]) / k
    right = sum(residual[k:]) / (len(y) - k)
    step = [left] * k + [right] * (len(y) - k)
    return [current[i] + nu * step[i] for i in range(len(y))]
```

仍用 `y = [1, 2, 6, 7]`。初始 `F` 是全体平均 4，残差是 `[-3, -2, 2, 3]`。减去常数不改变每个叶子内部的 SSE，所以第一刀的三行仍是 14、1、14，选择 `k = 2`。左残差平均 `-5/2`，右残差平均 `5/2`。

`ν = 1` 时，更新之后就是树桩本身：`3/2, 3/2, 13/2, 13/2`，SSE 是 1。`ν = 1/2` 时每步只走一半。

| 步 | `k` | 左叶子的 `h` | 右叶子的 `h` | 更新后的左 | 更新后的右 | 训练 SSE |
| --- | --- | --- | --- | --- | --- | --- |
| 初始 | | | | 4 | 4 | 26 |
| 1 | 2 | `-5/2` | `5/2` | `11/4` | `21/4` | `29/4` |
| 2 | 2 | `-5/4` | `5/4` | `17/8` | `47/8` | `41/16` |

`11/4 = 4 + (1/2)·(-5/2)`。第二步的残差是 `[-7/4, -3/4, 3/4, 7/4]`，SSE 是 `29/4`。这一步的三个候选里，`k = 2` 的 SSE 是 1，`k = 1` 和 `k = 3` 都是 `19/6`。`1 < 19/6`，所以第二刀仍是 `k = 2`。两步之后训练 SSE 是 `41/16`，仍大于 `ν = 1` 一步到达的 1。步长把同一方向拆开了，还没有走到树桩。

`ν = 1` 走完第一刀之后，残差是 `[-1/2, 1/2, -1/2, 1/2]`，SSE 是 1。再划一刀：

| `k` | 左平均 | 右平均 | SSE |
| --- | --- | --- | --- |
| 1 | `-1/2` | `1/6` | `2/3` |
| 2 | 0 | 0 | 1 |
| 3 | `-1/6` | `1/2` | `2/3` |

`k = 2` 的两个叶子平均都是 0：这一刀上的残差已经被上一棵树收完了。`k = 1` 和 `k = 3` 的 SSE 都是 `2/3`，平局取最小的 `k`，于是选择 `k = 1`。更新后的训练预测是 `1, 5/3, 20/3, 20/3`。和 `y` 的差是 `0, 1/3, -2/3, 1/3`，SSE 是 `2/3`。

阈值按训练 `x` 计算。`k = 1` 的阈值是 `(1+2)/2 = 3/2`。新点 `x = 1.6` 在第一棵树上的预测仍是 `3/2`，第二棵树因为 `1.6 > 3/2` 加上右叶子 `1/6`，得到 `5/3`。对 `y = 6/5` 的平方误差是 `(5/3 - 6/5)² = 49/225`。

平局的另一刀 `k = 3`，阈值是 `(3+4)/2 = 7/2`。`1.6 ≤ 7/2`，加上左平均 `-1/6`，预测 `3/2 - 1/6 = 4/3`，平方误差是 `(4/3 - 6/5)² = 4/225`。

| 模型 | 训练 SSE | `(1.6, 6/5)` 的平方误差 |
| --- | --- | --- |
| `ν = 1` 的第一棵树 | 1 | `9/100` |
| 再加 `k = 1` | `2/3` | `49/225` |
| 改加 `k = 3` | `2/3` | `4/225` |

两刀都把训练 SSE 从 1 降到 `2/3`。在这个新点上，`49/225` 大于 `9/100`，`4/225` 小于 `9/100`。训练 SSE 的平局分不出这两刀。停在哪一轮、平局留给哪一刀，用没参与这几步拟合的点来看，和上一篇用验证集选择 `λ` 是同一件事。

## 对数损失上的一步

分类的提升改的是 logit `F`，概率是 `p = σ(F)`。开篇已经算出这条样本对 logit 的导数是 `p - y`。损失下降的方向是 `y - p`。平方损失里树去拟合 `y - F`；对数损失里树去拟合 `y - p`。

四个点的 `x` 仍是 1、2、3、4，标签改成 `0, 0, 1, 1`。两类各有两个点，常数概率的最优是 `1/2`，对应的 logit 是 0。初始 `F = 0`，于是 `p = 1/2`，伪残差 `y - p` 是 `-1/2, -1/2, 1/2, 1/2`。`k = 2` 把左右都分成常数，叶子值就是 `-1/2` 和 `1/2`，残差 SSE 变成 0。`ν = 1` 时更新后的 logit 是 `-1/2, -1/2, 1/2, 1/2`。

`σ(1/2) ≈ 0.6225`，`σ(-1/2) ≈ 0.3775`。四个点的平均负对数似然从 `ln 2 ≈ 0.6931` 降到约 0.4741。左右对称，每个点的损失都是 `-ln σ(1/2)`。

牛顿步还要除以二阶导。对数损失对 logit 的二阶导是 `p(1-p)`。`p = 1/2` 时，每个点的二阶导是 `1/4`。一个叶子上的牛顿权重是 `- (叶子内梯度和) / (叶子内二阶导和)`。梯度取 `p - y`，所以分子里的负号把方向改回 `y - p`。

左叶子两个点的梯度都是 `1/2`，和是 1，二阶导和是 `1/2`，权重是 `-1 / (1/2) = -2`。右叶子权重是 2。平方损失里，梯度和二阶导的常数约掉之后，牛顿权重等于残差平均，所以上一节直接取平均。这里二阶导是 `1/4`，同一片上的残差平均是 `±1/2`，除以 `1/4` 得到 `±2`。

`ν = 1` 时 logit 变成 `-2, -2, 2, 2`。`σ(2) ≈ 0.8808`，`σ(-2) ≈ 0.1192`。平均负对数似然约 0.1269，比停在 `±1/2` 更低。这是同一切分上的更大一步，仍然是训练点上的损失。步长 `ν` 可以只取这个牛顿权重的一部分；取多少，仍看验证集。

## 和偏差、方差怎么接上

上一篇把固定 `x` 上的平均平方误差拆成噪声、偏差的平方和方差。树这一族把假设类换成递归划分，三项里能被模型碰到的是后两项。

| 做法 | 本篇已经算出的数 | 偏差和方差上的方向 |
| --- | --- | --- |
| 树桩 | 训练 SSE 从 26 到 1；`x = 1.6` 的平方误差是 `9/100` | 一片只有一个平均数，能表达的阶梯少 |
| 每个点一个叶子 | 训练 SSE 是 0；同一点的平方误差是 `16/25` | 训练点上可以消掉残差，预测跟着这一份样本走 |
| 许多深树的平均 | `σ² = 4`、`ρ = 1/2`、`B = 100` 时方差是 `101/50`，无穷多棵树时是 2 | 方差里 `1/B` 的那一项下降，`ρσ²` 留下 |
| 两棵单特征树的平均 | 训练 SSE 从每棵树的 1 到 `1/2` | 平均的是受限的树；能使用两个特征的深树在这四个点上 SSE 是 0 |
| 浅树逐步加残差 | `ν = 1/2` 时 SSE 是 26、`29/4`、`41/16`；`ν = 1` 再加一刀时训练 SSE 到 `2/3`，`x = 1.6` 可以升到 `49/225` | 训练误差随步数下降，新点上的误差可以在中途变大 |

随机森林通常长深树再平均，压的是方差，地板由树之间的相关决定。梯度提升通常用浅树沿残差或负梯度往前加，压的是还没拟合掉的那一部分；步数和 `ν` 过大时，验证误差会重新上升。两者都不是「树越多越好」这一句话：前一句里树多会碰到 `ρ`，后一句里步数多会碰到验证集。

## 容易算错的地方

- 划分的收益用误分类率时，上面那组 `a` 的收益是 0，Gini 的收益是 `1/50`。纯度已经变了，错误个数还没变。
- 训练 SSE 从 1 降到 0，`x = 1.6` 的平方误差从 `9/100` 升到 `16/25`。
- 抽样 A 里下标 0 出现两次，它在袋内。袋外只有下标 1。
- 点 2 没有袋外预测。把它的误差写成 0 再对四个点平均，得到 `337/64`。按点平均是 `337/48`，按树平均是 `193/32`。
- `ρ = 1/2`、`σ² = 4` 时，无穷多棵树的方差是 2，不是 0。
- 提升的下一步拟合 `y - F` 或 `y - p`。把原始 `y` 再拟合一遍，是另一棵独立的树。
- `ν = 1` 且第一刀是 `k = 2` 时，下一棵树在同一刀上的叶子值是 0。有收益的是 `k = 1` 和 `k = 3`。
- 这两刀的训练 SSE 都是 `2/3`。`x = 1.6` 上一个是 `49/225`，一个是 `4/225`。
- 叶子频率 `4/5` 是训练标签的比例。牛顿步把训练损失从约 0.6931 降到约 0.1269，降的也是这四个训练点。
- 只用 `x₁` 和只用 `x₂` 的 SSE 都是 1，因为这四行里它们对称。相等不是因果。

## 练习

### 练习 1：三行里选一刀

- 目标：用叶子平均的平方和选择 `k`。
- 限制：纸笔。
- 题面：`y = [1, 2, 6, 7]` 已经按 `x` 升序。三个 `k` 的左右 SSE 各是多少？树桩选哪一个？四个训练点上的预测是什么？
- 完成标准：14、1、14。`k = 2`。预测 `3/2, 3/2, 13/2, 13/2`。

<details>
<summary>参考解答</summary>

根 SSE 是 26。`k = 1` 时右叶子 2、6、7 的平均是 5，平方和 14。`k = 2` 时左右平均是 `3/2` 和 `13/2`，平方和各 `1/2`。`k = 3` 的平方和也是 14。最小的是 `k = 2`。

</details>

### 练习 2：收益为 0 的那一刀

- 目标：把误分类率和 Gini 分开。
- 限制：纸笔。父节点 7 正 3 负；`a = 0` 是 4 正 1 负；`a = 1` 是 3 正 2 负。
- 题面：两种准则的收益各是多少？若实现只在收益大于 0 时才划分，误分类率会怎样处理这一刀？
- 完成标准：误分类率收益 0，Gini 收益 `1/50`。

<details>
<summary>参考解答</summary>

误分类率在划分前后都是 `3/10`，因为三个负类仍被多数类判错。Gini 从 `21/50` 降到 `2/5`，差是 `1/50`。只看误分类率时，这一刀的收益是 0，不会被选上。

</details>

### 练习 3：训练 SSE 和这一个新点

- 目标：看出训练平方和的排序可以和新点相反。
- 限制：纸笔。沿用阈值规则。
- 题面：深树和树桩在 `x = 1.6`、`y = 6/5` 上各预测多少？平方误差各是多少？哪一个训练 SSE 是 0？
- 完成标准：深树预测 2，平方误差 `16/25`，训练 SSE 是 0。树桩预测 `3/2`，平方误差 `9/100`。

<details>
<summary>参考解答</summary>

深树的根阈值是 `5/2`，左边的阈值是 `3/2`。`1.6` 落在 `(3/2, 5/2]`，叶子是训练点 `x = 2`，预测 2。`(2 - 6/5)² = 16/25`。树桩只有阈值 `5/2`，`1.6` 在左边，预测 `3/2`，平方误差 `9/100`。

</details>

### 练习 4：方差的地板

- 目标：把 `ρ` 留在公式里。
- 限制：纸笔。`σ² = 4`，`ρ = 1/2`。
- 题面：`B = 1`、`B = 100` 和 `B` 趋于无穷时，平均预测的方差各是多少？`ρ` 改成 0 时，无穷多棵树的方差是多少？
- 完成标准：4、`101/50`、2。`ρ = 0` 时无穷多棵树的方差是 0。

<details>
<summary>参考解答</summary>

公式是 `ρσ² + (1-ρ)σ² / B`。`B = 1` 时是 4。`B = 100` 时是 `2 + 2/100 = 101/50`。无穷多棵树时第二项消失，剩下 `ρσ² = 2`。`ρ = 0` 时这一项也是 0。

</details>

### 练习 5：两种袋外平均

- 目标：空着的点不能补 0。
- 限制：纸笔。深度 0。抽样 A 是 `(0, 0, 2, 3)`，抽样 B 是 `(1, 1, 2, 2)`，`y = [1, 2, 6, 7]`。
- 题面：两次抽样的袋外集合是什么？按点平均、按树平均，以及把点 2 写成 0 之后的四点数，各是多少？
- 完成标准：袋外分别是 `{1}` 和 `{0, 3}`。三个数是 `337/48`、`193/32`、`337/64`。

<details>
<summary>参考解答</summary>

A 的预测是 `15/4`，只评估点 1，平方误差 `49/16`。B 的预测是 4，评估点 0 和点 3，平方误差都是 9。点 2 两次都在袋内。三个已有误差的平均是 `337/48`。两棵树的袋外误差 `49/16` 和 9 再平均是 `193/32`。把点 2 补成 0 后对四个点平均是 `337/64`。

</details>

### 练习 6：第二刀不是第一刀

- 目标：残差平均为 0 的划分不再移动 `F`。
- 限制：纸笔。`ν = 1`，第一刀已经是 `k = 2`。
- 题面：第二步的残差是什么？`k = 2` 的叶子值是什么？平局时实现选哪个 `k`？训练 SSE 变成多少？`x = 1.6` 的平方误差变成多少？
- 完成标准：残差 `[-1/2, 1/2, -1/2, 1/2]`。`k = 2` 的叶子值是 0。选择 `k = 1`。训练 SSE 是 `2/3`，这个新点是 `49/225`。

<details>
<summary>参考解答</summary>

第一棵树之后的预测是 `3/2, 3/2, 13/2, 13/2`，减去 `y` 得到上述残差。`k = 2` 两边的平均都是 0。`k = 1` 与 `k = 3` 的 SSE 都是 `2/3`，平局取最小的 `k`。`x = 1.6` 大于阈值 `3/2`，预测变成 `3/2 + 1/6 = 5/3`，对 `6/5` 的平方误差是 `49/225`。`k = 3` 在这个点上是 `4/225`，训练 SSE 也是 `2/3`。

</details>

### 练习 7：半步还没走到树桩

- 目标：`ν` 乘在叶子值外面。
- 限制：纸笔。
- 题面：`ν = 1/2`，初始预测 4，连续两步都取 `k = 2`。两步之后左右的预测是什么？训练 SSE 是多少？它和 `ν = 1` 的树桩 SSE 哪一个大？
- 完成标准：左 `17/8`，右 `47/8`，SSE 是 `41/16`。`41/16` 大于 1。

<details>
<summary>参考解答</summary>

第一步的叶子是 `-5/2` 和 `5/2`，乘 `1/2` 之后 `F` 变成 `11/4` 和 `21/4`，SSE 是 `29/4`。第二步的残差平均是 `-5/4` 和 `5/4`，再乘 `1/2`，得到 `17/8` 和 `47/8`。SSE 是 `41/16`。`ν = 1` 的一棵树桩已经把 SSE 做到 1。

</details>

### 练习 8：残差平均和牛顿权重

- 目标：二阶导把同一切分的步长放大。
- 限制：纸笔，概率可以用四位小数。
- 题面：`F = 0`，`y = [0, 0, 1, 1]`。伪残差是什么？`k = 2` 时残差叶子和牛顿叶子各是什么？三组 logit（全 0、`±1/2`、`±2`）上的平均负对数似然约是多少？
- 完成标准：伪残差 `[-1/2, -1/2, 1/2, 1/2]`。残差叶子 `±1/2`，牛顿叶子 `±2`。约 0.6931、0.4741、0.1269。

<details>
<summary>参考解答</summary>

`p = 1/2`，所以 `y - p` 就是这四个数，二阶导 `p(1-p) = 1/4`。左叶子梯度和是 1，二阶导和是 `1/2`，牛顿权重是 -2；右边是 2。全 0 时每个点的损失是 `ln 2`。后两组分别是 `-ln σ(1/2)` 和 `-ln σ(2)`。

</details>

## 本篇之外

线性回归会把正规方程和梯度下降放进同一个模型，那一篇还没有写。叶子里的频率是训练比例，概率预测是否校准留在后面。PCA 尚未写。

上一篇用验证集在两个 `λ` 之间选择。本篇的树深、提升的轮数和 `ν` 用同一批没参与拟合的点来停。`x = 1.6` 上的 `49/225` 和 `4/225` 就是一次这样的比较，只是验证集里只有一个点。

指数损失上的 AdaBoost 见文献里的 Friedman 2001 和 ESL 第 10 章。本篇的手算停在平方损失和对数损失。划分、袋外的两种平均、方差地板和提升的 SSE 由 `check_trees` 复核。
