## 训练误差与泛化误差

[最小闭环](01-监督学习的最小闭环.md) 里，风险是损失在数据分布上的期望，经验风险是训练集上的平均损失。本篇把这两个数用在已经拟合好的参数上。

参数一旦定下来，训练误差是这条损失在训练集上的平均。泛化误差是同一条损失在一条新样本上的期望。新样本和训练集独立，从同一个分布抽出。泛化误差仍依赖于这份训练集，因为参数是它拟合出来的。

再对训练集取期望，得到平均泛化误差。偏差–方差分解拆的是这一个数。只拿手头这一份验证集算出来的，是泛化误差的一次估计，还没有对训练集取期望。

参数在训练集上被选过，所以训练误差通常把泛化误差估小了。样本均值那一节会把这个差距算成 `2/n`。这里先记住比较的方向：用来拟合的那些点，不能单独当作新样本上的成绩。

## 平方损失的偏差–方差分解

固定一个输入 `x`。真实关系写成 `y = f(x) + ε`，`E[ε] = 0`，`Var(ε) = σ²`，ε 与训练集独立，因此也与预测 `ŷ` 独立。`ŷ` 是训练集的函数。记 `m = E[ŷ]`，期望只对训练集取。

把误差拆成三段：

```text
y - ŷ = (y - f(x)) + (f(x) - m) + (m - ŷ)
```

平方之后取期望，三个交叉项都是 0。

- `(y - f(x))` 的期望是 0，它和常数 `f(x) - m` 的乘积期望是 0。
- 它和 `m - ŷ` 的乘积期望是 0，因为 ε 与 `ŷ` 独立，而 `E[ε] = 0`。
- `(f(x) - m)` 是常数，`E[m - ŷ] = 0`，这一项的交叉也是 0。

剩下三项：

```text
E[(y - ŷ)²] = σ² + (f(x) - m)² + E[(ŷ - m)²]
```

第一项是噪声，换模型也消不掉。第二项是偏差的平方：预测的平均离真实函数有多远。第三项是方差：换一份训练集，预测甩得有多开。这个等式用的是平方损失。0-1 损失没有同样的三项。

下面不从样本反推系数，只规定每个训练集上的预测，用来把三项算完。系数怎样从样本得到，是岭回归那一节的事。

设 `f(x) = 1`，ε 取 `+1` 和 `-1` 各 `1/2`，所以 `σ² = 1`，`y` 取 2 和 0 各 `1/2`。两个训练集 `D1`、`D2` 各以 `1/2` 出现。

| 模型 | `D1` 的预测 | `D2` 的预测 | `m` | 偏差平方 | 方差 | 平均泛化误差 |
| --- | --- | --- | --- | --- | --- | --- |
| A | 3 | -1 | 1 | 0 | 4 | 5 |
| B | 2 | 1 | `3/2` | `1/4` | `1/4` | `3/2` |
| 永远预测 0 | 0 | 0 | 0 | 1 | 0 | 2 |

模型 A：`m = (3 + (-1)) / 2 = 1`，偏差是 0。方差是 `((3 - 1)² + (-1 - 1)²) / 2 = (4 + 4) / 2 = 4`。平均泛化误差是 `1 + 0 + 4 = 5`。

模型 B：`m = (2 + 1) / 2 = 3/2`，偏差是 `3/2 - 1 = 1/2`，平方是 `1/4`。两个偏离都是 `1/2`，方差是 `(1/4 + 1/4) / 2 = 1/4`。平均泛化误差是 `1 + 1/4 + 1/4 = 3/2`。

直接把四种结果平均一遍，用来核对分解没有把交叉项漏掉。每种 `(数据集, ε)` 的概率是 `1/4`。模型 B 的四种平方误差：

```text
y = 2, ŷ = 2 → 0
y = 0, ŷ = 2 → 4
y = 2, ŷ = 1 → 1
y = 0, ŷ = 1 → 1
平均 (0 + 4 + 1 + 1) / 4 = 3/2
```

和分解一致。模型 A 的四种平方是 `1, 9, 9, 1`，平均是 5。永远预测 0 时，`y = 2` 的平方是 4，`y = 0` 的平方是 0，平均是 2。

在这个分布上，方差为 4 的模型平均误差是 5，永远预测 0 的平均误差是 2，带一点偏差的模型 B 是 `3/2`。欠拟合不是这三者里最差的那个。模型 B 用 `1/4` 的偏差平方，换掉了模型 A 几乎全部的方差。

## 过拟合与欠拟合

欠拟合是偏差大。永远预测 0 的方差是 0，偏差平方是 1。再多的同类样本也不会改变这个预测，平均误差停在 2，而噪声下限是 1。假设类里最好的常数是 1，0 不在「靠数据能纠正」的方向上，它根本不看数据。

过拟合是方差大。模型 A 没有偏差，预测从 3 甩到 -1，训练集里的噪声进了预测。平均误差 5 里面，4 来自方差。

一份数据上的训练误差和验证误差，是上面这个平均的一次抽样，不是平均本身。训练误差很低、验证误差很高，先对照方差：模型跟着这批训练点走，换一批点就对不上。两条误差都高、而且靠在一起，先对照偏差：假设类的平均预测离 `f` 远，再拟合也不会靠近。学习曲线一节把这两种形状和样本量、优化步数对齐。

正则是主动做模型 B 那种交换：接受一些偏差，把方差降下来。岭回归在一份训练集上把系数缩小。那是一次拟合，还不是上表里对许多训练集取的期望。

## 岭回归的闭式解

没有截距。三条训练样本是

```text
X = | 1  0 |     y = | 1 |
    | 0  1 |         | 1 |
    | 1  1 |         | 0 |
```

预测是 `ŷ = w₁ x₁ + w₂ x₂`。目标写成

```text
J(w) = (1/2) ‖Xw - y‖² + (λ/2) ‖w‖²
```

对 `w` 求导，令梯度为 0：

```text
Xᵀ(Xw - y) + λ w = 0
(XᵀX + λ I) w = Xᵀ y
```

前面的 `1/2` 让梯度里不出现 2。把它去掉，改成 `‖Xw - y‖² + λ ‖w‖²`，解是同一个 `w`。平方和若先除以 `n`，对角上加的数要改成 `nλ`。本篇的正规方程没有除以 `n`；均方误差只在算训练误差和验证误差时才除以 3。Hoerl 和 Kennard 在 `XᵀX` 的对角上加的那个正数，就是这里的 `λ`。

```text
XᵀX = | 2  1 |     Xᵀy = | 1 |
      | 1  2 |           | 1 |
```

`XᵀX` 就是线性代数笔记里那个特征值是 3 和 1 的矩阵。`(1, 1)` 被映到 `(3, 3)`，`(1, -1)` 被映到 `(1, -1)`。

`λ = 0` 时就是正规方程。行列式是 `4 - 1 = 3`：

```text
w = (1/3) | 2  -1 | | 1 | = (1/3) | 1 | = | 1/3 |
          |-1   2 | | 1 |         | 1 |   | 1/3 |
```

`λ = 1` 时对角变成 3，行列式是 `9 - 1 = 8`：

```text
w = (1/8) | 3  -1 | | 1 | = (1/8) | 2 | = | 1/4 |
          |-1   3 | | 1 |         | 2 |   | 1/4 |
```

系数从 `(1/3, 1/3)` 收到 `(1/4, 1/4)`。

训练误差用均方误差，不把 `λ ‖w‖²` 加进去。惩罚已经体现在 `w` 里；再加一次，不同 `λ` 的目标就不能当预测成绩来比。三条样本，`n = 3`。

`λ = 0` 的预测是 `1/3, 1/3, 2/3`。残差都是绝对值 `2/3`：

```text
平方和 = 3 × 4/9 = 4/3
训练误差 = (4/3) / 3 = 4/9
```

`λ = 1` 的预测是 `1/4, 1/4, 1/2`。残差是 `3/4, 3/4, -1/2`：

```text
平方和 = 9/16 + 9/16 + 4/16 = 11/8
训练误差 = (11/8) / 3 = 11/24
```

`4/9 = 32/72`，`11/24 = 33/72`。训练误差上升了 `1/72`。`λ = 0` 是训练均方误差的最小值点，任何一个别的 `w` 都不会更小。只看训练误差，会选 `λ = 0`。

残差也不再垂直于列。`λ = 1` 时，残差 `(3/4, 3/4, -1/2)` 和第一列 `(1, 0, 1)` 的点积是 `3/4 - 1/2 = 1/4`，等于 `λ w₁`。`λ = 0` 时残差是 `(2/3, 2/3, -2/3)`，和同一列的点积是 0。一般地，`Xᵀ(y - Xw) = λ w`。

特征值也跟着平移。`λ = 1` 时，`(1, 1)` 被映到 `(4, 4)`，`(1, -1)` 被映到 `(2, -2)`。条件数从 `3/1 = 3` 变成 `4/2 = 2`。最小二乘系数的协方差里有 `(XᵀX)⁻¹`，很小的特征值会把这个方差放大。对角上加 `λ`，就是把每个特征值加上 `λ`。

若设计矩阵里有一列全是 1，通常不把这一列放进 `λ I`，否则惩罚会把预测的平均往 0 拉。另一种做法是先把各列和 `y` 中心化，再对斜率做岭回归。本篇的 `X` 没有全 1 列，两个系数都受罚。scikit-learn 的 `Ridge` 在默认估计截距时不惩罚截距；没有截距时，文档里的 `α` 就是本篇的 `λ`。

验证集是另外三个点，没有参与上面的解：

| `x₁` | `x₂` | `y` |
| --- | --- | --- |
| 1 | 0 | `1/2` |
| 0 | 1 | 0 |
| 1 | 1 | `1/2` |

`λ = 0` 的残差是 `-1/6, 1/3, 1/6`，平方和是 `1/36 + 4/36 + 1/36 = 1/6`，验证误差是 `(1/6) / 3 = 1/18`。

`λ = 1` 的残差是 `-1/4, 1/4, 0`，平方和是 `1/8`，验证误差是 `(1/8) / 3 = 1/24`。

`1/18 = 4/72`，`1/24 = 3/72`。验证误差下降了 `1/72`。在这两个候选里，验证集选 `λ = 1`。

这三个验证点的误差低于训练误差：`1/18` 和 `1/24` 都小于 `4/9`。那只说明这三个点离预测更近。一次划分里验证低于训练，不能单独写成「没有过拟合」或「发生了泄漏」。用来做选择的，是两个 `λ` 的验证误差哪一个更小。

`λ = 3` 留给练习。验证误差不是随着 `λ` 单调下降的。

## L1 为什么能把系数收成 0

岭回归把每个系数缩小，一般缩不到正好为 0。Lasso 换成绝对值。Tibshirani 的原始写法是在 `∑ |wⱼ| ≤ t` 的约束下最小化残差平方和。约束区域在坐标轴上有尖角，平方误差的等高椭圆常常先碰到尖角，尖角上至少有一个坐标是 0。圆盘没有尖角，碰到坐标轴要靠椭圆的轴正好对齐。这是形状上的原因。下面的一维计算给出稀疏发生的条件。

能手算的是一个坐标、列已经正交的情形。设最小二乘在这个坐标上的解是 `z`，目标

```text
J(w) = (1/2)(w - z)² + λ |w|
```

`|w|` 在 `w ≠ 0` 的导数是 `sign(w)`，在 0 的次梯度是区间 `[-1, 1]`。

- `z > λ` 时，`w = z - λ > 0`。导数 `w - z + λ = 0`。
- `z < -λ` 时，`w = z + λ < 0`。
- `|z| ≤ λ` 时，`w = 0` 是最优。`J` 在 0 的次梯度是 `-z + λ s`，`s ∈ [-1, 1]`。取 `s = z/λ`（`λ > 0`），次梯度含 0。绝对值在 0 的斜率区间能配平任何落在 `[-λ, λ]` 里的 `z`。

同一个坐标的 L2 目标是 `(1/2)(w - z)² + (λ/2) w²`，解是 `w = z / (1 + λ)`。平方项在 0 的导数是 0，配平不了一个非零的 `z`，所以 `z ≠ 0` 时解也不是 0。

| `z` | `λ` | L1 | L2 |
| --- | --- | --- | --- |
| 3 | 1 | `3 - 1 = 2` | `3/2` |
| `1/2` | 1 | 0 | `(1/2) / 2 = 1/4` |

`z = 3` 时 L1 的解是 2，这个坐标并没有被收成 0。稀疏发生在 `|z| ≤ λ` 的那些坐标上。`z = 1/2` 正好落进区间，L1 给出 0，L2 还留着 `1/4`。

阈值的位置跟着目标的写法走。若有人把目标写成 `(w - z)² + λ |w|`，配平 0 的区间会变成 `|z| ≤ λ/2`。先把 `λ` 写在哪一项前面对齐，再比较数字。

## 训练、验证、测试与 k 折

记号约定里的三份划分在这里继续用。

- 训练集更新 `w`。
- 验证集选择 `λ`、假设类和是否停。
- 测试集只在选择结束之后报告一次。

上面三个点的验证误差已经把 `λ` 选成 1。最终模型是用这个 `λ`、在三行训练集上重拟合的 `(1/4, 1/4)`。验证点不进这一次拟合。

再留三个点当测试，选择时不看它们：

| `x₁` | `x₂` | `y` |
| --- | --- | --- |
| 1 | 0 | 1 |
| 0 | 1 | 0 |
| 1 | 1 | 1 |

`λ = 1` 的测试误差是 `7/24`。`λ = 0` 的测试误差是 `2/9`。`2/9 = 16/72`，`7/24 = 21/72`，测试集更喜欢 `λ = 0`。

报告的数仍是 `7/24`。选择已经在验证集上做完。看见测试集更喜欢另一个 `λ` 再改回去，测试集就参加了选择，这份误差不再是「没看过的一次考试」。`1/24` 和 `7/24` 来自两份不同的三个点，差距里既有抽样，也有「我们挑了验证上更好的那个」。不能把 `7/24 - 1/24` 单独叫成选择带来的乐观程度。

一份验证集的运气会很大。k 折交叉验证把同一件事做 k 次再平均。把样本分成 k 份。对每一份：只用其余的样本重新拟合，在留出的那一份上算平均损失。k 个损失再平均。每一折的均值、标准差、特征选择都重新估计，这和最小闭环里「先标准化再划分」是同一条纪律。

下面用另一个一维例子把重拟合算清楚。模型是 `ŷ = w x`，没有截距。两个点 `(x, y) = (1, 1)` 和 `(1, 3)`。`k = 2`，每一折一个点，这就是留一法。目标仍是 `(1/2)` 乘平方和再加 `(λ/2) w²`，所以一个点上的解是 `w = xy / (x² + λ)`。

用全部两个点拟合：`∑ x² = 2`，`∑ xy = 4`，`w = 4 / (2 + λ)`。

| `λ` | 全数据的 `w` | 训练误差 |
| --- | --- | --- |
| 0 | 2 | 1 |
| 1 | `4/3` | `13/9` |

`λ = 0` 的预测都是 2，残差 `-1` 和 `1`，均方误差是 1。`λ = 1` 的预测都是 `4/3`，残差 `-1/3` 和 `5/3`，平方和 `26/9`，均方误差是 `13/9`。训练误差仍选 `λ = 0`。

留一必须重拟合。留出 `(1, 3)` 时，只用 `(1, 1)`：`w = 1/(1+λ)`。留出 `(1, 1)` 时，只用 `(1, 3)`：`w = 3/(1+λ)`。

| `λ` | 留出 `(1, 3)` 的平方误差 | 留出 `(1, 1)` 的平方误差 | 平均 |
| --- | --- | --- | --- |
| 0 | `(3 - 1)² = 4` | `(1 - 3)² = 4` | 4 |
| 1 | `(3 - 1/2)² = 25/4` | `(1 - 3/2)² = 1/4` | `13/4` |

`13/4 < 4`，留一平均选 `λ = 1`。选完之后，用 `λ = 1` 在两个点上重拟合，得到 `w = 4/3`。`13/4` 是选择用的分数。两个点都进过某一折的训练，它不是一份没参加选择的测试误差。这个例子没有第三份留出数据，就不另报一个测试数。

若有人用全数据的 `w` 在这两个点上算误差，再把它叫成交叉验证，算出来的是训练误差 1 和 `13/9`，选择会回到 `λ = 0`。折里的模型必须没见过这一折的标签。

## 超参数搜索

`λ`、树的深度、学习率、停在第几步，都是超参数：它们决定拟合哪一个模型，但不是那一次拟合里用梯度或正规方程解出来的 `w`。

本篇的搜索范围就是两个数，`{0, 1}`。准则是验证均方误差或留一平均。训练均方误差会选 `λ = 0`。`J(w)` 里的惩罚项随 `λ` 的写法变尺度，不同 `λ` 的 `J` 不能横比。

候选一多，验证上的最小值会偏乐观：你看见的是好几个噪声估计里最小的那个。上面测试集和验证集的差距已经提醒这件事，但那两份各只有三个点，数字本身不是纠偏公式。想估计「整个选择过程」在新样本上的误差，要把选择放进内层，外层再留一份从不参与选择的数据。这就是嵌套的交叉验证。外层的每一折里，内层重新挑 `λ`。本篇不把嵌套的全部分数再算一遍。

网格把每个超参数的取值乘在一起。真正影响验证误差的往往只有少数几维，其余维度上的格子是在重复。Bergstra 和 Bengio 比较了同样试验次数下的网格和随机搜索：随机搜索在重要的那几维上试过的不同取值更多，结果通常不差于网格，有时更好。他们的实验数字以论文为准，这里不搬。

## 选择模型时的泄漏

最小闭环里的两类泄漏这里仍然算。用全量数据估计均值和标准差，再划分，评价点的位置进了训练用的变换。特征在决策时刻还不存在，模型学到的是结果伴随的字段。

选择模型又多出几条。

用全部行对标签做相关，留下相关最高的若干列，然后再划分。列的去留已经看过测试标签。后面即使只在训练集上重估系数，列还是那一组。相关和任何其他筛选都要在训练折里做，每一折重做。

同一行复制进训练集和测试集。测试误差里有模型训练时见过的点。重复行要在划分前去掉；划分之后若仍有同一个键的多行，这些行进同一折。同一个用户的多行若分别落在训练和测试里，测到的是这个用户再出现一次时的误差。新用户的误差要让该用户的全部行留在同一折。

按时间排列的决策，随机划分会把后来的行放进训练、较早的行放进测试。若预测时只能看见过去，划分也要按时间：训练在前，验证和测试在后。

验证集参加了 `λ` 的选择之后，它的误差是选择后的误差。把它印成最终成绩，和用测试集调 `λ` 是同一类问题，只是名字不同。

## 学习曲线

学习曲线先声明横轴。横轴是样本量时，它回答「再收集数据有没有用」。横轴是优化步数时，它回答「再训练有没有用」。两张图不能套同一个结论。

先看样本量。总体里一个数 `y` 取 0 或 2，各 `1/2`，没有特征。`E[y] = 1`，`E[y²] = 2`，`σ² = 1`。最好的常数预测是 1，噪声下限是 1。概率笔记已经证明：独立同分布、方差为 `σ²` 时，`∑ (xᵢ - x̄)² / n` 的期望是 `((n - 1) / n) σ²`。那里的 `1, 2, 3` 是同一次平方和的两种除法，不是这个期望。四个等可能样本上这个估计量各取什么值，见 [统计](../02-数学基础/03-统计.md)。本篇的训练误差就是除以 `n` 的这一个。

永远预测 0：预测不看样本。每条的平方误差期望是 `E[y²] = 2`，训练和测试都是 2，`n` 变大也不变。

样本均值：无偏，方差是 `σ² / n`。期望测试误差是 `σ² + σ² / n = (n + 1) / n`。期望训练误差是 `(n - 1) / n`。二者的差是 `2/n`。

`n = 2` 可以穷举。四种样本等可能：

| 样本 | 均值 | 训练误差 | 新 `y` 上的期望误差 |
| --- | --- | --- | --- |
| `(0, 0)` | 0 | 0 | 2 |
| `(0, 2)` | 1 | 1 | 1 |
| `(2, 0)` | 1 | 1 | 1 |
| `(2, 2)` | 2 | 0 | 2 |

训练误差的平均是 `(0 + 1 + 1 + 0) / 4 = 1/2`。测试误差的平均是 `(2 + 1 + 1 + 2) / 4 = 3/2`。和公式一致。

| `n` | 永远预测 0 | 样本均值的期望训练误差 | 样本均值的期望测试误差 |
| --- | --- | --- | --- |
| 2 | 2 | `1/2` | `3/2` |
| 4 | 2 | `3/4` | `5/4` |

永远预测 0 的两条线贴在 2。这是偏差。加数据没用，要换假设，至少允许预测靠近 1。

样本均值的训练误差期望低于测试误差期望，差距从 1 降到 `1/2`。这是方差。加数据会把差距缩小。训练误差的期望从 `1/2` 升到 `3/4`，是 `(n - 1) / n` 在向 `σ²` 靠近。同一段里，测试误差的期望从 `3/2` 降到 `5/4`。

横轴改成优化步数时，用同一份训练集反复更新参数。预训练笔记里有一张已经算完的表：步 400 的训练 NLL 是 2.50、验证是 3.05；步 800 的训练是 2.10、验证是 3.20。训练还在降，验证已经升。相对这一份验证文本，400 步之后的更新在拟合训练文本，没有改进验证文本。留下步 400，就是用验证曲线选择步数。

两种形状对应的下一步：

- 训练和验证都高，并且靠在一起：加大假设类、减小 `λ`、或训练更久。若加数据和加容量之后仍然贴在高处，回到特征在决策时是否真的含有 `y` 的信息。
- 训练变低、验证变高：增大 `λ`、提早停止、增加数据，或缩小假设类。停下来的那一步由验证曲线选，不由最后一步的训练损失选。
- 验证远低于训练，低到像在默写验证文本：先查泄漏和污染。预训练笔记里验证 NLL 低到 `0.05`、训练 NLL 仍在 2 以上的那个对照，就是这种形状。

## 权重衰减、早停和评估污染

三件后面会再遇到的事，和本篇是同一个选择问题。

权重衰减让大的参数变贵，动机和岭回归的 `(λ/2) ‖w‖²` 相同。Krogh 和 Hertz 把这项写进梯度下降。优化笔记里的 AdamW 把衰减直接乘在参数上，不送进矩估计；耦合形式才会把 `λ θ` 加进梯度，再被自适应分母缩放。因此不能把 AdamW 的 `λ` 代进 `(XᵀX + λ I)⁻¹ Xᵀ y`。网络的损失也不是这条二次型。平方惩罚的闭式解停在本篇这种线性模型上。

早停限制的是优化走了多远。步数和 `λ` 一样，是用验证曲线选择的超参数。被选中那一步的验证损失，是选择用的分数。预训练笔记留下步 400，用的就是这条规则。早停怎样写进训练循环，是系统笔记的事。

评估笔记里的污染，是题目或它的近副本出现在任何会更新参数的数据里，包括预训练、监督微调和偏好数据。本篇的泄漏，是评价用的样本参与了 `w` 或 `λ` 的决定。结构相同：拿来打分的数据先被用来做了选择。测试集上调完 `λ` 再报告这个测试误差，和把测试题放进训练集再报告准确率，差在参数是被手上的选择改的，还是被梯度改的。

## 容易算错的地方

- 泛化误差是新样本上的期望。再对训练集取期望，才是偏差–方差分解的那个数。一份验证集只是一次估计。
- 分解只对平方损失成立。交叉项用了 `E[ε] = 0` 和 ε 与 `ŷ` 独立。
- 比较 `λ` 时用预测的均方误差。`J(w)` 里的惩罚项尺度不同，不能横比。
- `1/2` 不改变岭回归的解。L1 的阈值依赖于 `λ` 写在平方项前面还是绝对值前面。
- 全 1 的截距列通常不放进 `λ I`。本篇没有这一列。
- 本例验证误差低于训练误差，只说明这三个验证点离预测更近。选择看的是 `λ` 之间的比较。
- k 折的每一折都要重拟合。用全数据的残差冒充验证，得到的是训练误差。
- 验证上最好的那个 `λ`，它的验证误差偏乐观。看见测试集更喜欢另一个值，也不能改选择。
- 样本量学习曲线上，训练误差的期望上升，可以只是 `(n - 1) / n` 在变大。

## 练习

### 练习 1：解出两个系数

- 目标：从 `(XᵀX + λ I) w = Xᵀ y` 解到向量。
- 限制：纸笔。
- 题面：用正文的三行训练数据。分别对 `λ = 0` 和 `λ = 1` 求出 `w`。
- 完成标准：`(1/3, 1/3)` 和 `(1/4, 1/4)`。

<details>
<summary>参考解答</summary>

`XᵀX = [[2, 1], [1, 2]]`，`Xᵀy = (1, 1)`。`λ = 0` 的行列式是 3，`w = (1/3, 1/3)`。`λ = 1` 的行列式是 8，`w = (1/4, 1/4)`。对称性也可以：两个方程相同，所以两个坐标相等，`(3 + λ) w₁ = 1`。

</details>

### 练习 2：训练误差、验证误差和 `λ = 3`

- 目标：确认训练误差随 `λ` 上升，验证误差不单调。
- 限制：纸笔。
- 题面：`λ = 0` 和 `λ = 1` 的训练误差、验证误差各是多少？验证选哪一个？再算 `λ = 3` 的系数、训练误差和验证误差。三个候选里验证选哪一个？
- 完成标准：训练误差 `4/9`、`11/24`；验证误差 `1/18`、`1/24`；`λ = 3` 时 `w = (1/6, 1/6)`，训练误差 `1/2`，验证误差 `1/18`。三个里仍选 `λ = 1`。

<details>
<summary>参考解答</summary>

`λ = 3` 时 `w = 1/(3+3) = 1/6`。训练残差是 `5/6, 5/6, -1/3`，平方和 `25/36 + 25/36 + 4/36 = 54/36 = 3/2`，除以 3 得 `1/2`。验证残差是 `-1/3, 1/6, -1/6`，平方和 `1/6`，除以 3 得 `1/18`。`1/18` 与 `λ = 0` 相同，都大于 `1/24`。

</details>

### 练习 3：测试集不能改选择

- 目标：分清选择用的误差和报告用的误差。
- 限制：纸笔。`λ = 0` 的测试误差可以只做通分比较。
- 题面：正文测试集上，`λ = 1` 的均方误差是多少？`λ = 0` 的是多少？为什么最终报告前者？
- 完成标准：`7/24` 和 `2/9`。说明选择已经用验证集做完。

<details>
<summary>参考解答</summary>

`λ = 1` 的残差是 `-3/4, 1/4, -1/2`，平方和 `7/8`，除以 3 得 `7/24`。`λ = 0` 的残差是 `-2/3, 1/3, -1/3`，平方和 `2/3`，除以 3 得 `2/9`。`2/9` 更小。改选 `λ = 0` 会让测试集参加选择。报告保持 `7/24`。

</details>

### 练习 4：负坐标上的软阈值

- 目标：次梯度在 0 的区间能配平小的 `z`。
- 限制：纸笔。
- 题面：目标仍是 `(1/2)(w - z)² + λ |w|`，L2 仍是 `(1/2)(w - z)² + (λ/2) w²`。`z = -1/2`，`λ = 1`。两个解各是多少？为什么 L1 的 0 是最优？
- 完成标准：L1 是 0，L2 是 `-1/4`。

<details>
<summary>参考解答</summary>

`|z| = 1/2 ≤ 1`，所以 L1 的解是 0。次梯度取 `s = z/λ = -1/2`，`-z + λ s = 1/2 + 1×(-1/2) = 0`。L2 的解是 `z / (1 + λ) = -1/4`。

</details>

### 练习 5：把分解和四种结果对上

- 目标：交叉项没有被漏掉。
- 限制：纸笔。
- 题面：模型 B 的偏差平方、方差、分解给出的平均误差各是多少？四种 `(y, ŷ)` 的平方误差平均是多少？
- 完成标准：都是 `1/4`、`1/4`、`3/2`，四种结果的平均也是 `3/2`。

<details>
<summary>参考解答</summary>

`m = 3/2`，偏差平方 `(1/2)² = 1/4`，方差 `(1/4 + 1/4) / 2 = 1/4`，加上 `σ² = 1` 得 `3/2`。四种平方 `0, 4, 1, 1`，平均 `6/4 = 3/2`。

</details>

### 练习 6：留一和训练误差选反

- 目标：每一折的 `w` 不能用全数据的那个。
- 限制：纸笔。
- 题面：点 `(1, 1)`、`(1, 3)`，模型 `ŷ = w x`。`λ = 0` 和 `λ = 1` 的训练误差、留一平均各是多少？各会选哪个 `λ`？若用全数据的 `w` 在两个点上算误差，会得到什么？
- 完成标准：训练误差 1 和 `13/9`，留一平均 4 和 `13/4`。训练选 0，留一选 1。用全数据残差得到的就是训练误差。

<details>
<summary>参考解答</summary>

全数据 `w = 4/(2+λ)`。`λ = 1` 时残差平方和 `26/9`，均方误差 `13/9`。留出时 `w = 1/(1+λ)` 和 `3/(1+λ)`，`λ = 1` 的两个平方误差是 `25/4` 和 `1/4`，平均 `13/4`。`13/4 < 4`，留一选 `λ = 1`。全数据残差就是训练误差，会选 `λ = 0`。

</details>

### 练习 7：样本量曲线上的训练误差

- 目标：训练误差的期望变大，不一定是估计变差。
- 限制：纸笔。可以用 `(n-1)/n` 和 `(n+1)/n`。
- 题面：`y` 仍取 0 或 2 各 `1/2`，预测用样本均值。`n = 4` 时期望训练误差和期望测试误差是多少？为什么训练误差的期望比 `n = 2` 时高？
- 完成标准：`3/4` 和 `5/4`。说明差来自 `(n-1)/n` 向 `σ²` 靠近。

<details>
<summary>参考解答</summary>

`σ² = 1`。期望训练误差 `(4-1)/4 = 3/4`，期望测试误差 `(4+1)/4 = 5/4`。`n = 2` 时训练误差期望是 `1/2`。上升是因为除以 `n` 的平方和，其期望占 `σ²` 的比例从 `1/2` 变成 `3/4`。测试误差的期望从 `3/2` 降到 `5/4`。

</details>

### 练习 8：先筛选特征再划分

- 目标：列的去留也是一次用到标签的估计。
- 限制：文字。
- 题面：有人在全部行上计算每一列和 `y` 的相关，留下相关最高的 10 列，然后随机划分训练、验证、测试，只在训练集上重估这 10 列的系数。问题在哪一步？每一折应该怎样做？
- 完成标准：写明相关看见了验证和测试的标签。

<details>
<summary>参考解答</summary>

相关用了全部标签，列的去留已经包含验证集和测试集的信息。应先划分。只在训练折上计算相关、决定留下哪些列，再把同一组列用到验证和测试。交叉验证的每一折重新做这次筛选。

</details>

## 本篇之外

线性回归会把同一条正规方程和梯度下降放在一个模型里。树把假设类换成递归划分，偏差和方差往哪边走留在那一篇。校准、PCA 尚未写。dropout 尚未写。
