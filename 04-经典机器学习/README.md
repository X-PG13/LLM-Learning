## 完成时你能做什么

- 给一个分类问题同时写出训练损失和上线时的决策规则。决策阈值由代价决定，准确率隐含的是 0.5 和相等代价。
- 推出二元逻辑回归里 `dL/dz = p - y`，并手算一步更新。
- 指出「用包括测试集在内的全量数据计算均值和方差」是泄漏，并改成只在训练折上估计。
- 说明 L2 惩罚让目标变成拟合损失加上参数平方和，大的参数要为拟合付出代价。
- 用平方损失把固定输入上的期望预测误差拆成噪声、偏差的平方和方差。
- 在两个 `λ` 之间用验证误差选择，并且不因为测试集更喜欢另一个 `λ` 就改选择。

## 这一阶段不追求

在进入反向传播之前实现每一种集成模型。决策树和梯度提升是表格数据上的强基线，笔记会写它们把偏差和方差往哪边推，不写成库的 API 手册。

中文教材可以读李航《统计学习方法》和周志华《机器学习》。课程和文档见 [阅读清单](../08-研究习惯/阅读清单.md)。
