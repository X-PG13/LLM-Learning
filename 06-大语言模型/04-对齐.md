## 本篇要回答的问题

1. 监督微调的分母为什么只数回答里的 token？把提示上的一个目标加进平均，数会怎样变？
2. 奖励差是 2 时，Bradley-Terry 概率是多少？给两个奖励同加一个常数，概率为什么不变？
3. 四次比较里有三次偏好拒绝。奖励差的极大似然是多少？四次全部偏好拒绝时，为什么没有有限的极大似然？
4. 一对回答的序列对数概率已经给出。DPO 的间隔、偏好概率、损失和梯度权重各是多少？
5. PPO 的裁剪读哪一个概率比，KL 惩罚读哪一个对数概率比？代理奖励上升时，真实奖励可以落到哪里？

## 三种数据，三种损失

预训练拟合的是文档里的下一个 token。对齐要改的是「给定用户写下的提示，模型接着写什么」。这一步用另外两种样本。

| 数据 | 一条样本 | 损失在看什么 |
| --- | --- | --- |
| 预训练 | 一段文档 | 每个被监督 token 的负对数概率 |
| 监督微调（supervised fine-tuning，SFT） | 提示，加一条示范回答 | 示范回答上的负对数概率 |
| 偏好 | 同一个提示下的两条回答，以及哪一条更好 | 两条回答的奖励差，或策略相对参考模型的对数概率差 |

SFT 只看见被选中的那一条回答。偏好数据把「哪一条更好」留下来，绝对分数由模型去拟合。后面的奖励模型和直接偏好优化（direct preference optimization，DPO）用的是第三行。人类反馈强化学习（reinforcement learning from human feedback，RLHF）先把第三行拟合成奖励，再去更新策略。

## SFT 仍是回答上的平均 NLL

约定 A 下，提示里的 token 仍然出现在输入里，模型以它们为条件。损失不要求模型去预测提示本身。系统笔记里的例子是 `tokens = [1, 8, 9, 2, 0, 0]`，`prompt_len = 2`，标签为 `[None, 9, 2, None, None]`。参加损失的是回答 `9` 和结束符 `2`。结束符留在分母里，模型才有一个可以预测的停止。

本篇只给这两个位置指定概率，把掩码本身留在系统笔记。设模型把概率 `0.4` 给了回答 token，把概率 `0.8` 给了结束符。两项负对数似然的平均是

```text
(-ln 0.4 + -ln 0.8) / 2 ≈ 0.5697
```

若有人把提示上的一个目标也算进来，而那个位置的概率是 `0.9`：

```text
(-ln 0.9 + -ln 0.4 + -ln 0.8) / 3 ≈ 0.4149
```

模型没有变。分母从 2 变成 3，多出来的一项是 `−ln 0.9 ≈ 0.1054`，比原来两项的平均更小，所以总平均下降。提示往往比回答容易：输入里已经看见了提示的前缀，抄写下一个提示 token 的概率可以很高。这个更小的数衡量的是「提示加回答」的混合，不再是示范回答本身。

SFT 提高的是示范回答的条件概率。两条候选回答谁更好，不在这个损失里。示范数据里如果经常出现同一种开场白，模型会把概率堆到那种开场白上，即使另一条更短、更直接的回答在偏好里会赢。

## Bradley-Terry：奖励差就是对数几率

记提示为 `x`，两条回答为 `y_w` 和 `y_l`。下标 `w` 是这次比较里被偏好的一条（winner），`l` 是落败的一条（loser）。奖励模型（reward model）给每条回答一个实数 `r(x, y)`。Bradley-Terry 模型把偏好概率写成

```text
P(y_w 优于 y_l | x) = σ(r(x, y_w) - r(x, y_l))
σ(z) = 1 / (1 + exp(-z))
```

`σ` 是逻辑回归里的 sigmoid。奖励差是 `z` 时，胜率对败率的比是 `e^z`，所以 `z` 就是这个偏好的对数几率（log-odds）。Stiennon 等和 Ouyang 等都把奖励差解释成人类标注员偏好其中一条的对数几率。

`r(y_w) = 1`，`r(y_l) = -1`，差是 2：

```text
P = σ(2) = 1 / (1 + e^{-2}) ≈ 0.8808
损失 = -ln σ(2) = ln(1 + e^{-2}) ≈ 0.1269
```

把两个奖励都加上 5，变成 `6` 和 `4`，差仍是 2，概率和损失都不变。只依赖提示、不依赖回答的函数 `f(x)` 加到 `r` 上，也会在差里消掉。奖励的绝对零点没有被这个损失钉住。Ouyang 等因此在做强化学习之前，用一个偏置把标注员示范回答的平均奖励调成 0。那一步用的是平移不变，不是另一套偏好模型。

一对比较的损失是 `-ln σ(r_w - r_l)`。它是「这条偏好发生了」的负对数似然。`K` 条回答排成一个序时，Ouyang 等把全部两两比较放进同一次平均，前面的系数是 `1 / C(K, 2)`。`K = 2` 时系数是 1。本篇的手算都是一对一，系数就是 1。同一提示下的多条排序也可以写成 Plackett-Luce 模型。Rafailov 等在附录里给出对应损失，本篇不展开那个一般形式。

### 四次比较的极大似然

同一类提示上有四次独立比较。三次里「拒绝回答」获胜，一次里「直接回答」获胜。把这一类上的奖励差记成常数 `δ = r(拒绝) - r(回答)`。四次的对数似然是

```text
3 ln σ(δ) + ln σ(-δ)
```

对 `δ` 求导：`ln σ(δ)` 的导数是 `σ(-δ)`，`ln σ(-δ)` 的导数是 `-σ(δ)`。导数为

```text
3 σ(-δ) - σ(δ) = 3 (1 - p) - p = 3 - 4p
```

`p = σ(δ)`。令导数为 0，得到 `p = 3/4`，于是 `e^{-δ} = 1/3`，`δ = ln 3 ≈ 1.0986`。极大似然把胜率估成样本里的比例 `3/4`，奖励差估成这个比例的对数几率。这和 [概率](../02-数学基础/02-概率.md) 里 Bernoulli 的极大似然是 `k/n` 是同一件事，这里的「成功」是「拒绝获胜」。

四次损失的平均是

```text
-(3 ln(3/4) + ln(1/4)) / 4 ≈ 0.5623
```

分子约 `2.2493`，就是概率笔记里那组三项加一项的负对数似然之和。

若四次全部是拒绝获胜，对数似然是 `4 ln σ(δ)`。它的导数 `4 σ(-δ)` 在任何有限的 `δ` 上都是正的，似然随 `δ` 一直上升。这个数据集没有有限的极大似然：模型只被要求把拒绝的奖励差推到 `+∞`。三次对一次才把 `δ` 钉在 `ln 3`。

## 带 KL 约束的策略目标

奖励模型有了之后，策略 `π_θ` 要提高 `r`，同时不要离开参考策略 `π_ref`。参考策略在这条流程里通常是 SFT 模型，参数冻结。对一个提示，目标是

```text
J(π) = E_{y ~ π}[ r(x, y) ] - β KL(π(·|x) ‖ π_ref(·|x))
```

`β > 0`。KL 用 [开篇](01-Token与下一个词.md) 的定义，展开后是 `Σ_y π(y) ln(π(y) / π_ref(y))`。`β` 越大，离开参考策略的代价越高。

把回答集合暂时看成有限的，目标写成求和：

```text
J(π) = Σ_y π(y) r(y) - β Σ_y π(y) ln π(y) + β Σ_y π(y) ln π_ref(y)
```

`π ln π` 对 `π` 的导数是 `ln π + 1`。对某一个 `π(y)` 求导：

```text
∂J/∂π(y) = r(y) - β ln(π(y) / π_ref(y)) - β
```

概率和为 1 时，这个偏导在每个 `y` 上等于同一个常数 `c`：

```text
r(y) - β ln(π(y) / π_ref(y)) - β = c
ln(π(y) / π_ref(y)) = r(y) / β - 1 - c / β
```

`exp(-1 - c/β)` 对所有回答相同，收进归一化常数：

```text
π(y|x) = π_ref(y|x) exp(r(x, y) / β) / Z(x)
Z(x) = Σ_y π_ref(y|x) exp(r(x, y) / β)
```

反解奖励：

```text
r(x, y) = β ln(π(y|x) / π_ref(y|x)) + β ln Z(x)
```

`Z(x)` 只依赖提示。两个回答相减时，`β ln Z(x)` 消失，剩下的是两条对数概率比的差。词表上的 `Z(x)` 是对所有可能回答求和，训练时不算它。下面的两点分布小到可以把 `Z` 直接写出来，用来核对这个闭式。

序列的对数概率是 token 对数概率之和，所以

```text
ln(π(y|x) / π_ref(y|x)) = Σ_t ln(π(y_t | x, y_<t) / π_ref(y_t | x, y_<t))
```

把每一项 token 上的 `β ln(π / π_ref)` 加起来，就是整段的 `β ln(π(y|x) / π_ref(y|x))`。Ouyang 等两处都写了：惩罚加在每个 token 上，目标函数里又写成整段的这一个和。总和相同，信用分配不同。他们的完整目标还有一项，`γ` 乘预训练分布上的 `ln π(x)`。`γ = 0` 就是上面的 `J`。`γ > 0` 的版本他们称为 PPO-ptx。本篇的数都取 `γ = 0`。用成对偏好训练奖励再优化策略，来自 Christiano 等。把 KL 惩罚写进语言模型微调，Ziegler 等和 Stiennon 等已经这样做。

### 两点分布上的最优策略

回答只有两种，参考策略各给 `1/2`。这是一个教学分布，不是某个语言模型的词表。

| 回答 | 参考概率 | 代理奖励 | 真实奖励 |
| --- | --- | --- | --- |
| 正确 | `1/2` | 1 | 1 |
| 套话 | `1/2` | 3 | 0 |

代理奖励是奖励模型的分数。真实奖励只看对错。套话在代理里多拿 2 分，在真实奖励里是 0。`β = 1` 时，

```text
π(套话) / π(正确) = exp((3 - 1) / β) = e^2
π(套话) = e^2 / (e^2 + 1) = σ(2) ≈ 0.8808
π(正确) = 1 / (e^2 + 1) = σ(-2) ≈ 0.1192
```

参考策略均匀，所以最优概率正好是奖励差的 sigmoid。期望是

```text
代理奖励：1 * σ(-2) + 3 * σ(2) = 1 + 2 σ(2) ≈ 2.7616
真实奖励：σ(-2) ≈ 0.1192
```

参考策略自己的期望：代理奖励 `(1 + 3) / 2 = 2`，真实奖励 `1/2`。最优策略把代理奖励从 2 提高到约 `2.7616`，把真实奖励从 `0.5` 降到约 `0.1192`。

KL 和目标：

```text
KL = ln 2 + σ(2) ln σ(2) + σ(-2) ln σ(-2) ≈ 0.3278
J = 2.7616 - 0.3278 ≈ 2.4338
```

若把全部质量放在套话上，代理奖励是 3，KL 是 `ln 2`，目标是 `3 - ln 2 ≈ 2.3069`，低于 `2.4338`。单点并不是这个 `β` 下的最优。

`β = 4` 时，奖励差除以 `β` 是 `0.5`，套话的概率变成 `σ(0.5) ≈ 0.6225`，正确的概率约 `0.3775`，代理奖励期望约 `2.2449`。真实奖励升到约 `0.3775`，仍低于参考策略的 `0.5`。`β` 决定最优策略往套话走多远，不把代理奖励改写成真实奖励。

## PPO 裁剪的是另一个比

近端策略优化（proximal policy optimization，PPO）用来爬上面这个目标。它不计算 `Z(x)`。采样用的是旧策略 `π_old`，也就是这一批样本采出来时的参数。Schulman 等把概率比写成

```text
ρ = π_θ(a|s) / π_old(a|s)
```

论文里的记号是 `r_t(θ)`。这里用 `ρ`，把 `r` 留给奖励。优势（advantage）`Â` 估计的是：这个动作比基线好多少。`Â > 0` 时，提高它的概率会提高替代目标。裁剪目标是

```text
L = min( ρ Â,  clip(ρ, 1-ε, 1+ε) Â )
```

Schulman 等把 `ε = 0.2` 当作例子。下面用这个值，`Â` 先取 `+1`，再取 `-1`。`clip` 把 `ρ` 限制在 `[0.8, 1.2]`。

| `ρ` | `Â` | `ρ Â` | `clip(ρ) Â` | `min` |
| --- | --- | --- | --- | --- |
| 1.5 | +1 | 1.5 | 1.2 | 1.2 |
| 0.5 | +1 | 0.5 | 0.8 | 0.5 |
| 1.5 | -1 | -1.5 | -1.2 | -1.5 |
| 0.5 | -1 | -0.5 | -0.8 | -0.8 |

`Â > 0` 且 `ρ = 1.5` 时，未裁剪的项是 1.5，裁剪后的项是 1.2，`min` 留下 1.2。概率比再往上抬，替代目标也不增加。`Â < 0` 且 `ρ = 0.5` 时，未裁剪的项是 `-0.5`，裁剪后是 `-0.8`，`min` 留下 `-0.8`。概率比再往下降，替代目标也不增加。`Â > 0` 且 `ρ` 已经小于 `0.8` 时，`min` 留下更小的未裁剪项：裁剪没有把这一步的惩罚抹掉。

`ρ` 比较的是当前策略和采样策略。KL 惩罚比较的是当前策略和参考策略。第一次更新时，`π_old` 可以就是 `π_ref`，两个比重合。下一次采样之后就分开了。设这一步相对旧策略的对数概率差是 `0.1`，相对参考策略的对数概率差已经是 `1.5`：

```text
π_θ / π_old = exp(0.1) ≈ 1.1052
π_θ / π_ref = exp(1.5) ≈ 4.4817
```

`1.1052` 落在 `[0.8, 1.2]` 里，这一项的裁剪不起作用。KL 项仍然是 `β * 1.5`。`β = 0.1` 时，惩罚是 `0.15`。裁剪限制的是同一次采样上的步长。KL 惩罚累计的是离开 SFT 的距离。

实现里送进 PPO 的标量奖励通常已经减去 KL 项：

```text
r_shaped = r(x, y) - β (ln π_θ(y|x) - ln π_ref(y|x))
```

一条靠近参考策略的回答：`r = 1`，对数概率比是 0，塑形后仍是 1。一条参考策略几乎不产生的回答：`ln π_θ = -1`，`ln π_ref = -8`，对数概率比是 7，奖励模型给了 `r = 2`。

```text
β = 0.1：  2 - 0.1 * 7 = 1.3
β = 0.2：  2 - 0.2 * 7 = 0.6
```

`β = 0.1` 时，远处的 2 分在扣掉 0.7 之后仍高于近处的 1。`β = 0.2` 时，塑形后是 0.6，近处的回答更高。奖励模型在 `ln π_ref = -8` 的区域几乎没有比较数据可拟合，那个 2 是外推。`β` 决定这段外推要付多少 KL。

Ouyang 等还把价值函数从奖励模型初始化，用来估计 `Â`。价值函数的拟合不在本篇手算。

## 从最优策略反解出 DPO

把闭式里的 `r` 代回 Bradley-Terry。`β ln Z(x)` 在两答相减时消去：

```text
P(y_w 优于 y_l | x) = σ( β ln(π(y_w)/π_ref(y_w)) - β ln(π(y_l)/π_ref(y_l)) )
```

右边只剩策略和参考模型。DPO 把未知的最优策略换成正在训练的 `π_θ`，然后对观察到的偏好做极大似然。一条样本的损失是

```text
h = β [ (ln π_θ(y_w) - ln π_ref(y_w)) - (ln π_θ(y_l) - ln π_ref(y_l)) ]
L = -ln σ(h)
```

`π_ref` 不更新。训练时要拿到它在这两条回答上的对数概率，可以留着一份冻结的参数，也可以在进优化器之前把这两个数存下来。Rafailov 等在有 SFT 模型时把 `π_ref` 设成它。没有 SFT 时，他们先在被偏好的回答上做一次极大似然，用那个模型当参考。

隐式奖励 `r̂(x, y) = β ln(π_θ(y|x) / π_ref(y|x))` 是等价类里把 `β ln Z(x)` 定成 0 的那一个代表。同一个奖励差可以加上任意的 `f(x)`，Bradley-Terry 概率和 KL 约束下的最优策略都不变。DPO 没有再训练一个单独的标量头。

损失对 `h` 的导数是 `-σ(-h)`。对参数来说，梯度里 `∇ ln π_θ(y_w) - ∇ ln π_θ(y_l)` 前面的系数是 `-β σ(-h)`。权重 `σ(-h) = σ(r̂(y_l) - r̂(y_w))`：当前隐式奖励把败者排得越高，这条样本对参数的推力越大。`h` 已经是很大的正数时，权重接近 0，这条已经排对的样本几乎不再推。

### 一对回答的对数概率

两条回答各有两个 token。表内是 ln。

| 模型 | 回答 | 两个 token | 序列 |
| --- | --- | --- | --- |
| `π_θ` | `y_w` | -0.5，-0.5 | -1 |
| `π_θ` | `y_l` | -1.5，-2.5 | -4 |
| `π_ref` | `y_w` | -1，-1 | -2 |
| `π_ref` | `y_l` | -1，-2 | -3 |

`β = 1`：

```text
ln π_θ(y_w) - ln π_ref(y_w) = -1 - (-2) = 1
ln π_θ(y_l) - ln π_ref(y_l) = -4 - (-3) = -1
h = 1 - (-1) = 2
P = σ(2) ≈ 0.8808
L = -ln σ(2) ≈ 0.1269
权重 σ(-2) ≈ 0.1192
```

策略已经把胜者的对数概率比放在 `1`、败者放在 `-1`。权重只有约 `0.1192`，这条样本的梯度较小。

`β = 0.5` 时，同样的对数概率比只贡献 `h = 1`。`σ(1) ≈ 0.7311`，损失 `-ln σ(1) ≈ 0.3133`。`β` 把间隔成比例缩小，偏好概率更接近 `1/2`，损失变大。

两个序列概率是 `e^{-1}` 和 `e^{-4}`，加起来远小于 1。词表里还有很多别的回答。DPO 用的就是这两个序列对数概率。只把 `π_θ` 的两条重新归一化，等于给这两条对数概率加上同一个常数，相减时消掉，`h` 恰好不变。这个消项不依赖长度。会改变 `h` 的算法是改用每条序列的平均：平均把和除以长度。本例两条长度都是 2，间隔从 2 变成 1。长度不同时，两条除数不同，间隔也不再是把原来的差除以一个公共长度。

丢掉参考模型，间隔变成策略自己的差：

```text
h_无参考 = -1 - (-4) = 3
σ(3) ≈ 0.9526
损失 ≈ 0.0486
```

参考模型自己就更偏向 `y_w`：`-2 - (-3) = 1`。策略的差是 3，其中 1 已经存在于参考模型里，超出参考的部分是 2。丢掉参考模型，会把参考里原有的偏好算成策略新学到的间隔。

用每个序列的平均代替求和，等于把间隔除以长度 2：

```text
θ 的平均：-0.5 和 -2
参考的平均：-1 和 -1.5
h_平均 = (-0.5 - (-1)) - (-2 - (-1.5)) = 1
损失 = -ln σ(1) ≈ 0.3133
```

两条回答一样长，所以只是缩小了 `β` 的效果。长度不同时，更长的回答在平均里被稀释，间隔不再是 token 对数概率之和。

把策略的序列对数概率换成 `y_w = -3`、`y_l = -2`，参考模型仍是 `-2` 和 `-3`：

```text
ln π_θ(y_w) - ln π_ref(y_w) = -3 - (-2) = -1
ln π_θ(y_l) - ln π_ref(y_l) = -2 - (-3) = 1
h = -1 - 1 = -2
P = σ(-2) ≈ 0.1192
L = -ln σ(-2) ≈ 2.1269
权重 = σ(2) ≈ 0.8808
```

`-ln σ(-h) = h + (-ln σ(h))`。`h` 从 2 变成 -2 时，损失从约 `0.1269` 增加到约 `2.1269`，差正好是 2。权重从约 `0.1192` 升到约 `0.8808`：排反了的样本推得更重。

## 三种失效用的是上面的数

奖励投机（reward hacking）是代理奖励和真实奖励不是同一个函数。两点分布里，`β = 1` 的最优策略把代理期望从 2 提高到约 `2.7616`，真实期望从 `0.5` 降到约 `0.1192`。策略没有算错 KL 约束下的最优；被最大化的那个 `r` 把套话打得太高。Gao、Schulman 和 Hilton 用一个固定的金标准奖励模型代替人类，训练代理奖励再去优化它，观察到代理被优化得过狠时金标准分数变差。他们的曲线依赖模型和 KL 预算。本篇的 `2.7616` 和 `0.1192` 只属于这个两点分布。

过度拒答（over-refusal）是偏好标签把「拒绝」定义成更好，而另一个标准认为这个提示应当得到回答。四次比较的极大似然是 `δ = ln 3`，拒绝获胜的概率是 `3/4`。参考策略若在「拒绝」和「回答」上各给 `1/2`，`β = 1`，最优策略拒绝的概率也是 `σ(ln 3) = 3/4`。每次都取奖励更高的那一条，则会一直拒绝。提示可以是「光合作用怎样进行」。模型拟合的是这四次标签，不是另一套「这个提问是否允许」的规则。Ouyang 等观察到他们的模型会对简单问题过度含糊，并怀疑这与标注说明里奖励认知上的谦逊有关：奖励模型把含糊也当成了高奖励的特征。

分布偏移（distribution shift）是奖励模型的比较数据来自参考策略附近，策略后来走到了别处。`ln π_ref = -8` 的那条回答，`β = 0.1` 时塑形奖励是 `1.3`，高于近处回答的 `1`；`β = 0.2` 时是 `0.6`，低于 1。KL 项是按对数概率比计价，不是一份「奖励模型在这里仍然准」的证明。比较数据没有覆盖到的区域，标量 `r` 可以任意外推，直到 `β` 把这笔外推扣掉。

这三件事可以同时出现：标签把拒绝标成更好，奖励模型又给某种套话加分，策略再走进参考模型很少产生的区域。分开算，是为了看到每一项改的是哪一个数。

## 参考代码

序列对数概率是求和。DPO 的损失是 `-ln σ(h)`。

```python
import math


def sigmoid(value: float) -> float:
    return 1.0 / (1.0 + math.exp(-value))


def dpo_margin(
    logp_w: float,
    logp_l: float,
    logp_ref_w: float,
    logp_ref_l: float,
    beta: float,
) -> float:
    return beta * ((logp_w - logp_ref_w) - (logp_l - logp_ref_l))


def dpo_loss(margin: float) -> float:
    return -math.log(sigmoid(margin))
```

## 容易算错的地方

- SFT 的分母是回答上被监督的 token。提示概率 `0.9` 加进去，平均从约 `0.5697` 降到约 `0.4149`。
- 奖励同时加一个常数，Bradley-Terry 概率不变。`(1, -1)` 和 `(6, 4)` 都是 `σ(2)`。
- 四次全部偏好同一边时，似然随奖励差单调上升，没有有限的极大似然。三次对一次才得到 `ln 3`。
- DPO 用序列对数概率的和。这个例子里改成平均，`h` 从 2 变成 1，损失从约 `0.1269` 变成约 `0.3133`。
- 丢掉参考模型，`h` 从 2 变成 3。参考模型原有的对数概率差是 1，被算进了策略。
- PPO 的 `ρ` 相对 `π_old`。KL 相对 `π_ref`。`exp(0.1) ≈ 1.1052` 可以落在裁剪区间内，同时 `exp(1.5) ≈ 4.4817` 已经离开参考策略。
- 代理奖励的最优可以降低真实奖励。`β = 1` 时真实期望约 `0.1192`，参考策略是 `0.5`。

## 练习

### 练习 1：提示进了分母

- 目标：平均的分母决定这个数在衡量谁。
- 限制：纸笔或计算器。用 ln。
- 题面：回答两项的概率是 `0.4` 和 `0.8`。只对这两项平均，NLL 约是多少？再加入概率 `0.9` 的提示目标，三项平均约是多少？
- 完成标准：约 `0.5697` 和约 `0.4149`。

<details>
<summary>参考解答</summary>

`(-ln 0.4 - ln 0.8) / 2 ≈ 0.5697`。三项是 `(-ln 0.9 - ln 0.4 - ln 0.8) / 3 ≈ 0.4149`。脚本 `check_alignment` 复核。

</details>

### 练习 2：同一个奖励差

- 目标：Bradley-Terry 只看差。
- 限制：纸笔。
- 题面：`(r_w, r_l)` 先取 `(1, -1)`，再取 `(6, 4)`。两种情况的偏好概率和损失各约是多少？
- 完成标准：都是 `σ(2) ≈ 0.8808`，损失约 `0.1269`。

<details>
<summary>参考解答</summary>

两种差都是 2。`σ(2) = 1/(1+e^{-2})`，`-ln σ(2) = ln(1+e^{-2})`。

</details>

### 练习 3：三次拒绝，一次回答

- 目标：极大似然的胜率等于样本比例。
- 限制：纸笔。
- 题面：四次比较，三次拒绝获胜。`δ` 是多少？`σ(δ)` 是多少？四次损失的平均约是多少？若改成四次全部拒绝获胜，有限的极大似然在哪里？
- 完成标准：`δ = ln 3 ≈ 1.0986`，概率 `3/4`，平均损失约 `0.5623`。四次全胜时没有有限的极大似然。

<details>
<summary>参考解答</summary>

导数 `3 - 4σ(δ) = 0` 给出 `σ(δ) = 3/4`，`δ = ln 3`。平均损失是 `-(3 ln(3/4) + ln(1/4)) / 4`。四次全胜的导数 `4 σ(-δ)` 恒正。

</details>

### 练习 4：把 DPO 的间隔算完

- 目标：序列对数概率先求和，再进入 `h`。
- 限制：纸笔。用正文的四行对数概率，`β = 1`。
- 题面：四条序列对数概率是多少？`h`、偏好概率、损失、梯度权重各约是多少？
- 完成标准：`-1, -4, -2, -3`。`h = 2`，概率约 `0.8808`，损失约 `0.1269`，权重约 `0.1192`。

<details>
<summary>参考解答</summary>

`-0.5-0.5 = -1`，`-1.5-2.5 = -4`，`-1-1 = -2`，`-1-2 = -3`。两个对数概率比是 `1` 和 `-1`，差是 2。权重是 `σ(-2)`。

</details>

### 练习 5：参考模型和平均长度

- 目标：间隔里的两项都要在。
- 限制：纸笔。仍用练习 4 的表。
- 题面：丢掉参考模型时 `h` 是多少，损失约是多少？改用每条序列的 token 平均时 `h` 是多少，损失约是多少？`β = 0.5` 而仍用求和时，`h` 和损失呢？
- 完成标准：`h = 3`，损失约 `0.0486`；`h = 1`，损失约 `0.3133`；`β = 0.5` 时 `h = 1`，损失仍约 `0.3133`。

<details>
<summary>参考解答</summary>

策略自己的差是 `-1 - (-4) = 3`。token 平均把每个和除以 2，间隔变成 1。`β = 0.5` 乘在原来的差 2 上，也得到 1。两种算法不同，这个例子里的 `h` 数值相同。

</details>

### 练习 6：间隔取反

- 目标：排反的样本损失更高，权重更大。
- 限制：纸笔。参考模型仍是 `-2` 和 `-3`，`β = 1`。
- 题面：策略的序列对数概率改成 `y_w = -3`、`y_l = -2`。`h`、损失和权重各约是多少？损失比 `h = 2` 时大多少？
- 完成标准：`h = -2`，损失约 `2.1269`，权重约 `0.8808`。损失大约增加 2。

<details>
<summary>参考解答</summary>

`(-3-(-2)) - (-2-(-3)) = -2`。`-ln σ(-2) = 2 + (-ln σ(2))`，所以比原来的损失大 2。权重是 `σ(2)`。

</details>

### 练习 7：裁剪之后留下哪一个

- 目标：`min` 用的是裁剪后不再变好的那一侧。
- 限制：纸笔。`ε = 0.2`。
- 题面：`ρ = 1.5` 且 `Â = 1`，替代目标是多少？`ρ = 0.5` 且 `Â = -1`，替代目标是多少？`exp(0.1)` 是否落在 `[0.8, 1.2]` 里？
- 完成标准：`1.2` 和 `-0.8`。`exp(0.1) ≈ 1.1052`，落在区间里。

<details>
<summary>参考解答</summary>

`clip(1.5) = 1.2`，`min(1.5, 1.2) = 1.2`。`clip(0.5) = 0.8`，两项是 `-0.5` 和 `-0.8`，`min` 是 `-0.8`。`e^{0.1}` 介于 0.8 和 1.2 之间。

</details>

### 练习 8：代理上升、真实下降

- 目标：KL 约束下的最优仍可能压低真实奖励。
- 限制：纸笔。用正文的两点分布。
- 题面：`β = 1` 时，套话的概率、代理奖励期望、真实奖励期望各约是多少？全部质量放在套话上时目标约是多少，为什么它不是最优？`β = 4` 时真实奖励期望约是多少？远处那条回答在 `β = 0.1` 和 `β = 0.2` 时的塑形奖励是多少？
- 完成标准：约 `0.8808`、`2.7616`、`0.1192`。单点目标约 `2.3069`，低于约 `2.4338`。`β = 4` 时真实期望约 `0.3775`。塑形奖励是 `1.3` 和 `0.6`。

<details>
<summary>参考解答</summary>

`β = 1` 时套话概率是 `σ(2)`，代理期望是 `1 + 2σ(2)`，真实期望是 `σ(-2)`。单点的目标是 `3 - ln 2`。`β = 4` 时套话概率是 `σ(0.5)`，真实期望是 `1 - σ(0.5)`。远处回答是 `2 - 0.7` 和 `2 - 1.4`。

</details>

## 本篇之外

评估指标、检索和智能体按路线图在后面。奖励模型怎样在一批排序上做一次前向、PPO 的价值函数怎样拟合、以及 `γ` 那一项对公开 NLP 任务的影响，以 Ouyang 等的实验设定为准，不在本篇手算。本篇的 sigmoid、DPO 间隔、裁剪和两点分布由 `check_alignment` 复核。
