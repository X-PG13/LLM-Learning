## 本篇要回答的问题

1. 和 Vaswani 等 2017 的解码器图相比，现在常见的 decoder-only 一块里，归一化的位置、编码器、前馈和注意力头各变成了什么？哪些部分还在？
2. RoPE 怎样用旋转把位置写进 query 和 key，使点积只依赖相对位移？偶奇维、转角，以及是否旋转 value，本篇用的是哪一套？
3. RMSNorm 放在前置残差的哪一侧？子层读到的向量，和加回残差的向量，各在归一化的哪一边？
4. SwiGLU 的门、值、逐元素积和输出投影各是哪一次线性？中间维怎样取得和两层 ReLU 前馈相近的参数量？
5. GQA 里几个 query 头共享一个 key/value 头？MHA 和 MQA 是哪两个端点？缓存字节和 KV 投影的参数差在哪一个因子上？

## 和 2017 年的解码器图对照

2017 年的解码器一块有三个子层，归一化在残差加法之后。`memory` 是编码器的输出。

```text
h = LayerNorm(x + Dropout(MaskedSelfAttn(x)))
c = LayerNorm(h + Dropout(CrossAttn(h, memory)))
y = LayerNorm(c + Dropout(FFN(c)))
```

前馈是两层线性变换，中间是 ReLU，宽度常取 `4 d_model`。位置信息加在嵌入上，正弦公式在自注意力那一篇。每个注意力头有自己的 query、key、value。

LLaMA 这一路的 decoder-only 块去掉编码器，因此没有交叉注意力。归一化挪到子层的输入上，函数换成 RMSNorm。LLaMA 论文第 2.2 节把「归一化放在子层输入」记为来自 GPT-3，把 RMSNorm、SwiGLU、RoPE 分别记为来自 Zhang 与 Sennrich、Shazeer、Su 等。本篇的手算按 Dropout 为 0，线性层不含偏置。很多这一路的预训练也不使用 Dropout。

```text
h = x + SelfAttn(RMSNorm(x))
y = h + SwiGLU(RMSNorm(h))
```

自注意力仍是缩放点积、softmax 和因果掩码。q 和 k 在点积之前按本篇的 RoPE 旋转。key/value 头可以少于 query 头，那是 GQA。嵌入不再加上正弦位置向量；位置在每一层的 q、k 上重新写一次。栈的最后一块出来之后，再做一次 RMSNorm，然后投影到词表。这一次没有残差加回来。

还在的部分：每个子层外面有残差，宽度是 `d_model`；注意力之后仍是逐位置的前馈；输入仍是 token 嵌入，输出仍是词表 logits。损失落在哪些位置，沿用自注意力那一篇接到下一个 token 的约定。

`y = x + f(Norm(x))` 对 `x` 的导数留着一条单位阵。`f` 的导数为 0 时，前置的输出仍是 `x`。后置把这条单位阵乘进归一化的雅可比。推导在 [激活、初始化与归一化](../05-深度学习/03-激活初始化与归一化.md)。Xiong 等比较过前后置对训练的影响。本篇只核对手算得到的两个向量。

## RoPE

约定先写死，后面的数都按这一套。

头维 `d = d_k` 是偶数。坐标按相邻的偶奇配对：第 `2i` 维和第 `2i+1` 维是第 `i` 个平面，`i` 从 0 计，和正弦位置里的 `i` 相同。论文若从 1 计，指数里写的是 `2(i−1)`，数列不变。

```text
θ_i = 10000^(-2i / d)
```

`d = 4` 时，`θ_0 = 10000^0 = 1`，`θ_1 = 10000^(-1/2) = 1/100 = 0.01`。第一对频率和自注意力篇正弦编码的分母是同一组：那里的 `10000^(2i/d_model)` 在 `i = 1`、`d_model = 4` 时也是 100。两篇用的底相同，放进网络的位置不同。正弦编码加在嵌入上；RoPE 不改嵌入，只旋转每一层投影之后的 query 和 key。

位置 `m` 从 0 计。第 `i` 个平面的转角是 `φ = m θ_i`。这一对坐标左乘

```text
| cos φ   -sin φ |
| sin φ    cos φ |
```

也就是

```text
x' = x cos φ - y sin φ
y' = x sin φ + y cos φ
```

把 `(x, y)` 看成复数 `x + i y`，上式就是乘 `cos φ + i sin φ`。只旋转 query 和 key。value 不转。旋转在线性投影之后、缩放点积之前。每个头在自己的 `d_k` 上转，每一层都转。

`R(φ)` 表示上面的 2×2 矩阵。它满足 `R(α)^T = R(−α)`，`R(α) R(β) = R(α+β)`。因此 query 在 `m`、key 在 `n` 时

```text
(R(mθ) q) · (R(nθ) k) = q · R((n-m)θ) k = (R((m-n)θ) q) · k
```

绝对位置只通过差 `m − n` 进入点积。`m = n` 时矩阵变成单位阵，点积回到没旋转的 `q · k`。全维点积是各平面点积之和，每个平面只用自己的 `θ_i`，所以整段点积也只依赖相对位移。因果掩码仍在分数上挡 `j > i`。RoPE 不代替掩码。

### 一个平面，转角取直角

下面这一组把 `θ` 设成 `π/2`，让正弦和余弦落在 `{-1, 0, 1}`。它用来手算相对位移。真实频率仍是上一节的 `10000^(-2i/d)`，第一平面是 `θ_0 = 1`，不是 `π/2`。

未旋转的向量：`q = (1, 0)`，`k = (3, 1)`。二者的点积是 3。象限旋转：

```text
φ = 0        (x, y) → (x, y)
φ = π/2      (x, y) → (−y, x)
φ = π        (x, y) → (−x, −y)
φ = 3π/2     (x, y) → (y, −x)
```

```text
q 在位置 0、1、2：(1, 0)，(0, 1)，(−1, 0)
k 在位置 0、1、2：(3, 1)，(−1, 3)，(−3, −1)
```

相对位移 `m − n = 0`：

```text
位置 0 和 0：(1, 0) · (3, 1) = 3
位置 1 和 1：(0, 1) · (−1, 3) = 3
```

相对位移 `m − n = 1`：

```text
query 在 1、key 在 0：(0, 1) · (3, 1) = 1
query 在 2、key 在 1：(−1, 0) · (−1, 3) = 1
```

相对位移 `m − n = −1`：query 在 0、key 在 1，`(1, 0) · (−1, 3) = −1`。位移为 2 的两对放在练习里。

只把相对转角加在 key 上，应得到同一个 1。`n − m = −1`，转角 `−π/2`，和 `3π/2` 是同一象限：`(3, 1) → (1, −3)`。再和未旋转的 `q` 做点积：`(1, 0) · (1, −3) = 1`。

位移 0 得到 3，位移 1 得到 1，位移 −1 得到 −1。两个位置同时加上同一个整数，点积不变。

手算用 `cos(π/2) = 0`、`sin(π/2) = 1`。浮点里 `cos(π/2)` 约是 `6.12 × 10⁻¹⁷`，不是比特级的 0。核对这组整数时按上面的象限表转，不要调用 `cos(π/2)`。

### 第一对真实频率

`θ = 1`，内容向量仍是 `q = k = (1, 0)`。未旋转的点积是 1。位置 `m` 把 `(1, 0)` 转到 `(cos m, sin m)`。

```text
位置 1：(cos 1, sin 1) ≈ (0.5403, 0.8415)
位置 2：(cos 2, sin 2) ≈ (−0.4161, 0.9093)
```

相对位移都是 1 的两对：

```text
query 在 1、key 在 0：点积 = cos 1 ≈ 0.5403
query 在 2、key 在 1：cos 2 cos 1 + sin 2 sin 1 = cos(2−1) = cos 1
```

用已经收成四位的 `cos 2`、`sin 2`、`cos 1`、`sin 1` 再乘，得到约 `0.5404`。核对以未舍入的正弦余弦为准，四位小数只用于阅读。自注意力篇里 `PE(1) ≈ (sin 1, cos 1)`，和这里位置 1 的 `(cos 1, sin 1)` 是同一对函数值，坐标顺序不同，而且一个加在嵌入上，一个是旋转。

`d = 4` 的两个平面，位置 1，输入 `(1, 0, 1, 0)`。第一平面转 1 弧度，第二平面转 0.01 弧度：

```text
(cos 1, sin 1, cos 0.01, sin 0.01) ≈ (0.5403, 0.8415, 0.999950, 0.0100)
```

`cos 0.01` 保留六位，避免收成 `1.0000`。`sin 0.01` 保留四位，和正弦位置那一篇同一组角。第二平面几乎没转。点积把两个平面加在一起，慢的那一对对近距离不敏感，快的那一对随相对位移变号。

## RMSNorm 在前置残差里

公式不在这里重推。`ε = 0`、通常没有 `β`：

```text
RMS(x) = sqrt( (1/n) Σ x_i² )
y_i = γ_i * x_i / RMS(x)
```

`(1, 3, 5)` 上和 LayerNorm 的对照，以及 PyTorch 不传 `ε` 时用浮点机器精度，见 [激活、初始化与归一化](../05-深度学习/03-激活初始化与归一化.md)。本篇只把这个 `y` 放进残差的顺序里。手算取 `ε = 0`。和默认实现对数字之前，先把 `ε` 对齐。

一块里注意力子层的顺序是：先 RMSNorm，子层只读归一化后的向量，再加回没归一化的 `x`。前馈子层对 `h` 重复这三步。下面用一个 2 维线性层代替子层，好让加法项也随输入变化。自注意力篇里的常数子层不看输入，两种结构相加的向量相同。这里的 `W` 会看输入，相加的向量本身就不同。

`x = (1, 3)`，`γ = (1, 1)`。`W` 的形状是 `(2, 2)`，两行是 `(1, 1)` 和 `(0, 1)`，`y = x @ W.T`。

```text
RMS = sqrt( (1 + 9) / 2 ) = sqrt(5) ≈ 2.236068
u = (1/sqrt(5), 3/sqrt(5)) ≈ (0.447214, 1.341641)
a = u @ W.T = (4/sqrt(5), 3/sqrt(5)) ≈ (1.788854, 1.341641)
h = x + a = (1 + 4/sqrt(5), 3 + 3/sqrt(5)) ≈ (2.788854, 4.341641)
```

同一张 `W` 若走后置：子层读的是 `x`，加法之后再 RMSNorm。

```text
x @ W.T = (4, 3)
和 = (5, 6)
RMS = sqrt( (25 + 36) / 2 ) = sqrt(61/2) ≈ 5.522681
后置 = (5, 6) / RMS ≈ (0.905357, 1.086429)
```

前置得到约 `(2.788854, 4.341641)`，后置得到约 `(0.905357, 1.086429)`。子层若输出 0，前置的 `h` 仍是 `(1, 3)`，后置的结果是 `RMSNorm(1, 3)`。

`γ = (2, 1)` 时，送进子层的向量是 `(2/sqrt(5), 3/sqrt(5)) ≈ (0.894427, 1.341641)`。上面的 `h` 仍用 `γ = 1`。把这个 `γ` 乘进残差是练习。末尾那一次 RMSNorm 包的是最后一块的输出，没有 `x +` 在外面。

## SwiGLU

2017 年的前馈是 `ReLU(x W_1) W_2`，两块矩阵。SwiGLU 用三块，门是 SiLU。SiLU 就是 `z * σ(z)`，`z = 2` 时的值在激活篇。本篇的形状按行向量：

```text
gate = SiLU(x @ W_gate.T)     # W_gate 是 (d_ff, d_model)
up   = x @ W_up.T             # W_up   是 (d_ff, d_model)
y    = (gate ⊙ up) @ W_down.T # W_down 是 (d_model, d_ff)
```

没有偏置。`⊙` 是逐元素乘。值这一支对 `x` 是线性的，非线性在门上。门接近 0 的坐标把对应的值压下去。SiLU 在负半轴不是 0，所以负的门预激活仍留下一个负因子，不会像 ReLU 那样把这一维乘成 0。GLU 家族里把门换成 sigmoid 或 GELU，得到的是 GLU 和 GEGLU。本篇只算 SwiGLU。

有的实现把 `W_gate` 和 `W_up` 拼成一次矩阵乘，再沿输出维切开。先切开的是门还是值，要和权重的行对应。切反了，SiLU 会打在值那一支上。

手算把中间维收到 2，只为能在纸上乘完。宽度规则在下一节。

```text
x = (1, −2)

W_gate = | 1  0 |     W_up = | 1  1 |     W_down = | 1  0 |
         | 0  1 |            | 1  0 |              | 1  1 |
```

```text
门的预激活 = (1, −2)
SiLU(1) = 1 / (1 + exp(−1)) ≈ 0.731059
SiLU(−2) = −2 / (1 + exp(2)) ≈ −0.238406
值 = (1 − 2, 1) = (−1, 1)
逐元素积 = (−SiLU(1), SiLU(−2)) ≈ (−0.731059, −0.238406)
输出 = (−SiLU(1), −SiLU(1) + SiLU(−2))
     ≈ (−0.731059, −0.969464)
```

用已经收成六位的逐元素积再相加，第二维是 `−0.969465`。差 `0.000001` 是舍入。核对以未舍入的 `exp` 为准。

负的门留下 `−0.238406`，没有被截成 0。它再乘值的 `1`，符号进入输出的第二维。

### 中间维和参数量

两层 ReLU 前馈、`d_ff = 4 d_model`、无偏置，参数是 `8 d_model²`。`d_model = 512` 时是 `2_097_152`，自注意力篇已经算过。

SwiGLU 是 `3 d_model d_ff`。中间维仍取 `4 d_model` 时，`d_model = 512` 的三块矩阵是 `3 * 512 * 2048 = 3_145_728`，等于两层前馈的 `3/2`。

LLaMA 把中间维写成 `(2/3) · 4d`，也就是 `8d/3`。三块矩阵的参数回到 `3 d (8d/3) = 8 d²`。`d = 512` 时 `8 * 512 / 3 = 4096/3`，不是整数。手算先整除：

```text
(8 * 512) // 3 = 1365
3 * 512 * 1365 = 2_096_640
```

精确的 `8 d²` 是 `2_097_152`。整除丢掉不到 1 的中间维，参数少 `3 * 512 * (1/3) = 512`。

有的实现还把中间维向上取到 256 的倍数。256 是对齐宽度，不是另一条缩放定律。`1365 = 5 * 256 + 85`，进位

```text
1365 + 256 − 85 = 1536
3 * 512 * 1536 = 2_359_296
```

`2_359_296 / 2_097_152 = 9/8`。进位之后比两层 ReLU 前馈多八分之一，因为 1536 比 `4096/3` 大一截。

## GQA

多头注意力（MHA）里，每个 query 头有自己的 key 头和 value 头。分组查询（GQA）把 query 头分成若干组，一组共用一个 key 头和一个 value 头。多查询（MQA）是极端：所有 query 头共用一组 key/value，KV 头数是 1。三者的 query 头数可以相同。变的是 KV 头数。

本篇按连续的组切分。query 头数 `H` 能被 KV 头数 `G` 整除。每组有 `H / G` 个 query 头。组号

```text
g = q_head // (H / G)
```

组 `g` 包含 query 头 `g * (H/G)` 到 `(g+1) * (H/G) − 1`，读 KV 头 `g`。`H = 4`、`G = 2` 时，头 0 和 1 读 KV 头 0，头 2 和 3 读 KV 头 1。用 `q_head % G` 是另一种编号：头 1 会得到 `1 % 2 = 1`，读到另一组。本篇的数不要换成那种编号。

重复 KV 头，只是为了让矩阵乘的头维和 query 头对齐。缓存里存的是重复之前的 `G` 个 key 和 `G` 个 value。key 按它第一次出现的位置做完 RoPE 再留下；value 不旋转。下一步新 token 只旋转自己的 q 和 k。旧 key 再乘一次 `R`，就转了两次。

### 两个 query 头读同一组 KV

`d_k = 1`，缩放因子 `sqrt(1) = 1`。`H = 4`，`G = 2`。只算位置 1，因果掩码留下位置 0 和 1。三个头够看分组：头 0 和头 1 共用 KV，头 2 读另一组。

```text
KV 头 0：位置 0 的 k=1、v=4；位置 1 的 k=0、v=2
KV 头 1：位置 0 的 k=2、v=1；位置 1 的 k=0、v=5

query 头 0：q=1，组 0
query 头 1：q=0，组 0
query 头 2：q=1，组 1
```

头 0 的分数是 `(1, 0)`。`softmax(z, 0) = (σ(z), σ(−z))`。

```text
权重 ≈ (0.731059, 0.268941)
输出 ≈ 3.462117
```

用六位权重再乘，得到 `3.462118`。核对以未舍入的 softmax 为准。`σ(1) ≈ 0.731059` 就是 SwiGLU 那一节的 `SiLU(1)`，因为那里的预激活是 1，SiLU 比 sigmoid 多乘了这个 1。

头 1 的分数是 `(0, 0)`，权重各 `1/2`，输出 `(1/2)*4 + (1/2)*2 = 3`。同一组 KV，query 不同，输出不同。

头 2 的分数是 `(2, 0)`。`σ(2) ≈ 0.880797`，和激活篇里的 sigmoid 是同一个数。

```text
权重 ≈ (0.880797, 0.119203)
输出 ≈ 1.476812
```

头 2 读的是 KV 头 1，里面没有 KV 头 0 的 `v = 4`。分组决定和谁做点积、对谁加权。query 头数仍是 4。

### 参数和缓存字节

另一组形状，用来对参数和字节。`d_model = 8`，`H = 4`，`d_k = d_v = 2`，于是 `H * d_k = d_model`。无偏置。`W_Q` 和 `W_O` 仍各是 `8 * 8 = 64`。`W_K` 和 `W_V` 的列数是 `G * d_k`。

| 做法 | `G` | `W_K` 或 `W_V` | 四个矩阵合计 |
| --- | --- | --- | --- |
| MHA | 4 | 64 | 256 |
| GQA | 2 | 32 | 192 |
| MQA | 1 | 16 | 160 |

MHA 的 256 就是 `4 d_model²`。GQA 少掉的是两块 KV 投影，少 `2 * 8 * (8 − 4) = 64`，256 变成 192。MQA 再少 `2 * 8 * (4 − 2) = 32`，192 变成 160。

缓存字节沿用推理优化里的公式：层数、key 与 value 的 2、KV 头数、头维、分配的位置数、批量、每元素字节数，乘在一起。这里取 1 层、头维 2、分配 4 个位置、批量 1、每元素 2 字节：

```text
字节数 = 1 × 2 × G × 2 × 4 × 1 × 2 = 32 G
```

MHA、GQA、MQA 是 `128`、`64`、`32` 字节。比就是 `4 : 2 : 1`，等于 KV 头数之比。query 头数 4 不进这张账。Mistral 7B 表 1 那种 32 层、8 个 KV 头的 GiB 数，在 [推理优化](../07-系统工程/02-推理优化.md)。本篇的 128 字节只核对因子，不代替那一笔服务端的账。

## 参考代码

`theta[i]` 是第 `i` 个平面每前进一个位置所转的弧度。`weight` 的每一行是 `(out, in)` 的一行。直角那一组不要走 `rotate_pair(·, π/2)`，走象限表。

```python
import math


def rotate_pair(x0, x1, phi):
    cosine = math.cos(phi)
    sine = math.sin(phi)
    return (x0 * cosine - x1 * sine, x0 * sine + x1 * cosine)


def apply_rope(vec, pos, theta):
    out = []
    for i, angle in enumerate(theta):
        out.extend(rotate_pair(vec[2 * i], vec[2 * i + 1], pos * angle))
    return tuple(out)


def rms_norm(x, gamma=None):
    rms = math.sqrt(sum(v * v for v in x) / len(x))
    y = tuple(v / rms for v in x)
    if gamma is None:
        return y
    return tuple(g * v for g, v in zip(gamma, y))


def linear(x, weight):
    return tuple(sum(x[j] * row[j] for j in range(len(x))) for row in weight)


def silu(z):
    return z / (1.0 + math.exp(-z))


def swiglu(x, w_gate, w_up, w_down):
    gate = tuple(silu(z) for z in linear(x, w_gate))
    up = linear(x, w_up)
    hidden = tuple(g * u for g, u in zip(gate, up))
    return linear(hidden, w_down)


def kv_group(q_head, num_q_heads, num_kv_heads):
    return q_head // (num_q_heads // num_kv_heads)
```

## 容易算错的地方

- 平面配成前一半和后一半。四维 `(a, b, c, d)` 在本篇是 `(a, b)` 与 `(c, d)`。前一半配后一半会把 `(a, c)` 转在一起，同一个向量得到另一组坐标。
- `θ_i` 的 `d` 用了 `d_model`。旋转发生在已经按头切开的 `d_k` 上。
- 位置从 1 计，或把 `θ_0 = 1` 当成角度制。位置 1 的第一平面就是 1 弧度，`sin 1` 不是「1 度的正弦」。
- 调用 `cos(π/2)` 去核对直角那一组。浮点值约是 `6.12 × 10⁻¹⁷`。那一组按象限表，点积是整数 3、1、−1。
- 相对位移为 0 时还去改点积。同一转角乘在 q 和 k 上，点积保持 `q · k`。
- 把 value 也转了，或把已经转过、放进 KV cache 的 key 再转一次。
- 用 RoPE 代替因果掩码。`j > i` 仍要在 softmax 之前挡掉。
- 前置残差里先加再归一化，或给末尾那一次 RMSNorm 又加一条残差。子层输出为 0 时，前置应得到原来的 `x`。
- RMSNorm 减了均值，或把 LayerNorm 的 `ε = 10⁻⁵` 抄过来。同一向量上的两个结果在激活篇。
- SwiGLU 的门用了 ReLU。`SiLU(−2) ≈ −0.238406`，不是 0。
- 三块矩阵仍按 `8 d_model²` 计，同时中间维用了 `4 d_model`。`d_model = 512` 时那是 `3_145_728`，不是 `2_097_152`。进到 256 的倍数之后是 `2_359_296`，也不是 `2_097_152`。
- 拼在一起的 gate/up 切反。SiLU 打在值那一支上，手算的 `(−0.731059, −0.238406)` 对不上。
- 缓存字节乘了 query 头数。上面的小例子里 query 头是 4，字节是 `32 G`，GQA 的 64 不是 128。
- 组号写成 `q_head % G`。`H = 4`、`G = 2` 时，头 1 在本篇是组 0；取余会把它分到组 1。
- 把重复之后的 KV 头再存进缓存。重复只对齐矩阵乘的头维，字节仍按 `G` 计。

## 练习

### 练习 1：直角平面上的四个点积

- 目标：同一相对位移得到同一个点积，位移变了点积才变。
- 限制：纸笔。用象限表，不要调用 `cos(π/2)`。`q = (1, 0)`，`k = (3, 1)`，`θ = π/2`。
- 题面：计算 `(m, n) = (0, 0)`、`(1, 1)`、`(1, 0)`、`(2, 0)` 的点积。再算 `(m, n) = (3, 1)`，说明它和 `(2, 0)` 为什么相同。位置 3 的 `q` 是什么？
- 完成标准：点积依次是 3、3、1、−3，以及 −3。位置 3 的 `q` 是 `(0, −1)`。

<details>
<summary>参考解答</summary>

位置 0 不转，点积是 3。位置 1 的 `q` 是 `(0, 1)`，`k` 是 `(−1, 3)`，点积是 3。query 在 1、key 在 0：`(0, 1) · (3, 1) = 1`。query 在 2：`q = (−1, 0)`，与 key 在 0 的点积是 −3。位置 3 的转角是 `3π/2`，`(1, 0) → (0, −1)`。key 在 1 是 `(−1, 3)`，点积 `−3`。两组的相对位移都是 2。脚本 `check_decoder_structure` 复核。

</details>

### 练习 2：真实频率的两个平面

- 目标：`θ_0 = 1` 的点积收成 `cos 1`，第二平面用 `0.01`。
- 限制：四位小数可以查正弦表。乘完再舍入，不要用四位中间结果回乘。
- 题面：`q = k = (1, 0)`，`θ = 1`。query 在 2、key 在 1 的点积，未舍入时应等于哪个函数值？四位阅读值是多少？若先把四个正弦余弦收成四位再乘，得到哪一个四位小数？`d = 4`、位置 1、输入 `(1, 0, 1, 0)` 时，写出旋转后的四维，第二平面的 `θ` 是多少？
- 完成标准：等于 `cos 1`，约 `0.5403`。四位回乘约 `0.5404`。四维约 `(0.5403, 0.8415, 0.999950, 0.0100)`，`θ_1 = 0.01`。

<details>
<summary>参考解答</summary>

`cos 2 cos 1 + sin 2 sin 1 = cos 1 ≈ 0.5403`。`−0.4161 * 0.5403 + 0.9093 * 0.8415 = 0.54035712`，收到四位是 `0.5404`。第二平面的角度是 `0.01`，`(cos 0.01, sin 0.01)` 按正文的位数书写。

</details>

### 练习 3：前置的 h 和后置的向量

- 目标：子层读取的向量不同，残差的结果就不同。
- 限制：`ε = 0`，`γ = 1`。精确式用 `sqrt(5)` 和 `sqrt(61/2)`，小数保留六位。
- 题面：`x = (1, 3)`，`W` 的两行是 `(1, 1)`、`(0, 1)`。写出前置的 `h`，以及后置 RMSNorm 的结果。`γ = (2, 1)` 时送进子层的向量是什么？仍用这个 `W`，前置的新 `h` 是什么？
- 完成标准：前置约 `(2.788854, 4.341641)`，后置约 `(0.905357, 1.086429)`。`γ` 那条送进子层的是约 `(0.894427, 1.341641)`，新 `h` 约 `(3.236068, 4.341641)`。

<details>
<summary>参考解答</summary>

`u @ W.T = (4/sqrt(5), 3/sqrt(5))`，加回 `(1, 3)` 得正文的 `h`。后置先得到 `(4, 3)`，和是 `(5, 6)`，再除以 `sqrt(61/2)`。`γ` 把第一维乘 2，子层输入是 `(2/sqrt(5), 3/sqrt(5))`。`W` 的输出是 `(sqrt(5), 3/sqrt(5))`，加回 `x` 得 `(1 + sqrt(5), 3 + 3/sqrt(5))`。

</details>

### 练习 4：把 SwiGLU 乘完

- 目标：门、值、逐元素积、输出投影四步都留下数。
- 限制：SiLU 用 `z / (1 + exp(−z))`。六位小数在最后一步舍入。
- 题面：按正文的 `x`、三块 `W`，写出 SiLU、值、逐元素积和输出。用六位逐元素积相加时，输出第二维变成多少？`d_model = 512` 时，中间维先整除、再进到 256 的倍数，三块矩阵各有多少参数？两层 ReLU 前馈的 `2_097_152` 和进位后的数成什么比？
- 完成标准：SiLU 约 `(0.731059, −0.238406)`，值 `(−1, 1)`，逐元素积约 `(−0.731059, −0.238406)`，输出约 `(−0.731059, −0.969464)`。六位相加得到 `−0.969465`。参数 `2_096_640` 和 `2_359_296`，比是 `9/8`。

<details>
<summary>参考解答</summary>

值的第一维是 `1 + (−2) = −1`，门的第二维是负的，乘积仍是负的。输出第二维是两个未舍入乘积之和。六位乘积 `−0.731059 + (−0.238406) = −0.969465`。`(8 * 512) // 3 = 1365`，进位到 `1536`。`3 * 512 * 1536 = 9 * 512²`，两层前馈是 `8 * 512²`。

</details>

### 练习 5：分组、输出和字节

- 目标：组号、共享 KV 时的不同输出、参数和缓存用同一套定义。
- 限制：组号用整除，不用取余。softmax 的六位是阅读值。
- 题面：正文里头 0、头 1、头 2 在位置 1 的输出各是多少？`H = 8`、`G = 2` 时，query 头 5 的组号是多少，和哪些头共用 KV？`d_model = 8`、`H = 4`、`d_k = 2`、`G = 2` 时四个矩阵多少参数？同一缓存公式下 MHA、这个 GQA、MQA 各多少字节？
- 完成标准：输出约 `3.462117`、正好 `3`、约 `1.476812`。头 5 在组 1，和头 4、6、7 共用。参数 `192`。字节 `128`、`64`、`32`。

<details>
<summary>参考解答</summary>

头 0 的权重是 `softmax(1, 0)`，头 1 的分数全是 0，头 2 读的是 `k = 2` 和 `k = 0`。`H / G = 4`，`5 // 4 = 1`，这一组从头号 4 到 7。`W_Q` 与 `W_O` 各 64，两块 KV 各 32。字节 `32 * G`，G 取 4、2、1。

</details>

## 本篇之外

长上下文里把 RoPE 的频率或位置编号再缩放，例如位置插值、NTK-aware、YaRN，不在本篇。只旋转一部分维度、以及给 value 也乘旋转，都不在本篇的约定里。ALiBi 那种加在分数上的相对偏置也不在。GEGLU、ReGLU 只换了门的函数，三块矩阵的形状和本篇相同，手算不另做。

QK-Norm、注意力和前馈同时加回同一条残差，不在本篇的块序里。交叉注意力、编码器、MoE 不在。注意力的梯度不手算。FlashAttention 改的是同一种注意力的访存，见推理优化里点到的那一条。分页、预填和解码的调度也在那一篇。Dropout 的保留概率不在本篇；这里的块按 Dropout 为 0 来写。

本篇的旋转、残差、SwiGLU、分组和字节由 `check_decoder_structure` 复核。
