## 本篇要回答的问题

1. 困惑度更低的模型，为什么可以在「抽一个续写、按任务规则算对错」上更差？
2. 多选时，对数概率的总和与按 token 平均，为什么会选出不同的选项？`pass@k` 的无偏估计和 `1-(1-c/n)^k` 差在哪一个数？
3. 回答文字不变，只调换位置或把同一段话再写一遍，模型裁判的胜率可以怎样变？
4. 两个系统评分相同，胜一场之后 Elo 各是多少？相差 400 分时期望得分是多少，它和 Bradley-Terry 的自然对数几率是什么关系？
5. 100 题对 80 题，准确率的标准误和 95% 区间是多少？同一批题上相差 5 个百分点，配对区间为什么可以包含 0？

## 先把问题写下来

一个可以解释的分数要先写清四件事。

| 事项 | 要写明的内容 |
| --- | --- |
| 题目从哪来 | 哪个人群、哪种任务、什么时间写成。换一批题，分数可以换一个含义 |
| 系统能看什么 | 提示、允许的工具、温度、抽几条。温度 0 和温度 0.8 是两个协议 |
| 对错怎么定 | 整串相等、单元测试、人类偏好，还是另一个模型的判断 |
| 数用来做什么决定 | 留下哪一个检查点、要不要换模型、能不能上线 |

四件里缺一件，后面的百分比就没有比较的对象。经典机器学习笔记已经把训练集、验证集、测试集分开。调提示时反复读取的那一批是验证集。最终一次报告用没有参与选择的题。本篇不再算「永远预测负类得到准确率 0.99」。

生成模型的输出通常是字符串。同一组参数可以在续写概率、选择题、单元测试和人类偏好上给出四个不同的排序。Liang 等的 HELM 把这件事写成评估设计：同时报告多个场景和多个指标，一个总分盖不住这些差别。

## 困惑度回答的是参考续写的概率

困惑度是 `exp(平均 NLL)`，对数是 ln。定义、分词器不同就不能比、以及按 token 平均和按序列平均会差出两个数，开篇和预训练笔记已经算过。本篇只使用一个结论：困惑度低，表示模型把更多概率分给了参考文本里的下一个 token。

任务规则经常接受多种写法。参考字符串只是其中一种。下面两个模型面对同一个前缀，下一个 token 只有三类：参考写法、另一种也算对的写法、错误写法。各抽一个 token，任务成功是前两类的概率之和。困惑度只看参考那一类，所以是 `1/p_参考`。

| 模型 | 参考 | 另一种正确 | 错误 | 这一项的困惑度 | 任务成功 |
| --- | --- | --- | --- | --- | --- |
| 甲 | 0.5 | 0.1 | 0.4 | 2 | 0.6 |
| 乙 | 0.25 | 0.6 | 0.15 | 4 | 0.85 |

甲的负对数似然是 `ln 2 ≈ 0.6931`，乙是 `ln 4 ≈ 1.3863`。按困惑度，甲更好。按「抽一个 token 算不算对」，乙更好。乙把概率放在另一种正确写法上，参考字符串只分到 0.25，困惑度因此更高。

这还是教师强制下的一步。训练和算困惑度时，前缀是数据里的真实 token。生成时，前缀是模型自己已经写下的 token。开篇把这个差别叫 exposure bias。困惑度不测量后一种条件。

平均落在每一个被监督 token 上。虚词往往容易预测，一个关键事实只占其中一个位置。平均可以下降，而那个位置仍然经常错。Schaeffer、Miranda 和 Koyejo 进一步指出：准确率这类带阈值的指标，可以把概率上的平稳变化显示成突然跳起来。指标换了，曲线的形状可以换。读「能力在某个规模突然出现」之前，先看纵轴是损失还是一道硬阈值。

## 多选、精确匹配与 pass@k

### 对数概率的总和，和按长度平均

多选的一种协议是：每个选项接在同一个提示后面，把选项 token 的对数概率相加，取得分最高的选项。这是条件概率的对数。选项更长时，乘上的因子更多，总和更容易更负。短的错误项可以因此赢过长的正确项。

正确项两个 token，条件概率都是 0.5。错误项一个 token，条件概率 0.4。

```text
正确项的总和 = ln 0.5 + ln 0.5 = -2 ln 2 = ln(1/4) ≈ -1.3863
错误项的总和 = ln 0.4 ≈ -0.9163
正确项的平均 = -ln 2 ≈ -0.6931
错误项的平均 = ln 0.4 ≈ -0.9163
```

总和更大的是错误项：`-0.9163 > -1.3863`。按 token 平均，正确项更大：`-0.6931 > -0.9163`。两种协议选出两个答案。

Brown 等在 GPT-3 的多数选择题上用的是按 token 平均。按 token 平均依赖分词：同一串字，切得更碎，分母变大。EleutherAI 的评测框架把未归一化的叫 `acc`，把除以长度之后的叫 `acc_norm`，并用字符或字节做分母，以免分词器决定这个长度。你运行的那一版除的是字符还是字节，以那一版代码为准。上面的手算除的是 token 数，和字符平均不是同一个分母。

四个选项若只写成字母 `A`、`B`、`C`、`D`，长度相同，总和与平均选出同一个字母。这时比的是字母的概率，不是选项原文的概率。模型可以把正确句子的概率打得很高，却把对应字母的概率打得很低。Hendrycks 等的 MMLU 是四选一的知识题。报告分数时写明比的是字母还是原文，以及有没有除以长度。

### 精确匹配把规范化算进指标

精确匹配是生成串和参考串在一套规范化之后完全相同。Rajpurkar 等的 SQuAD 把小写、去标点和去掉冠词写进了这套规则。规则不同，分数不同。

参考答案是 `13800138000`。

| 输出 | 整串相等 | 去掉非数字之后相等 |
| --- | --- | --- |
| `13800138000` | 对 | 对 |
| `138-0013-8000` | 错 | 对 |
| `13800138000。` | 错 | 对 |
| `电话是13800138000` | 错 | 对 |

不写明比的是哪一列，0 和 1 都没有含义。别名、另一种语言、多写一个标点，都可以在整串相等下得 0，同时在人看来是对的。反过来，子串匹配会让「把许多候选号码都写进去」抬高分数。评分函数要写明失败的样子。

### pass@k 的无偏估计

编程题的一种正确性是通过单元测试，不是和参考代码逐字相同。Chen 等的 HumanEval 用这个定义。`pass@k` 是：独立抽 k 条样本，至少一条通过测试的概率。k 变大，这个概率变大，因为尝试次数变多。`pass@1` 和 `pass@100` 回答的是两个问题。

只抽一次 k 条、看有没有通过，期望是对的，方差大。Chen 等改成每题抽 `n ≥ k` 条，数出通过的条数 `c`，再计算

```text
pass@k 的估计 = 1 - C(n - c, k) / C(n, k)
```

`n - c < k` 时，任何 k 条里都至少有一条通过，估计等于 1。否则失败的比例是从 `n - c` 条失败样本里抽出 k 条的组合数，除以从 n 条里抽出 k 条的组合数。

这个数等于：从这 n 条里无放回抽出 k 条，至少一条通过的比例。固定某 k 个位置，它们全部失败的概率是 `(1-p)^k`，这里假定每次独立、通过概率同为 p。对所有组合取平均，期望不变，而平均只取决于 c。所以它是 `1-(1-p)^k` 的无偏估计。直接算组合数会溢出。等价的连乘是

```text
C(n-c, k) / C(n, k) = ∏_{i = n-c+1}^{n} (1 - k/i)
```

手算 `n = 5`，`c = 2`，`k = 2`。

```text
C(5, 2) = 10
C(3, 2) = 3
估计 = 1 - 3/10 = 7/10
连乘：(1 - 2/4) * (1 - 2/5) = (1/2) * (3/5) = 3/10
```

把 `c/n = 2/5` 代进总体公式：

```text
1 - (1 - 2/5)^2 = 1 - (3/5)^2 = 1 - 9/25 = 16/25 = 0.64
```

`7/10 = 0.7`。两个公式在这一次相差 `0.06`。Chen 等的附录说明代入公式在期望上偏低。这一次的差距不是每一次的差距。`k = 1` 时两个公式都变成 `c/n`，这里是 `2/5`。

再取 `c = 4`。失败条数是 1，小于 `k = 2`，无偏估计是 1。代入公式是 `1 - (1/5)^2 = 24/25`。

温度为 0 时各次样本相同，独立性不成立，`pass@k` 不会随 k 上升。温度是协议的一部分。Chen 等在一个 679M 参数的模型上，`pass@1` 用温度 0.2，`pass@100` 用 0.8；更大的 k 需要更多样的样本。换一个模型，这两个温度不必仍是同一选择。他们所有抽样评估用 nucleus sampling，`top p = 0.95`。

他们的图 1 里，温度 0.8 下 Codex 单次求解约 28.8%；100 条里能挑出通过测试的那一条时，约 77.5% 的题至少有一条通过。后者回答的是「允许多次尝试、并且用测试来认出哪一条通过了」。部署时若没有这套测试，就不能把 77.5% 说成一次提交的通过率。测试本身没覆盖的错误仍会被判成通过。拿掉边界用例，通过率上升，任务没有变好。

他们还把样本和参考代码算 BLEU，正确样本和错误样本的分数分布明显重叠。表面重合上升，不表示单元测试通过率上升。

## 表面重合与模型裁判

### 截断之后的重合

BLEU 和 ROUGE 比较的是候选和参考的 n 元片段，不是事实。Papineni 等的修改精度先把候选里每个 n 元的次数截断到它在参考里的次数，再除以候选的 n 元总数。不截断时，把一个出现过的词重复很多遍，精度可以接近 1。

参考：`猫 在 垫子`。候选：`猫 猫 猫 在`。

```text
不截断：四个 token 都在参考里出现过，一元精度 = 4/4 = 1
截断：猫 最多计 1 次，在 计 1 次，精度 = 2/4 = 1/2
```

BLEU 再对一元到四元的修改精度做几何平均，并乘上一个短句惩罚。完整定义以 Papineni 等为准。上面只算截断这一步。

Lin 的 ROUGE 面向召回：参考里有多少 n 元被候选盖住。参考三个词，候选 `猫 在 桌子` 盖住两个，一元召回是 `2/3`。错误的「桌子」不降低这个召回。把原文抄进摘要，召回可以很高。

### 三个会改变胜负的裁判偏差

开放式回答常常没有唯一字符串。Zheng 等用一个强模型比较两条回答，并对照人类。他们报告，在处理了偏差之后，GPT-4 裁判和人类的一致率可以超过 80%，和人类之间的一致率处于同一档。这个数是他们的裁判、他们的题和他们的提示下的结果。换一个裁判模型，要重测。

他们单独检查了三种偏差。

**位置。** 两条回答对调之后，裁判改判。他们用很接近的两条回答做实验，多数裁判偏向先出现的那一条；在那场实验里，只有 GPT-4 的一致率超过 60%，默认提示下的一致率是 65.0%。下面用一组构造的计数说明协议怎样改分数，这组计数不是他们的表。

100 对比较。待测系统放在第一位时，它赢 65 次。对调之后，它赢 45 次。

```text
两种顺序的平均 = (65 + 45) / 2 / 100 = 0.55
只报第一位 = 0.65
```

固定位置比两种顺序的平均高 10 个百分点。回答没有变。Zheng 等的一种处理是：两种顺序都判同一个赢家，才记这个赢家；对调后改判的，记成平局。

**长度。** 他们做了「重复列表」：把已经说过的条目换一种说法再写一遍，不增加信息，接在原文前面。裁判若认为更长的这一份更好，攻击就成功。他们观察到各档裁判都会中这种攻击，强裁判更少。把一条回答里已经说过的话再写一遍，不改正文，就可以利用这个偏好。

**自我偏好。** Zheng 等把它叫 self-enhancement：裁判可能更喜欢自己生成的回答。他们看到 GPT-4 相对人类基线给自己多出约 10% 的胜率，Claude-v1 多出约 25%，同时也看到这些裁判偏爱别的模型，因此认为那场数据还不能断定偏差存在。风格和质量缠在一起。Panickssery、Bowman 和 Feng 后来把自我偏好定义成：人类认为质量相当时，裁判仍给自己的输出更高分。他们发现 GPT-4 和 Llama 2 能以高于随机的准确率认出自己的输出，并且这种辨认和自我偏好一起变化。用待测模型自己的家族当裁判，胜率里会混进这一项。

Dubois 等后来把回答长度当作协变量，再估计胜率，用来减轻榜单上的长度偏好。那是对自动胜率的一种修正。它不代替「两种顺序都要跑」这条规定。

## 人类偏好与 Elo

对齐笔记里的 Bradley-Terry 比较的是同一提示下的两条回答，奖励差的 sigmoid 是偏好概率。极大似然在三次对一次时给出 `ln 3`，本篇不重算。

评估把同一个概率用在系统上。一场对局是：一个提示，两个系统各写一条回答，人类（或裁判）选出更好的一条。系统 `A` 的强度是 `s_A`。

```text
P(A 胜 B) = σ(s_A - s_B)
σ(z) = 1 / (1 + exp(-z))
```

这和奖励模型是同一个函数，自变量换成了系统强度。它不产生 DPO 的损失，也不更新策略。一个强度把所有提示平均在一起。系统可以在编程上赢、在中文写作上输。一个总分会把这两件事加没。决定如果依赖某一类提示，就按那一类单独排名。

在线 Elo 是这个模型的一种顺序更新。象棋里常用的期望得分是

```text
E_A = 1 / (1 + 10^((R_B - R_A) / 400))
R_A ← R_A + K (S_A - E_A)
```

`S_A` 在胜时为 1，负时为 0，平局为 0.5。`K` 决定一场对局能动多少分。两边都从 1000 出发，`K = 32`，`A` 获胜：

```text
E_A = 1/2
A 的新评分 = 1000 + 32 * (1 - 1/2) = 1016
B 的新评分 = 1000 + 32 * (0 - 1/2) = 984
```

令 `s = R ln 10 / 400`。则 `10^((R_B-R_A)/400) = exp(s_B - s_A)`，期望得分等于 `σ(s_A - s_B)`。象棋刻度上相差 400 分：

```text
E_A = 1 / (1 + 10^{-1}) = 10/11 ≈ 0.9091
s_A - s_B = ln 10 ≈ 2.3026
σ(ln 10) = 10/11
```

对齐笔记里已经算过 `σ(1) ≈ 0.7311`。那是自然对数几率相差 1，不是这 400 分。有的榜把 Bradley-Terry 系数乘一个常数再加 1000，让印出来的数字落在象棋评分附近。乘的常数决定了「相差 400」对应 `10/11` 还是 `σ(1)`。协议里要写期望得分的公式。

一场更新会改变下一场的期望得分。同一批对局按不同顺序送进在线 Elo，评分可以不同。Bradley-Terry 的极大似然只看胜负次数，顺序不进入似然。Chiang 等把 Chatbot Arena 的公布排名放在这个极大似然上，并用区间表示估计的不确定。LMSYS 在 2023 年 12 月的说明里写了为何从在线 Elo 改过来：在线更新依赖顺序和 `K`。平局在他们的模型里记成半胜半负，对应 `S = 0.5`。

一维强度也表示不了循环：`A` 胜 `B`，`B` 胜 `C`，`C` 胜 `A`。极大似然仍会给出一个折中的排序。折中不是每一类提示上的胜负。

## 污染：题进了训练集

监督学习笔记里的泄漏，是特征用了决策时尚不存在的信息，或预处理统计量看见了测试折。预训练笔记里的精确去重，删的是文档哈希相同的副本；他们已经写明，精确匹配删不掉改写，验证 NLL 低到 `0.05` 时要先回去查去污染。本篇不重算那个困惑度。这里要查的是另一件事：评测题或它的近副本出现在**任何会更新参数的数据**里，包括预训练、SFT 和偏好数据。SFT 的损失仍是回答 token 上的平均负对数似然。题和标准答案若躺在那批回答里，模型可以背下字符串，损失下降测的是背诵。

Brown 等用词的 n 元重叠来标记。gram 是小写、按空白切开、去掉标点的词。分析时每份数据取一个长度 `N`：题目词数的第 5 百分位，再夹到 8 和 13。非合成任务的下限是 8，更短的重叠里假阳性很多。一条题目只要和任何训练文档共享一个这样的 `N` 元，就标成 dirty。阅读理解里，训练文档可以只含背景段落、不含问题和答案。他们检查 DROP 时，匹配到的就是这种段落。规则标出了重叠，重叠的不一定是答案。

教学计数用更短的阈值，便于手算，不是他们的 8 到 13。词按下面的空格切开。训练片段是 `报道 泰坦尼克 的 船长 是 谁 的 新闻`。

| 题目 | 和训练片段最长的连续重叠 | 阈值 5 是否标出 |
| --- | --- | --- |
| `泰坦尼克 的 船长 是 谁` | 5 | 标出 |
| `沉船 的 船长 叫 什么` | 2（`的 船长`） | 不标出 |

第二句没有五个连续的相同词，规则把它放行。船长这个事实仍然可能从第一句里学到。n 元干净，没有证明题目是新的。

Carlini 等用 canary 测记忆。在一个固定模板的所有可能填充里，按模型概率从高到低排名。exposure 是

```text
exposure = log2(填充的个数) - log2(名次)
```

名次从 1 起，1 是概率最高的那一条。模板有 `2^10 = 1024` 种填充。真 canary 排第 1：exposure `= 10 - 0 = 10`。排在第 512：`log2(512) = 9`，exposure `= 1`。随机排序的名次靠近中间时，exposure 靠近 0。一条只该出现在评测文件里的独特字符串若排到最前，文件很可能进过训练。

Shi 等用另一条成员信号：一段文本里，取对数概率最低的那 k% 个 token，再平均。训练中见过的文本，这些本来最不像的 token 往往没那么低。分数高是要去核对的信号，不是「这道题的答案已经被背下」的证明。

## 标准误、区间与题量

把每道题看成独立的对或错，成功概率同为 `p`。`n` 题里对了 `X` 题，`p̂ = X/n`。估计的标准误是

```text
SE = sqrt( p̂ (1 - p̂) / n )
```

`p(1-p)` 用 `p̂` 代入。Wald 区间用标准正态的 0.975 分位数，约 1.96：

```text
p̂ ± 1.96 SE
```

100 题对 80 题，`p̂ = 0.8`。

```text
SE = sqrt(0.8 * 0.2 / 100) = sqrt(0.0016) = 0.04
1.96 * 0.04 = 0.0784
区间 = [0.7216, 0.8784]
```

80% 和 75% 的两个点估计都落在对方这种宽度的区间附近。只看点估计的排序，读不出差距是否站得住。

同一批题上的两个系统要配对。100 题的计数：都对 70，只 A 对 10，只 B 对 5，都错 15。A 的准确率是 0.8，B 是 0.75，差是 0.05。

令 `D = I_A - I_B`。只 A 对时 `D = 1`，只 B 对时 `D = -1`，其余为 0。

```text
E[D²] = 15/100 = 0.15
(E[D])² = 0.05² = 0.0025
Var(D) = 0.1475
SE = sqrt(0.1475 / 100) = sqrt(0.001475) ≈ 0.0384
1.96 * SE ≈ 0.0753
区间 ≈ [-0.0253, 0.1253]
```

区间包含 0。5 个百分点在这 100 道相同的题上，Wald 区间还不能把 A 排在 B 前面。

用协方差核对同一笔账。`P(都对) = 0.70`，`Cov = 0.70 - 0.8 * 0.75 = 0.10`。

```text
Var(I_A - I_B) = 0.8*0.2 + 0.75*0.25 - 2*0.10
               = 0.16 + 0.1875 - 0.20
               = 0.1475
```

概率笔记里，相关的两个变量不能把方差直接相加。这里是相减，协方差要减两次。把协方差当成 0：

```text
SE_独立 = sqrt(0.04² + 0.75*0.25/100) = sqrt(0.003475) ≈ 0.0589
```

这组题上两边的对错正相关，忽略配对会把标准误算成约 0.0589，大于约 0.0384。都对和都错的题不提供差值。要缩小差值的区间，需要更多两边答案不同的题。

`p(1-p)` 最大是 `1/4`，在 `p = 1/2`。于是 `SE ≤ 1/(2 sqrt(n))`。要让 1.96 倍标准误不超过 0.05：

```text
0.98 / sqrt(n) ≤ 0.05
sqrt(n) ≥ 19.6
n ≥ 384.16
```

至少 385 题。384 题的半宽约 0.05001，仍大于 0.05。385 题约 0.04995。这是最坏情形下、这份题上的 Wald 半宽。题都来自同一份试卷时，区间描述的是这份试卷上的抽样波动。换一批题，或换一群用户，波动可以更大。

`p̂` 是 0 或 1 时，代入之后的标准误是 0，Wald 区间缩成一个点。40 题全对，得到的是 `[1, 1]`。它不表示下一句没见过的题也会对。事先指定一个指标，区间才按 1.96 来读。在 20 个指标里挑涨幅最大的那个再配区间，覆盖率不再是 95%。

## 一个小评估，和一种刷分

任务：从一句中文里抽出手机号。有号码就输出恰好 11 位数字，没有就输出 `NONE`。整串相等才算对。温度 0，只生成一次。提示在看分数之前定死。

题目 40 句，两类各 20，在准备训练数据之后写成，并且不放进任何会更新参数的混合物。两类各半，是为了不靠「永远输出 `NONE`」在倾斜数据上拿高准确率。一次结果可以是：

| 切片 | 对 | 错 |
| --- | --- | --- |
| 有号码 | 16 | 4 |
| 没有号码 | 8 | 12 |
| 合计 | 24 | 16 |

```text
准确率 = 24/40 = 0.6
SE = sqrt(0.6 * 0.4 / 40) = sqrt(0.006) ≈ 0.07746
1.96 * SE ≈ 0.15182
区间 ≈ [0.4482, 0.7518]
```

没有号码的 20 句里错了 12 句：模型经常编一个号码。另一种切片是有号码对 12、没有号码对 12，合计仍是 24。总准确率相同，错误的种类不同。报告里两行都要在。

半宽要用没有收成四位小数的标准误去乘。先把标准误收成 0.0775 再乘 1.96，得到 0.1519，区间的端点会跟着偏。

**一种刷分：把这 40 句和标准答案放进 SFT。** 损失仍是回答上的下一个 token。模型可以背下这 40 个字符串。再测同一批，40/40，代入之后的标准误变成 0，Wald 区间缩成一个点。这个点回答的是「这 40 句还能不能背出来」，不回答「下一句没见过的简历能不能抽出号码」。另写 40 句，不放进预训练、SFT 或偏好数据，才还是原来的问题。n 元重叠或一条只出现在这 40 句里的 canary，用来检查混合物里有没有它们。

刷分跟着评分函数走。若把整串相等改成「输出里含有这 11 位」，在正确答案后面加一段客套话就会从错变对。若改成模型裁判，并且待测回答总放在第一位，用上面那组 65 和 45，报告的胜率是 0.65，两种顺序的平均是 0.55。再把错误号码所在的句子重复一遍，长度偏好可以继续把错的那条判成更好。号码不必改对。

## 参考代码

连乘就是 Chen 等的无偏估计。标准误用样本比例代入 `p(1-p)`。

```python
import math


def pass_at_k(n: int, c: int, k: int) -> float:
    """1 - C(n-c, k) / C(n, k)。n-c < k 时为 1。"""
    if n - c < k:
        return 1.0
    fail = 1.0
    for i in range(n - c + 1, n + 1):
        fail *= 1.0 - k / i
    return 1.0 - fail


def binomial_se(successes: int, n: int) -> float:
    p_hat = successes / n
    return math.sqrt(p_hat * (1.0 - p_hat) / n)
```

## 容易算错的地方

- 甲的困惑度是 2，任务成功是 0.6。乙的困惑度是 4，任务成功是 0.85。排序跟着纵轴走。
- 两个 token 各 0.5，总和约 `-1.3863`。一个 token 0.4，总和约 `-0.9163`。总和选短的错误项，按 token 平均选长的正确项。
- `n=5,c=2,k=2` 时，无偏估计是 `7/10`，代入 `1-(1-c/n)^k` 得到 `16/25`。`c=4` 时前者是 1，后者是 `24/25`。
- `pass@100` 允许一百次尝试。把它说成一次提交的通过率，换了问题。
- 100 对比较只放第一位是 0.65，两种顺序平均是 0.55。
- 从 1000 对 1000 胜一场，`K=32` 时是 1016 对 984。象棋刻度相差 400 分是 `10/11`，不是对齐笔记里的 `σ(1)`。
- 100 题对 80 题，标准误是 0.04，区间是 `[0.7216, 0.8784]`。配对差 0.05 的区间约是 `[-0.0253, 0.1253]`，包含 0。
- 40 题全对时，代入之后的标准误是 0。点区间不描述下一批题。
- 半宽先乘再收成四位。`sqrt(0.006)` 先收成 0.0775 再乘，半宽会写成 0.1519。

## 练习

### 练习 1：困惑度和任务成功各排一次

- 目标：两个纵轴可以给出两个排序。
- 限制：纸笔。用 ln。
- 题面：用正文的甲和乙。各自的参考类负对数似然、困惑度、任务成功概率是多少？哪一个模型在哪一个指标上更好？
- 完成标准：甲约 `0.6931` 和 `2`，成功 `0.6`。乙约 `1.3863` 和 `4`，成功 `0.85`。

<details>
<summary>参考解答</summary>

参考概率 `1/2` 和 `1/4`，负对数似然是 `ln 2` 和 `ln 4`，困惑度是 2 和 4。成功概率是 `0.5+0.1=0.6` 和 `0.25+0.6=0.85`。困惑度选甲，任务成功选乙。

</details>

### 练习 2：总和与平均各选谁

- 目标：长度进不进分母，是协议的一部分。
- 限制：纸笔或计算器。
- 题面：正确项两个 token，概率都是 0.5。错误项一个 token，概率 0.4。写出两个总和、两个平均，并写出每种规则下的赢家。
- 完成标准：总和约 `-1.3863` 和 `-0.9163`，平均约 `-0.6931` 和 `-0.9163`。总和选错误项，平均选正确项。

<details>
<summary>参考解答</summary>

`-2 ln 2 = ln(1/4)`。`ln 0.4` 更大，所以总和选错误项。平均之后 `-ln 2` 更大，选正确项。

</details>

### 练习 3：把 pass@k 的两个公式算开

- 目标：无偏估计用的是组合，不是把 `c/n` 代进总体公式。
- 限制：纸笔。
- 题面：`n=5`，`k=2`。`c=2` 时两个估计各是多少？连乘的两项是什么？`c=4` 时两个估计各是多少？`k=1` 且 `c=2` 时呢？
- 完成标准：`7/10` 和 `16/25`。连乘是 `1/2` 和 `3/5`。`c=4` 时是 `1` 和 `24/25`。`k=1` 时都是 `2/5`。

<details>
<summary>参考解答</summary>

`C(3,2)/C(5,2)=3/10`。`(3/5)^2=9/25`。`c=4` 时失败条数小于 2，组合比是 0。`k=1` 时 `1-(n-c)/n=c/n`。

</details>

### 练习 4：一场 Elo，和 400 分的期望得分

- 目标：分清一次更新和刻度。
- 限制：纸笔。`K=32`。
- 题面：两边都是 1000，A 获胜。新评分是多少？A 为 1400、B 为 1000 时，A 的期望得分是多少？这个差距在自然对数几率上是多少？
- 完成标准：1016 和 984。期望得分 `10/11`，约 `0.9091`。自然对数几率 `ln 10`，约 `2.3026`。

<details>
<summary>参考解答</summary>

期望得分是 `1/2`，变化量是 `32*1/2=16`。差 400 分时分母是 `1+0.1`，得分 `10/11`。`s=R ln 10/400`，差 400 分对应 `ln 10`。`σ(1)` 是另一个刻度。

</details>

### 练习 5：80/100 的区间

- 目标：标准误带着题量。
- 限制：纸笔。1.96 倍要乘在没有提前收位的标准误上。
- 题面：100 题对 80 题。标准误是多少？95% 的 Wald 区间是多少？
- 完成标准：标准误 `0.04`，区间 `[0.7216, 0.8784]`。

<details>
<summary>参考解答</summary>

`0.8*0.2/100=0.0016`，平方根是 `0.04`。`1.96*0.04=0.0784`。两端是 `0.8` 加减这个半宽。

</details>

### 练习 6：配对之后区间是否包含 0

- 目标：两边都对的题不提供差值。
- 限制：纸笔或计算器。用正文的 70、10、5、15。
- 题面：准确率之差是多少？配对标准误约是多少？Wald 区间约是多少？把协方差当成 0 时标准误约是多少？
- 完成标准：差 `0.05`。配对标准误约 `0.0384`，区间约 `[-0.0253, 0.1253]`，包含 0。独立公式约 `0.0589`。

<details>
<summary>参考解答</summary>

`Var(D)=0.15-0.0025=0.1475`，再除以 100 后开方。`1.96` 倍约 `0.0753`，从 `0.05` 向两侧展开。协方差是 `0.10`，独立公式少减了 `2*0.10`。

</details>

### 练习 7：半宽不超过 0.05 要多少题

- 目标：用 `p=1/2` 的最坏方差定题量。
- 限制：纸笔或计算器。
- 题面：`1.96/(2 sqrt(n)) ≤ 0.05` 时，`n` 至少是多少？384 和 385 的半宽各约是多少？为什么 40 题全对时，代入 `p̂` 之后的标准误不能用来宣布下一句也会对？
- 完成标准：`n ≥ 385`。半宽约 `0.05001` 和 `0.04995`。全对时这个标准误是 0，区间缩成一个点。

<details>
<summary>参考解答</summary>

`0.98/sqrt(n) ≤ 0.05` 推出 `sqrt(n) ≥ 19.6`，`n ≥ 384.16`，所以取 385。384 仍大于 0.05。`p̂=1` 时 `p̂(1-p̂)=0`。

</details>

### 练习 8：40 句手机号，以及一种刷分

- 目标：评分函数决定哪种取巧有效。
- 限制：纸笔。半宽用未收位的标准误。
- 题面：24/40 的准确率、标准误和 Wald 区间各约是多少？把这 40 句和标准答案放进 SFT 再测同一批，准确率和代入之后的标准误会变成什么？这个点回答的是哪一个问题？若评分改成「输出含有这 11 位数字」，再举一种不抽对号码也能提高分数的做法。
- 完成标准：准确率 `0.6`，标准误约 `0.0775`，区间约 `[0.4482, 0.7518]`。背下来之后是 `1` 和标准误 `0`。子串规则下，在正确答案后面加无关文字可以从错变对。

<details>
<summary>参考解答</summary>

`sqrt(0.006)≈0.07746`，乘 1.96 约 `0.15182`，端点约 `0.4482` 和 `0.7518`。先收成 `0.0775` 再乘会得到 `0.1519`。背诵把同一批测成 40/40。子串匹配允许额外的客套话。固定裁判位置和重复原句，是另一套评分函数上的取巧，见正文的 `0.65` 和 `0.55`。

</details>
