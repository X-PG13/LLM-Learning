## 本篇要回答的问题

1. 参数里已经能记住一些事实，解码时为什么还要把外部文本读进来？
2. 同一组二维向量，内积、余弦和欧氏距离为什么排出三种顺序？相关集是 {甲, 丙} 时，召回率@k 和「前 k 名里至少有一篇相关」各是多少？
3. 四篇短文档上，BM25 的分数是多少？为什么把「退货」重复三遍的短文档，排在写出「七天」的那一篇前面？
4. 倒数排名融合（k = 60）的第一名是谁？把 BM25 和余弦直接相加，第一名又是谁？
5. 下一步只在文档甲上条件化，「七」和「三」谁的概率更大？按 3/5 与 2/5 把两份文档边缘化之后，argmax 是否换人？
6. 块预算只有 7 个词时，把乙放在甲前面，「七」还在不在提示里？三条主张的上下文忠实和引用正确各是多少？

## 解码时多出来的条件

因果语言模型给出的是 `p(下一个 token | 已经写下来的 token)`。预训练把大量事实写进参数。Lewis 等把这份记忆叫做参数记忆：它在权重里，不在一条可以打开的文档里。三件事因此留在解码外面。

**覆盖。** 训练混合物里没有的事实，参数没有见过。见过的事实也会和别的实体写混。参数变大可以记住更多，记全不是这个条件分布的定义。

**时效。** 事实在训练截止之后变了。要改权重，就得再做一次更新。外部索引可以换成新文本，生成模型的参数保持不动。Lewis 等把这种更换叫做 index hot-swapping：非参数记忆换掉，生成器不用重训。

**出处。** 权重里的一个数指回不了一句话。检索把一段字符串放进条件，读者可以对照这段字符串。对照发现引用错了，仍然是一种可以报告的失败。没有这段字符串时，失败只表现为「模型说错了」。

检索不保证这段字符串为真，也不保证模型按它来写。它改变的是解码时条件里有什么。参数继续参与这个条件：即使提示里写着「七天」，下一步把概率分给「三」仍然可能。本篇后面用 3/4 和 1/4 算这个剩余。

这条路径上，参数在解码期间不更新。检索发生在生成之前或生成之中，文档进入下一个 token 的条件。Lewis 等的检索增强生成（retrieval-augmented generation，RAG）把文档当成隐变量，对 top-k 篇做边缘化，再让序列到序列模型生成。现在常见的用法更简单：把若干块拼进同一次提示，只解码一次。两种都是推理时使用非参数记忆。

另外两条线不在本篇展开公式。Guu 等的 REALM 在预训练时就检索，用检索到的文档做掩码语言建模。Borgeaud 等的 RETRO 在网络内部用交叉注意力读检索到的块，检索器是冻结的。它们都改了训练，不只是在一次已经训好的解码前面拼提示。

## 切块：证据要落在同一块里

检索的单位通常不是整篇文档。DPR 把维基百科文章切成互不重叠的 100 词段落，得到 21,015,324 块，再为每块学一个向量。Lewis 等的检索器用的就是这套 DPR 索引。块是后来被放进提示的那段文字，也是被算进召回率的那条候选。

固定窗口会把一句话切在答案中间。教学用的词已经按空格切开。文档是

```text
本公司 规定 退货 期限 是 七 天 请 保留 发票
```

共 10 个词。窗口长度为 4。

无重叠时步长也是 4，起点是 0、4、8：

| 起点 | 块 | 含「退货」 | 含「七」 |
| --- | --- | --- | --- |
| 0 | 本公司 规定 退货 期限 | 是 | 否 |
| 4 | 是 七 天 请 | 否 | 是 |
| 8 | 保留 发票 | 否 | 否 |

没有任何一块同时含有「退货」和「七」。查询若要这两个词互相证明，检索即使命中其中一块，另一半证据也不在这块里。词次总数仍是 10。

步长改成 2，起点是 0、2、4、6、8。最后一块可以短：

| 起点 | 块 | 同时含有「退货」和「七」 |
| --- | --- | --- |
| 0 | 本公司 规定 退货 期限 | 否 |
| 2 | 退货 期限 是 七 | 是 |
| 4 | 是 七 天 请 | 否 |
| 6 | 天 请 保留 发票 | 否 |
| 8 | 保留 发票 | 否 |

第二块把「退货」和「七」留在一起。五块的词次是 `4+4+4+4+2 = 18`。原文只有 10 个词，重叠使索引里的词次变成 18。召回和存储一起变。DPR 的公开索引用的是不重叠的 100 词；重叠是切分规则的另一项选择，不是那次实验的默认。

块太长时，一个向量要代表好几件不相干的事，点积会被别的句子拉走。块太短时，上面这种切断就会出现。窗口和步长是这条流水线的参数，要和后面的召回一起报告。

## 三种近邻，三种顺序

下面四个向量是为手算造的，不是某个编码器的输出。查询 `q = (3, 1)`。

| 块 | 向量 | 与 q 的点积 | 余弦 | 到 q 的平方距离 |
| --- | --- | --- | --- | --- |
| 甲 | (3, 1) | 10 | 1 | 0 |
| 乙 | (9, −7) | 20 | `2/sqrt(13) ≈ 0.5547` | 100 |
| 丙 | (1, 2) | 5 | `1/sqrt(2) ≈ 0.7071` | 5 |
| 丁 | (0, 3) | 3 | `1/sqrt(10) ≈ 0.3162` | 13 |

余弦是 ` (u · v) / (|u| |v|) `，`|u| = sqrt(u · u)`。甲与 q 同方向，余弦是 1。乙的点积是

```text
3×9 + 1×(−7) = 20
|乙|² = 81 + 49 = 130
余弦 = 20 / (sqrt(10) × sqrt(130)) = 2/sqrt(13) ≈ 0.5547
```

平方距离是 `|q − x|²`。乙是 `(−6)² + 8² = 100`。

三种「谁更近」：

| 规则 | 从近到远 |
| --- | --- |
| 点积最大 | 乙 (20)、甲 (10)、丙 (5)、丁 (3) |
| 余弦最大 | 甲 (1)、丙 (≈0.7071)、乙 (≈0.5547)、丁 (≈0.3162) |
| 平方距离最小 | 甲 (0)、丙 (5)、丁 (13)、乙 (100) |

乙比甲长。它在 q 的方向上投影不小，正交方向上还有一大截，所以点积最高，角度和欧氏距离都不好。先把两边都除以自身的范数，点积就变成余弦，顺序会和余弦那一行相同。DPR 和 Lewis 等的检索把查询向量和文档向量的点积当作分数，近邻搜索是最大内积搜索（maximum inner product search，MIPS）。向量没有归一化时，MIPS 和余弦不是同一次排序。本篇这四个向量没有归一化。

把四个点积送进 softmax，乙拿走几乎全部质量。以 20 为峰值：

```text
p(乙) = 1 / (1 + exp(−10) + exp(−15) + exp(−17)) > 0.9999
```

点积相差 10，指数把差距放大。这个分布不能当作「四篇都还值得读」的文档概率。余弦再送进 softmax 会平坦得多；那是另一个输入，本篇不把它当成检索器的输出。

这一节先把相关集规定成 {甲, 丙}，用来把召回的分母摆开。后面回答「退货期限是几天」时，相关集只留甲，因为只有甲写出了天数。两个相关集是两个问题。

```text
召回率@k = |相关 ∩ 前 k 名| / |相关|
命中@k = 1，当前 k 名里至少有一篇相关；否则为 0
```

|R| = 2。

| 排序 | @1 的召回 | @1 的命中 | @2 的召回 | @2 的命中 | @3 的召回 |
| --- | --- | --- | --- | --- | --- |
| 余弦：甲、丙、乙、丁 | 1/2 | 1 | 1 | 1 | 1 |
| 点积：乙、甲、丙、丁 | 0 | 0 | 1/2 | 1 | 1 |
| 距离：甲、丙、丁、乙 | 1/2 | 1 | 1 | 1 | 1 |

点积的前两名只含甲。命中@2 已经是 1，召回率@2 仍是 1/2。DPR 报告的 top-k retrieval accuracy 是命中这一型：在问题集合上，前 k 个段落里出现能回答该问题的文本的比例。相关段落可以有多段，命中不惩罚「还有几段没进前 k」。表 2 的测试集 top-20 里，Natural Questions 上 BM25 是 59.1，按该数据集单独训练的 DPR 是 78.4；SQuAD 上 BM25 是 68.8，DPR 是 63.2。稠密检索在他们的表里不是每一列都更高。这些百分比是他们的测试集，不是上面四个向量。

## 近似最近邻：少看一些距离

四篇可以两两算完。块数到了 DPR 那种两千万，每个查询都对全库算精确距离，次数随库大小线性涨。近似最近邻少算一些距离，用召回率交换。两种常见结构可以用很小的图看懂。它们都不是上表那四个向量。

### 倒排文件：先选桶，再在桶里精确算

Johnson、Douze 与 Jégou 描述的倒排文件（inverted file，IVF）先用一组质心把库分成桶。每个向量归到离它最近的质心，记在这个质心的倒排表里。查询来时，只打开离查询最近的 `nprobe` 个质心，在这些表里用精确距离排序。近似发生在「哪些表被打开」。打开之后，表内的距离是精确的。

质心放在 0 和 10。库里只有两个点。

```text
a = 4：到 0 的距离是 4，到 10 的距离是 6，进入 0 的表
b = 9：到 0 的距离是 9，到 10 的距离是 1，进入 10 的表
查询 q = 6：到 0 的距离是 6，到 10 的距离是 4
```

`nprobe = 1` 只打开 10 的表，看到 b，距离 `|6 − 9| = 3`。真近邻是 a，距离 `|6 − 4| = 2`，它在没打开的表里。若相关集只有 a，这次近似的召回率@1 是 0。`nprobe = 2` 两张表都打开，精确距离把 a 排到前面，召回率@1 是 1。多探的桶越多，越接近全库扫描，也越多读倒排表。

### 层次小世界图：贪心走到局部，长边负责跳

Malkov 与 Yashunin 的 HNSW（Hierarchical Navigable Small World）把向量连成图。搜索从入口沿边走到更近的邻居。上层点稀、边长，用来跳到查询附近；下层点密，用来在附近收尾。每一层保留的候选个数记为 `ef`。`ef = 1` 就是只留当前最近的一个名字。

下面这张图是为了看搜索步，不是某次插入算法自动连出来的边。点在一条线上，查询在 5。

```text
距离：A=0 → 5，B=3 → 2，C=4 → 1，M=8 → 3
底层的边：A—B，B—M，M—C。没有 B—C
```

`ef = 1`，从 A 出发：

- A 的邻居 B 更近，列表换成 B。
- 展开 B。邻居 M 的距离是 3，大于 B 的 2，列表已满，M 不进入。
- C 只和 M 相连，这一步看不到。返回 B，距离 2。真近邻 C 的距离是 1。

`ef = 2` 可以同时留两个名字：

- 从 A 走到 B 时，A（距离 5）还留在列表里。
- M 的距离 3 小于 5，M 进入，A 被挤出。列表是 B 和 M。
- 展开 M。C 的距离是 1，进入列表，M 被挤出。列表是 C 和 B。最近的是 C。

上层若只有一条长边 A—M，`ef = 1` 也会从 A 走到 M（3 < 5）。下一层从 M 出发。M 同时连着 B（距离 2）和 C（距离 1），列表只留一个名字，最后留在 C。长边改变的是下层的入口。没有这条长边、并且 `ef = 1` 时，搜索停在 B。

`ef` 和 IVF 的 `nprobe` 是同一类旋钮：允许多看一些候选，近似的召回上升，查询时的距离次数也上升。建图或分桶的参数要和这个查询旋钮分开记。

## BM25：词频会饱和，长文档会被拉长

稀疏检索不先把块变成稠密向量。BM25 按查询词在文档里的次数打分。Robertson 与 Zaragoza 的式 (3.15) 对查询中的每个词累加

```text
IDF(t) × f / (f + k1 × (1 − b + b × |D| / avgdl))
```

`f` 是词 t 在该文档里的次数，`|D|` 是文档词数，`avgdl` 是语料平均词数。`k1 > 0` 控制词频何时饱和，`b ∈ [0, 1]` 控制长度归一化有多强。`f` 再大，这一项也不超过 IDF(t)。Lucene 9.11 的 `score` 用的是同一个词频因子；默认 `k1 = 1.2`、`b = 0.75`。手算用这组默认，并且用精确词数。Lucene 把长度编进一个字节的范数表时，长度是近似的，和这里会差一截。

他们的式 (3.3) 把没有相关性反馈时的 IDF 写成

```text
ln( (N − n + 0.5) / (n + 0.5) )
```

`N` 是文档数，`n` 是含有该词的文档数。Lucene 9.11 写成

```text
ln( 1 + (N − n + 0.5) / (n + 0.5) )
```

差在比值外面的那个 1。Java 的 `log` 是自然对数，和本篇的 ln 相同。

四篇文档，查询词是「退货」和「期限」。问的是退货期限是几天；天数不在查询词里，它只决定哪一篇算相关。

| 文档 | 词 | 词数 |
| --- | --- | --- |
| 甲 | 退货 的 期限 是 七 天 并且 需要 发票 | 9 |
| 乙 | 退货 退货 退货 | 3 |
| 丙 | 会员 期限 | 2 |
| 丁 | 天气 晴朗 | 2 |

`N = 4`，总词数 16，`avgdl = 4`。「退货」出现在甲和乙，`n = 2`；「期限」出现在甲和丙，`n = 2`。

```text
式 (3.3)：ln( (4 − 2 + 0.5) / (2 + 0.5) ) = ln 1 = 0
Lucene：ln(1 + 2.5/2.5) = ln 2 ≈ 0.6931
```

用式 (3.3) 时两个查询词的 IDF 都是 0，四篇分数都是 0，排不出顺序。词出现在一半文档里，这个 IDF 就到了 0；出现得更广时它还会变成负数。本篇的分数改用 Lucene 的 IDF，两个词都是 `ln 2`。这是公式选择，不是这四篇的内容突然变了。

长度因子 `1 − b + b × |D| / avgdl`，再乘 `k1`：

| 文档 | `|D|/4` | 长度因子 | `k1` × 长度因子 |
| --- | --- | --- | --- |
| 甲 | 9/4 | 31/16 = 1.9375 | 93/40 = 2.325 |
| 乙 | 3/4 | 13/16 = 0.8125 | 39/40 = 0.975 |
| 丙 | 1/2 | 5/8 = 0.625 | 3/4 = 0.75 |
| 丁 | 1/2 | 5/8 = 0.625 | 3/4 = 0.75 |

甲的一项：`f = 1`，分母是 `1 + 93/40 = 133/40`，词频因子是 `40/133`。两个词都如此，文档系数是 `80/133`。

乙只有「退货」，`f = 3`：

```text
3 / (3 + 39/40) = 3 / (159/40) = 120/159 = 40/53
```

丙只有「期限」，`f = 1`：`1 / (1 + 3/4) = 4/7`。丁两项都是 0。

| 文档 | 乘在 `ln 2` 上的系数 | 分数 | 四位小数 |
| --- | --- | --- | --- |
| 甲 | 80/133 | `(80/133) ln 2` | 0.4169 |
| 乙 | 40/53 | `(40/53) ln 2` | 0.5231 |
| 丙 | 4/7 | `(4/7) ln 2` | 0.3961 |
| 丁 | 0 | 0 | 0 |

顺序是乙、甲、丙、丁。乙更短，长度因子更小；「退货」出现三次，又还没饱和。单个词的上限是 IDF，也就是 `ln 2 ≈ 0.6931`。乙这一项已经走到上限的 `40/53 ≈ 0.7547`。甲每个词只走到 `40/133`。乙没有「期限」，但它这一个词的分数已经高于甲两个词的和。

相关集取 {甲}：只有甲写出了「七天」。召回率@1 = 0，召回率@2 = 1。|R| = 1 时，命中@k 和召回率@k 是同一个数。

综述还写了一组常见参数：`k1 = 2`、`b = 0.5`，并说明不少实验会把 `k1` 取得更低、把 `b` 取得更高。换成这组，系数变成甲 `8/17`、乙 `12/19`、丙 `2/5`，分数约是 0.3262、0.4378、0.2773。顺序仍然是乙、甲、丙、丁。参数变了，分数变了；在这四篇上，谁第一没有变。换一篇语料，这个「没有变」不必还在。

另一个常见变体是在分子上再乘 `(k1 + 1)`。综述写明：这个因子对每个词都一样，不改变排序；放进去是为了和没有长度归一化的 RSJ 权重对齐。`k1 + 1 = 11/5 = 2.2`。这个因子乘在没有收成四位的分数上，甲、乙、丙约是 0.9172、1.1509、0.8714，顺序不变。先把乙收成 0.5231 再乘 2.2，得到的是 1.1508。和评估笔记里先把标准误收位再乘一样，四位小数要留到最后一步。此时单个词的上限变成 `2.2 ln 2 ≈ 1.5249`，不再是 `ln 2`。和 Elasticsearch 或论文对分数时，先看分子里有没有 `k1 + 1`，再看 IDF 是式 (3.3) 还是 Lucene 那一式。

查询里若再加一个所有文档都没有的词，例如「几天」，这个词的 `f` 全是 0，贡献是 0，排序不变。若查询只剩「几天」，四篇都是 0 分。文档写的是「七」「天」，查询写的是「几天」，词对不上时 BM25 没有分数可用。稠密向量还有机会把这两句话排到一起；那要靠编码器，不是靠这个词表。

## 混合与交叉编码器重排

两路排序经常一起用。BM25 对上了的词很稳，对不上的词是 0。余弦或点积能把词面不同的块排上来，也会把一个很长的向量排到前面。混合要处理的是两套分数不在同一个尺度上。

余弦顺序是甲、丙、乙、丁。BM25 顺序是乙、甲、丙、丁。把本篇的 Lucene 式 BM25 和余弦直接相加：

```text
甲：0.4169 + 1      = 1.4169
乙：0.5231 + 0.5547 = 1.0778
丙：0.3961 + 0.7071 = 1.1032
丁：0      + 0.3162 = 0.3162
```

顺序变成甲、丙、乙、丁，和余弦相同。乙在 BM25 上对甲的领先约是 `0.5231 − 0.4169 = 0.1062`。甲在余弦上对乙的领先约是 `1 − 0.5547 = 0.4453`。更大的那一截决定了和。直接相加之前，两路分数还没有放到同一尺度。

Cormack、Clarke 与 Büttcher 的倒数排名融合（reciprocal rank fusion，RRF）只用名次。他们的分数是

```text
RRF(d) = Σ 1 / (k + r(d))
```

`r(d)` 从 1 起，1 是该路的第一名。`k = 60` 在他们的试点里定下，后面的验证没有再改。本篇用这个 60。

| 文档 | BM25 名次 | 余弦名次 | RRF |
| --- | --- | --- | --- |
| 甲 | 2 | 1 | `1/62 + 1/61 = 123/3782 ≈ 0.0325` |
| 乙 | 1 | 3 | `1/61 + 1/63 = 124/3843 ≈ 0.0323` |
| 丙 | 3 | 2 | `1/63 + 1/62 = 125/3906 ≈ 0.0320` |
| 丁 | 4 | 4 | `1/64 + 1/64 = 1/32 = 0.03125` |

`1/32 = 0.03125` 正好落在小数第四位的正中，这里保持分数，不收成四位。另外三个约是 0.0325、0.0323、0.0320。顺序是甲、乙、丙、丁。`k = 60` 把名次差压得很小，第一名仍然从乙换成了甲。相关集 {甲} 时，BM25 的召回率@1 是 0，RRF 的召回率@1 是 1。

重排是另一层。Nogueira 与 Cho 把查询和段落接成一次 BERT 的输入，用分类头打一个相关性分数。查询词和文档词在同一次注意力里见面。这种模型叫交叉编码器（cross-encoder）。Reimers 与 Gurevych、以及 DPR 的双编码器是两条塔：文档向量可以在查询到来之前算好，查询时只做一个点积或一次近似最近邻。交叉编码器的文档表示依赖这条查询，候选有多少，就要跑多少次成对的前向。所以它通常只打在前 m 篇上，不打全库。

对 BM25 的前三名另给一组教学用的 logit，同样不是某个 BERT 的输出：甲是 2，乙是 0，丙是 −1。sigmoid 单调，排名与 logit 相同。

```text
σ(2) = 1/(1 + exp(−2)) ≈ 0.8808
σ(0) = 1/2
σ(−1) = 1/(1 + e) ≈ 0.2689
```

重排后的顺序是甲、乙、丙。相关集 {甲} 时，拿去生成的列表在第 1 名就命中。重排改变的是这 m 篇的顺序，补不回没有进这 m 篇的文档。丁若没进候选，交叉编码器看不见它。

## 拼进提示，以及一次边缘化

生成时，下一次要采样的分布是

```text
p(y_t | 提示与已经拼进去的块, y_<t)
```

参数不动。多出来的条件就是这些块。温度作用在这个分布的 logit 上，不负责把没拼进来的句子找回来。

Lewis 等用两种方式把检索到的文档 `z` 加回去。检索器给出 `p(z | x)`，生成器给出 `p(y | x, z)`。RAG-Sequence 让同一篇 `z` 负责整个输出：

```text
p(y | x) ≈ Σ_z p(z | x) Π_t p(y_t | x, z, y_<t)
```

RAG-Token 允许每个位置选不同的文档，和式放在连乘里面。只生成一个 token 时，连乘只有一项，两式相同。

手算只用两篇，文档概率是为了算分数选的：`p(甲) = 3/5`，`p(乙) = 2/5`。它不是前面四个点积的 softmax。那个 softmax 已经把质量几乎全给了乙。

```text
p(七 | 甲) = 3/4，p(三 | 甲) = 1/4
p(七 | 乙) = 1/10，p(三 | 乙) = 9/10

p(七) = 3/5 × 3/4 + 2/5 × 1/10 = 9/20 + 1/25 = 49/100
p(三) = 3/5 × 1/4 + 2/5 × 9/10 = 3/20 + 9/25 = 51/100
```

只把甲放进条件，`3/4 > 1/4`，argmax 是「七」。边缘化之后 `51/100 > 49/100`，argmax 是「三」。温度取 0 也是这个 argmax。乙进了和式，就把概率往错误的天数上拉。甲自己仍把 `1/4` 放在「三」上：正确的块已经在条件里，参数分布还可以不同意它。

把甲和乙拼成同一条提示，再做一次前向，得到的是 `p(y | x, 甲接乙)`。这是一个条件，不是两个条件的加权和。边缘化要对每篇各跑生成概率再相加。拼接只跑一次，模型自己决定看哪一段。本篇没有一个真实模型，给不出拼接之后的概率；能算的是上面这个和式，以及下面这个预算。

块要占用上下文。推理优化那篇把多出来的 token 算进 prefill 和 KV cache。这里只问：预算砍掉以后，天数还在不在。

甲的 9 个词是「退货 的 期限 是 七 天 并且 需要 发票」。乙是三个「退货」。预算 7 个词，按顺序拼接，超出的尾巴丢掉。

```text
甲在前：退货 的 期限 是 七 天 并且
乙在前：退货 退货 退货 + 退货 的 期限 是
```

甲在前时，「七」和「天」都在。乙在前时，甲只能再贡献 4 个词，停在「是」，「七」被砍掉。检索阶段甲可以是第 2 名；提示里的第 1 名若先占掉预算，证据仍然进不了解码。

另一条规则是放不下就跳过、试下一块。预算 11。丙和丁各 2 个词，乙 3 个，甲 9 个。按从短到长：`2+2+3 = 7`，剩下 4，甲的 9 放不下，提示里没有甲。按重排后的甲、乙、丙：甲先放进 9 个词，剩下 2，乙的 3 放不下，丙的 2 正好放下。提示是甲和丙，「七」还在。两种装法用的是同一批分数、同一个窗口，提示里有没有天数可以不同。

Liu 等发现，相关文字已经放进长上下文之后，模型对它的使用仍然依赖位置：他们观察到，相关信息在上下文开头或结尾时，任务表现常常最高，放在中间时会明显变差。那是他们的模型和任务。本篇的预算例子更早一步：位置还没开始影响注意力之前，截断可以已经把「七」删掉了。

## 召回、忠实与引用

评估笔记要求先写明四件事。检索这一层要单写的是：相关集是哪一个，k 是多少，命中和召回率哪一个进了报告。生成这一层要单写的是：主张对照的是提示里的文本，还是被点名的那一块。

相关集 {甲, 丙}、点积排序时，召回率@2 = 1/2，命中@2 = 1。只报命中，看不出丙还没进来。回答「几天」时相关集只有甲，这和点积那一节不是同一个标注。BM25 的第一名是乙，召回率@1 = 0，召回率@2 = 1。把相关集改成「含有查询词的文档」之后，乙、甲、丙都算相关，召回率@1 变成 1/3，命中@1 变成 1。第一名仍然没有写出天数。相关集是指标的一部分。

生成结果里拆三条主张。这次提示里放的是甲的全文，不是预算 7 的那种截断。甲含有「七天」，也含有「需要发票」。丁是「天气 晴朗」。

| 主张 | 提示中的甲是否支持 | 回答点名的块 | 该块是否支持 |
| --- | --- | --- | --- |
| 期限是七天 | 支持 | 甲 | 支持 |
| 需要发票 | 支持 | 丙 | 不支持 |
| 周末不计入 | 不支持 | 丁 | 不支持 |

上下文忠实是主张被**提示里的文本**支持的比例，这里是 `2/3`。引用正确是被点名的那一块支持该主张的比例，这里是 `1/3`。第二条两边不同：甲里有发票，丙里没有。换一个引用对象，这一条就会从错变对；主张本身没有改。第三条在甲里也不存在，模型是在提示之外加了一句。

Es 等的 RAGAS 把「回答是否忠实于检索到的上下文」和检索自己的指标分开。Min 等的 FActScore 把长回答拆成原子事实，计算被一份知识源支持的比例；他们的源是传记对应的资料，不是本篇这三条。Rashkin 等的 AIS 问的是输出能否归因到标出来的来源，更接近这里的引用正确。`2/3` 和 `1/3` 是这三条主张上的计数，不是那些论文里的实验表。

一种把分数做高的办法，是改分母。上下文忠实若只统计模型自己标了引用的主张，第三条被拿掉，`2/3` 变成 `1`。召回率若把相关集收成「和查询有词重叠的块」，乙可以在第一名就贡献命中。两种改法都不需要把「七天」写对。

## 参考代码

分数用 Lucene 的 IDF 和式 (3.15) 的词频因子。召回率的分母是相关集的大小。

```python
import math


def cosine(query: list[float], vector: list[float]) -> float:
    def dot(left: list[float], right: list[float]) -> float:
        return sum(a * b for a, b in zip(left, right))

    return dot(query, vector) / math.sqrt(dot(query, query) * dot(vector, vector))


def bm25_term(tf: float, dl: float, avgdl: float, k1: float, b: float, idf: float) -> float:
    """式 (3.15)：idf × tf / (tf + k1 × (1 − b + b × dl / avgdl))。"""
    norm = (1.0 - b) + b * dl / avgdl
    return idf * tf / (tf + k1 * norm)


def rrf(ranks: list[int], k: int = 60) -> float:
    """名次从 1 起。Cormack 等把 k 固定为 60。"""
    return sum(1.0 / (k + rank) for rank in ranks)


def recall_at_k(ranked: list[str], relevant: set[str], k: int) -> float:
    if not relevant:
        raise ValueError("empty relevant set")
    return len(set(ranked[:k]) & relevant) / len(relevant)
```

## 容易算错的地方

- 余弦顺序是甲、丙、乙、丁。点积顺序是乙、甲、丙、丁。平方距离顺序是甲、丙、丁、乙。乙的三个数是点积 20、余弦约 0.5547、平方距离 100。
- 相关集 {甲, 丙} 时，点积的召回率@2 是 1/2，命中@2 是 1。
- 四个点积做 softmax，乙的概率大于 0.9999。
- 式 (3.3) 在 `N = 4`、`n = 2` 时是 `ln 1 = 0`。Lucene 的 IDF 是 `ln 2 ≈ 0.6931`。
- Lucene 默认参数下，甲、乙、丙约是 0.4169、0.5231、0.3961。`(k1+1)` 乘在未收位的分数上，约是 0.9172、1.1509、0.8714。先把 0.5231 乘 2.2，第四位会写成 1.1508。顺序都是乙、甲、丙、丁。
- `k1 = 2`、`b = 0.5` 时约是 0.3262、0.4378、0.2773，这一次顺序不变。
- RRF 约是 0.0325、0.0323、0.0320，丁是 `1/32 = 0.03125`。第一名是甲。直接相加约是 1.4169、1.0778、1.1032、0.3162，第一名也是甲，但丙排在乙前面。
- 边缘化：`p(七) = 49/100`，`p(三) = 51/100`。只条件在甲上时，「七」的概率是 3/4。
- 预算 7 且乙在前，拼出来的甲的部分是「退货 的 期限 是」，没有「七」。
- 上下文忠实是 2/3，引用正确是 1/3。差在「需要发票」这一条：甲支持它，丙不支持。
- `nprobe = 1` 的距离是 3，真近邻的距离是 2。`ef = 1` 停在距离 2，C 的距离是 1。

## 练习

### 练习 1：三种近邻和两种命中

- 目标：排序规则和相关集一起决定召回率。
- 限制：纸笔。余弦保留四位小数。
- 题面：用正文的 `q = (3, 1)` 和甲乙丙丁。写出三个点积、三个非 1 的余弦、四个平方距离。相关集 {甲, 丙} 时，余弦和点积的召回率@1、召回率@2、命中@1、命中@2 各是多少？
- 完成标准：点积 10、20、5、3。余弦约 0.5547、0.7071、0.3162。平方距离 0、100、5、13。余弦是 1/2、1、1、1。点积是 0、1/2、0、1。

<details>
<summary>参考解答</summary>

乙的余弦是 `2/sqrt(13)`，丙是 `1/sqrt(2)`，丁是 `1/sqrt(10)`。余弦的前两名是甲和丙，召回率从 1/2 到 1。点积的第一名是乙，前两名只多了甲，召回率是 0 和 1/2；命中在第 2 名变成 1。

</details>

### 练习 2：BM25 的两个 IDF

- 目标：IDF 的式子会把整表分数乘没。
- 限制：纸笔。`k1 = 1.2`，`b = 0.75`，用 Lucene 的 IDF。
- 题面：式 (3.3) 和 Lucene 的 IDF 各是多少？甲、乙、丙的系数和四位小数分数是多少？相关集 {甲} 时召回率@1 和召回率@2 是多少？乘上 2.2 之后三篇约是多少，顺序变不变？
- 完成标准：IDF 是 0 和 `ln 2 ≈ 0.6931`。系数 80/133、40/53、4/7，分数约 0.4169、0.5231、0.3961。召回率是 0 和 1。2.2 乘在未收位的分数上，约 0.9172、1.1509、0.8714，顺序仍是乙、甲、丙。

<details>
<summary>参考解答</summary>

`n = 2` 时比值是 1，式 (3.3) 为 0，Lucene 在比值外加 1，得到 `ln 2`。甲的长度项 `k1 × 31/16 = 93/40`，两个词各贡献 `40/133`。乙是 `40/53`。`(k1+1)` 对每篇相同，顺序不变。2.2 乘的是 `(40/53) ln 2` 本身；用已经收成 0.5231 的数去乘，第四位会少 0.0001。

</details>

### 练习 3：换一组 k1、b

- 目标：参数进分数，不一定进排序。
- 限制：纸笔或计算器。`k1 = 2`，`b = 1/2`，IDF 仍是 `ln 2`。
- 题面：甲、乙、丙乘在 `ln 2` 上的系数是多少？四位小数分数是多少？第一名还是乙吗？
- 完成标准：系数 `8/17`、`12/19`、`2/5`。分数约 0.3262、0.4378、0.2773。第一名仍是乙。

<details>
<summary>参考解答</summary>

甲的长度因子是 `13/8`，一词的因子是 `1/(1+13/4) = 4/17`，两词合起来是 `8/17`。乙的长度因子是 `7/8`，`3/(3+7/4) = 12/19`。丙是 `1/(1+3/2) = 2/5`。`12/19 > 8/17`，因为 `12×17 = 204`，`8×19 = 152`。

</details>

### 练习 4：相加和 RRF

- 目标：尺度和名次是两种混合。
- 限制：纸笔。`k = 60`。丁的 RRF 保持 `1/32`。
- 题面：BM25 加余弦，四篇约是多少，顺序是什么？RRF 的四个分数是什么，第一名是谁？相关集 {甲} 时，BM25 和 RRF 的召回率@1 各是多少？
- 完成标准：和约是 1.4169、1.0778、1.1032、0.3162，顺序甲、丙、乙、丁。RRF 是 `123/3782 ≈ 0.0325`、`124/3843 ≈ 0.0323`、`125/3906 ≈ 0.0320`、`1/32`。两路的第一名都是甲。召回率@1 从 0 变成 1。

<details>
<summary>参考解答</summary>

乙对甲的 BM25 领先约 0.1062，甲对乙的余弦领先约 0.4453，和跟着余弦走，所以丙也排在乙前面。RRF 只看名次：甲是第 2 和第 1，乙是第 1 和第 3。`123/3782 > 124/3843`，第一名换成甲。

</details>

### 练习 5：一个 token 的边缘化

- 目标：和式是解码时的另一种用法，和拼接不是同一个条件。
- 限制：纸笔。文档概率是 3/5 和 2/5。
- 题面：只条件在甲上时，「七」和「三」的概率是多少，argmax 是谁？边缘化之后两个概率是多少，argmax 是谁？为什么温度取 0 也不会回到「七」？
- 完成标准：3/4 和 1/4，argmax 是「七」。边缘化是 49/100 和 51/100，argmax 是「三」。温度 0 取的就是这个 argmax。

<details>
<summary>参考解答</summary>

`9/20 + 1/25 = 45/100 + 4/100 = 49/100`。`3/20 + 9/25 = 15/100 + 36/100 = 51/100`。和式已经把更多质量放在「三」上。拼接甲和乙是另一次前向，本篇没有那一次的概率。

</details>

### 练习 6：预算把「七」留在外面

- 目标：检索名次和提示里的词不是同一份名单。
- 限制：纸笔。用甲的 9 个词和乙的 3 个词。
- 题面：预算 7，甲在前和乙在前，提示里各有哪些词？「七」在不在？预算 11 且按短块优先（丙 2、丁 2、乙 3、甲 9），甲进得去吗？按甲、乙、丙的顺序跳过装入，放进哪几块？
- 完成标准：甲在前时含有「七」和「天」。乙在前时甲只贡献到「是」。短块优先放进丙、丁、乙，甲进不去。跳过装入放进甲和丙。

<details>
<summary>参考解答</summary>

乙占 3 个词，剩下 4 个，甲的前四个词是「退货 的 期限 是」。短块合计 7，剩下 4，小于 9。甲先占 9 个词，剩下 2，乙要 3 个，丙要 2 个。

</details>

### 练习 7：忠实和引用

- 目标：两个比例的分母都是主张数，分子看的文本不同。
- 限制：纸笔。用正文的三行表。
- 题面：上下文忠实和引用正确各是多少？哪一条主张造成了差距？若评测只统计写了引用的主张、并且模型没把第三条算进主张，忠实度会变成多少？
- 完成标准：2/3 和 1/3。差距在「需要发票」：甲支持，丙不支持。丢掉第三条之后，前两条都由甲支持，忠实度变成 1。

<details>
<summary>参考解答</summary>

提示里的甲盖住前两条，盖不住「周末不计入」。点名的块只有第一条对上。分母从 3 变成 2，而且剩下的两条都能在甲里找到，分子分母一起变。

</details>

### 练习 8：少看的那一次近邻

- 目标：近似的召回取决于没打开的桶和没走到的边。
- 限制：纸笔。
- 题面：IVF 的例子里，`nprobe = 1` 返回哪个点，距离是多少？真近邻的距离是多少？HNSW 在 `ef = 1` 时停在哪个点，距离是多少？C 的距离是多少？上层有 A—M 时，`ef = 1` 的下层入口是哪个点？
- 完成标准：返回 b，距离 3；a 的距离是 2。停在 B，距离 2；C 的距离是 1。下层入口变成 M。

<details>
<summary>参考解答</summary>

查询 6 离质心 10 更近，只打开 b 所在的表。a 在质心 0 的表里，距离是 2。底层没有 B—C 时，`ef = 1` 拒绝更远的 M，也就到不了 C。长边 A—M 把入口送到 M，M 的邻居 C 更近。

</details>
