## 完成时你能做什么

- 画出 decoder-only 的一次前向：token id → 嵌入与位置 → 若干层（注意力、前馈、残差、归一化）→ logits → 只在被监督的下一个 token 上算交叉熵。因果掩码使位置 `t` 看不到它右边的 token。
- 区分三种数据：预训练语料、SFT 的示范回答、偏好优化里同一提示下的优劣对。
- 说明 DPO 在 Bradley-Terry 假设下，把「奖励模型 + 带 KL 约束的策略优化」写成只含策略和参考模型对数概率的分类损失。它去掉的是单独的奖励模型和强化学习循环。
- 给一个任务设计小评估，并写出一种不解决任务也能提高分数的办法，例如测试题混进训练集。
- 说明 KV cache 保存已经算过的 key 和 value。新 token 只计算自己的 query，并与缓存做注意力。精确算术下结果与整段重算相同。显存随序列长度和层数增长。

## 术语先固定在这里

下面这些段落只固定词义，避免以后各篇对同一个词各写各的。公式和实现留在还没写的笔记里。

**分词器（tokenizer）。** 它规定字符串怎样变成整数序列，以及整数序列怎样解回字符串。模型读到的是整数。

**因果语言模型。** 用链式法则把联合分布写成从左到右的条件分布。位置 `t` 的输入是已经确定的前缀，预测对象是下一个 token。

**嵌入与位置。** 嵌入把 token id 变成向量。位置信息告诉模型这些向量的顺序。绝对位置和相对位置是两类做法。RoPE 用旋转把位置写进 query 和 key，使它们的点积依赖相对位移。

**Attention。** 由 query 与 key 的点积得到权重，再对 value 加权求和。缩放点积把点积除以 `sqrt(d_k)`，避免维度变大时点积的尺度把 softmax 推进梯度很小的区域。多头是多组这样的运算拼接后再做线性变换。因果掩码在 softmax 之前把未来位置设为不参与，使那些位置的权重为 0。

**Transformer 块。** 常见组成是注意力子层和前馈子层，各自配残差。归一化可以放在子层之前或之后，现代大模型多用前置归一化。具体论文图以 Vaswani 等 2017 为准，现代实现的差异在结构笔记里对照，不在这里混成一张图。

**解码器为主。** 生成式大模型通常只保留从左到右的解码器。编码器模型（例如 BERT）双向看上下文，适合当时的理解式微调；编码器-解码器（例如 T5）把输入和输出分成两段。认得这三种拓扑，是为了读论文时知道掩码不同。

**一组现代组件的动机。** RMSNorm 用均方根缩放，通常不减均值。SwiGLU 是带门控的前馈，用来替换原来的两层前馈。GQA 让多个 query 头共享较少的 key/value 头，以减小 KV cache；MQA 是所有 query 头共享一组 key/value 的极端情形。第一版要求认得动机，不要求默写实现。

**预训练。** 在大规模文本上做下一个 token 预测，得到一个通用条件分布。数据混合物、去重、训练步数都是这个阶段的算法问题。Kaplan 与 Hoffmann 等人的扩展规律，是特定设定下损失随规模变化的经验拟合。用它帮助分配参数量和数据量。换数据或换架构后，系数可以变。Chinchilla 工作的实践含义是：在他们研究的算力设定下，当时不少模型相对数据来说参数过大。自己的设定要重新估计。

**SFT。** 数据是提示和期望回答。损失仍是下一个 token 的交叉熵，通常只落在回答部分，提示只作为条件。它让模型模仿这些回答。它不比较两个回答谁更好。

**RLHF 与 PPO。** 偏好数据说的是同一提示下哪个回答更好。常见流程先训练奖励模型，再用策略优化提高奖励，并用对参考策略的 KL 惩罚限制偏离。PPO 用概率比的裁剪限制一次更新的步长。裁剪的是策略更新，KL 惩罚限制的是相对参考策略的漂移。二者都在缓解奖励模型被钻空子，机制不同。

**DPO。** 见上面的完成标准。训练样本仍是偏好对，损失里仍出现参考模型。

**评估。** 困惑度衡量模型分配给真实续写的概率。任务成功率、格式正确率、事实性要另测。基准分数和「这些题是否可能出现在训练集」一起解释。模型当裁判可以扩大规模，裁判自身的偏好也会进结果。

**RAG。** 先检索外部文本，再让模型在这些文本的条件下生成。失败常来自检索不相关、切块把证据拆开，或回答不按检索内容说。检索要有自己的指标。

**智能体。** 模型在循环里根据状态决定是否调用工具、调用哪一个、参数是什么，再把工具结果写回状态。它适合必须读外部系统或必须多步查找的任务。一轮就能答的问题，多一步就多一处延迟和失败。

**推理与服务。** 解码策略把下一个 token 的分布变成一个具体 token。KV cache、连续批处理和量化决定延迟、吞吐和显存。量化用更少的位数保存权重或激活，输出分布可能改变。FlashAttention 计算的是同一种注意力，改变的是访存方式，它不是一种近似注意力。

**数据侧。** 重复文档会改变模型见到的分布，也可能让评估题以另一种形式出现在训练里。合成数据会把生成模型自己的偏好写回训练集。配比是在几种数据之间分配训练 token 的比例。这三件事都要在实验记录里能查到。
