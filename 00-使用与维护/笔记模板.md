# 笔记模板

复制本页结构写新笔记。删掉灰色说明，保留对读者有用的小节。没有内容的小节直接删去，不要留「待补充」。

状态只用两个词：

- `笔记已写`：可以开始学。
- `地图`：路线图里已经有位置，这一篇还没写。地图不单独建文件。

```markdown
# 标题

| 项 | 内容 |
| --- | --- |
| 阶段 | 例如：06-大语言模型 |
| 状态 | 笔记已写 |
| 前置 | 需要先会什么。写技能，不写「读完某一本书」。 |
| 本篇之后 | 下一篇计划写什么；若还没有文件，写「尚未写」。 |

## 本篇要回答的问题

1. 用完整的句子写出 2 到 5 个问题。读完正文和练习之后，读者要能不看笔记回答。

## 定义

先给后面会反复用的对象。每个定义配一个该定义排除了什么容易混进来的东西，用一句肯定句写清楚边界。

## 推导或过程

只推本篇真正要用的那几步。每一步写输入是什么、输出是什么。

## 一个完整的小例子

数字要小到能手算。最终用到的数字应能被 `python3 tools/check_worked_examples.py` 复核，或者在篇内说明它为什么是符号例子、不进脚本。

## 在算法工作里会在哪里再见到

用表格或短段落指向后面的阶段。还没有笔记的主题，写路线图里的名字，不要链接到不存在的文件。

## 容易算错的地方

每条先写正确做法，再写一个会触发错误的具体输入或形状。

## 练习

练习使用 [`练习模板`](练习模板.md)。参考解答默认折叠。

## 本篇之外

这一篇故意不讲什么，以及它属于哪一条后续笔记。

## 文献

- 核心文献写全名和链接，并在阅读清单里有同一条目。
- 教材写书名和用途。不贴章节正文。

## 修订

| 日期 | 改动 |
| --- | --- |
| YYYY-MM-DD | 初稿。 |
```

## 论文笔记

论文笔记也放在对应阶段目录，文件名用 `论文-短标题.md`。第一版还没有样例论文笔记，格式以这里为准。

```markdown
# 论文：标题

| 项 | 内容 |
| --- | --- |
| 文献 | 作者，年份，链接 |
| 阅读遍数 | 第一遍 / 第二遍 / 第三遍 |
| 日期 | YYYY-MM-DD |

## 它声称解决的问题

五句以内，用自己的话。每句能指回论文的节、图或表。

## 方法的输入和输出

包括数据单位（token、文档、偏好对）和模型更新了什么。

## 关键假设

假设不成立时，方法会怎样失败。

## 证据

作者用什么基线、什么数据。哪一条证据最关键，哪一条还没说服你。

## 我要核对的最小实验

数据小到什么程度，指标是什么，什么结果会推翻我现在的理解。做不到的实验写明卡在算力、数据还是缺少官方代码，不要写成已经做了。

## 仍不确定的点

具体到公式、形状或实验设定。
```
