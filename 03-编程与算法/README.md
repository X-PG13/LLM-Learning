## 完成时你能做什么

- 由数据规模判断一个 `O(n²)` 的解能不能用。
- 独立实现并测试：二分边界、在答案上的二分、有序双指针、滑动窗口、图的 BFS、一道状态定义清楚的 DP、用堆取当前极值。
- 给自己的实现写不变量。隔周重写时靠不变量，不靠记忆代码。
- 大约 40 道覆盖这些模式的题，自己做对过，并且能重写。
- 给训练步里的下标错误写出一个会失败的测试。开篇的二分 bug 就是这种测试的样品。
- 说明 float64 在 1 附近的间距是 `2⁻⁵²`，并指出同一组数的两种求和顺序可以差 1。
- 从右边对齐两个形状，判断能否广播；两个维长度相同时，指出向量落在哪一维。
- 对 `(n, k)` 乘 `(k, m)` 写出乘法次数，并说明矩阵乘的库函数不改变这个次数。
- 写出带掩码平均的分子和分母。分母是被计入的位置数。

## 这一阶段不追求

按题号刷完某个题库，收集没有不变量的模板，或者在正确性还没钉住时做指令级优化。哈希表在平均意义上说 `O(1)`，冲突可以使单次操作退化。这个差别在 [哈希、堆与搜索模式](02-哈希堆与搜索模式.md) 里用同一条链算过。浮点部分停在间距、结合律、广播和归约的分母，不把全部舍入模式当成必须背下来的表。
