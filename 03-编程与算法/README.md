## 完成时你能做什么

- 由数据规模判断一个 `O(n²)` 的解能不能用。
- 独立实现并测试：二分边界、有序双指针、图的 BFS、一道状态定义清楚的 DP、用堆取当前极值。
- 给自己的实现写不变量。隔周重写时靠不变量，不靠记忆代码。
- 大约 40 道覆盖这些模式的题，自己做对过，并且能重写。题单和题解留在仓库外面。
- 给训练步里的下标错误写出一个会失败的测试。开篇的二分 bug 就是这种测试的样品。

## 这一阶段不追求

按题号刷完某个题库，收集没有不变量的模板，或者在正确性还没钉住时做指令级优化。哈希表在面试里说平均 `O(1)`，同时知道冲突可以使单次操作退化。这个提醒放在开篇，单独的哈希笔记再展开。
