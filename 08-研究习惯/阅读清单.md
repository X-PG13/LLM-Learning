# 阅读清单

外部论文、文档、课程和书籍按阶段列在这里。用法有三种：

- **先读**：短，或者是该主题的规定文献。不是要求在写代码前把清单读完。
- **选读**：课程或长文，按阶段取用相关部分。
- **查阅**：写到对应主题、需要对齐定义时再打开。

## 数学

<a id="3b1b-linalg"></a>
**3Blue1Brown，Essence of Linear Algebra。** 先读。几何直觉，配线性代数开篇。  
<https://www.3blue1brown.com/?topic=linear-algebra>

<a id="strang-1806"></a>
**Gilbert Strang，MIT 18.06 Linear Algebra。** 选读。方程组、投影、特征值。  
<https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/>

<a id="d2l-zh-linalg"></a>
**《动手学深度学习》中文版，线性代数预备。** 先读。符号和深度学习里的形状更近。  
<https://zh.d2l.ai/chapter_preliminaries/linear-algebra.html>

<a id="mit-6041"></a>
**MIT 6.041SC Probabilistic Systems Analysis。** 选读。条件概率、期望、常见分布。  
<https://ocw.mit.edu/courses/6-041sc-probabilistic-systems-analysis-and-applied-probability-fall-2013/>

<a id="stat110"></a>
**Harvard Stat 110 公开播放列表（Blitzstein）。** 选读。与 6.041 二选一深入即可，不两门都当作业。  
<https://www.youtube.com/playlist?list=PL2SOU6wwxB0uwwH80KTQ6ht66KWxbzTIo>

<a id="d2l-zh-prob"></a>
**《动手学深度学习》中文版，概率预备。** 先读。用来对齐条件概率的符号。  
<https://zh.d2l.ai/chapter_preliminaries/probability.html>

<a id="mackay"></a>
**David MacKay，Information Theory, Inference, and Learning Algorithms。** 选读。只读熵、交叉熵、KL 相关章。全书免费公开。  
<https://www.inference.org.uk/mackay/itila/>

<a id="boyd"></a>
**Boyd、Vandenberghe，Convex Optimization。** 查阅。需要凸、对偶或约束优化的严格表述时。全书由作者公开。  
<https://web.stanford.edu/~boyd/cvxbook/>

<a id="d2l-math-appendix"></a>
**d2l.ai 英文版数学附录。** 查阅。特征值、极大似然等短章。中文版章节结构和这里不完全相同，不要把英文附录的路径套到中文站。  
<https://d2l.ai/chapter_appendix-mathematics-for-deep-learning/index.html>

## 语言模型与论文

<a id="shannon-1948"></a>
**Shannon，1948，A Mathematical Theory of Communication。** 选读。读导论级的熵定义即可。这里链的是一个公开副本。  
<https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf>

<a id="sennrich-2016"></a>
**Sennrich、Haddow、Birch，2016，子词单元。** 先读。BPE 进入神经机器翻译的规定论文。  
<https://arxiv.org/abs/1508.07909>

<a id="vaswani-2017"></a>
**Vaswani 等，2017，Attention Is All You Need。** 先读。结构笔记的规定论文。  
<https://arxiv.org/abs/1706.03762>

<a id="alammar-transformer"></a>
**Jay Alammar，The Illustrated Transformer。** 先读。图示。定义以 Vaswani 等为准。  
<https://jalammar.github.io/illustrated-transformer/>

<a id="annotated-transformer"></a>
**Harvard NLP，The Annotated Transformer。** 选读。自己实现时对照形状。与论文图不一致时记下来。  
<https://nlp.seas.harvard.edu/annotated-transformer/>

<a id="gpt2-2019"></a>
**Radford 等，2019，Language Models are Unsupervised Multitask Learners（GPT-2）。** 选读。字节级 BPE 和生成式预训练的公开说明。  
<https://cdn.openai.com/better-language-models/language_models_are_unsupervised_multitask_learners.pdf>

<a id="gpt3-2020"></a>
**Brown 等，2020，Language Models are Few-Shot Learners。** 选读。读问题设定和实验规模，不把文中的所有任务分数当成当前模型的水平。  
<https://arxiv.org/abs/2005.14165>

<a id="kaplan-2020"></a>
**Kaplan 等，2020，Scaling Laws for Neural Language Models。** 选读。经验拟合，使用时写下数据与架构假定。  
<https://arxiv.org/abs/2001.08361>

<a id="chinchilla-2022"></a>
**Hoffmann 等，2022，Training Compute-Optimal Large Language Models。** 选读。给定算力下参数量和数据量的权衡。  
<https://arxiv.org/abs/2203.15556>

<a id="wei-cot-2022"></a>
**Wei 等，2022，Chain-of-Thought Prompting。** 选读。提示格式怎样改变多步推理的评测表现。  
<https://arxiv.org/abs/2201.11903>

<a id="instructgpt-2022"></a>
**Ouyang 等，2022，Training Language Models to Follow Instructions with Human Feedback。** 先读。SFT、奖励模型和 PPO 这条流程的规定论文。  
<https://arxiv.org/abs/2203.10752>

<a id="ppo-2017"></a>
**Schulman 等，2017，Proximal Policy Optimization。** 查阅。写到 RLHF 的策略更新时核对裁剪目标，不作为强化学习的第一门课。  
<https://arxiv.org/abs/1707.06347>

<a id="dpo-2023"></a>
**Rafailov 等，2023，Direct Preference Optimization。** 先读。偏好损失与参考模型对数概率。  
<https://arxiv.org/abs/2305.18290>

<a id="rag-2020"></a>
**Lewis 等，2020，Retrieval-Augmented Generation。** 先读。检索加生成的规定论文。  
<https://arxiv.org/abs/2005.11401>

<a id="nucleus-2019"></a>
**Holtzman 等，2020，The Curious Case of Neural Text Degeneration。** 选读。top-p 采样。  
<https://arxiv.org/abs/1904.09751>

<a id="lora-2021"></a>
**Hu 等，2022，LoRA。** 选读。低秩增量的参数化。线性代数开篇只算了参数量。  
<https://arxiv.org/abs/2106.09685>

<a id="rope-2021"></a>
**Su 等，2024 年期刊版 / 2021 年预印本，RoFormer。** 选读。旋转位置编码。打开论文核对你引用的版本。  
<https://arxiv.org/abs/2104.09864>

<a id="flashattention-2022"></a>
**Dao 等，2022，FlashAttention。** 选读。同一种注意力的访存改造，不是近似算法。  
<https://arxiv.org/abs/2205.14135>

<a id="zero-2019"></a>
**Rajbhandari 等，2020，ZeRO。** 选读。数据并行下优化器状态、梯度和参数的切分。  
<https://arxiv.org/abs/1910.02054>

<a id="dedup-2021"></a>
**Lee 等，2022，Deduplicating Training Data Makes Language Models Better。** 选读。重复数据同时影响训练分布和评估。  
<https://arxiv.org/abs/2107.06499>

<a id="gqa-2023"></a>
**Ainslie 等，2023，GQA。** 查阅。减少 KV 头的数量。  
<https://arxiv.org/abs/2305.13245>

<a id="mqa-2019"></a>
**Shazeer，2019，Fast Transformer Decoding（MQA）。** 查阅。所有 query 头共享一组 KV 的极端情形。  
<https://arxiv.org/abs/1911.02150>

<a id="qlora-2023"></a>
**Dettmers 等，2023，QLoRA。** 查阅。量化基座加上低秩更新。  
<https://arxiv.org/abs/2305.14314>

<a id="llama2-2023"></a>
**Touvron 等，2023，Llama 2。** 查阅。公开的模型报告，用来对照架构和 RLHF 流程。技术报告里的分数单独批判地看。  
<https://arxiv.org/abs/2307.09288>

<a id="qwen2-2024"></a>
**Yang 等，2024，Qwen2 Technical Report。** 查阅。中文社区常用模型的公开报告。读架构和数据披露，不把榜单分数当成方法证明。  
<https://arxiv.org/abs/2407.10671>

<a id="sentencepiece-2018"></a>
**Kudo、Richardson，2018，SentencePiece。** 查阅。与词内 BPE 不同的一种预处理。  
<https://arxiv.org/abs/1808.06226>

<a id="unigram-2018"></a>
**Kudo，2018，Subword Regularization。** 查阅。Unigram 语言模型分词，和 BPE 的合并方向不同。  
<https://arxiv.org/abs/1804.10959>

<a id="bert-2018"></a>
**Devlin 等，2019，BERT。** 查阅。双向编码器。用来对比因果解码器的掩码，不作为生成模型的主线。  
<https://arxiv.org/abs/1810.04805>

<a id="word2vec-2013"></a>
**Mikolov 等，2013，Efficient Estimation of Word Representations in Vector Space。** 查阅。嵌入的历史入口。  
<https://arxiv.org/abs/1301.3781>

<a id="mmlu-2020"></a>
**Hendrycks 等，2021，MMLU。** 查阅。知道这项基准在测多任务知识题，同时检查题目是否可能进过训练集。  
<https://arxiv.org/abs/2009.03300>

<a id="helm-2022"></a>
**Liang 等，Holistic Evaluation of Language Models（HELM）。** 查阅。评估要同时报告多个指标和场景，而不是单一分数。预印本公开于 2022 年。  
<https://arxiv.org/abs/2211.09110>

<a id="schaeffer-2023"></a>
**Schaeffer、Miranda、Koyejo，2023，Are Emergent Abilities a Mirage?** 选读。用来约束「涌现」这个词，把它和指标的选择连在一起。  
<https://arxiv.org/abs/2304.15004>

<a id="glu-2020"></a>
**Shazeer，2020，GLU Variants Improve Transformer。** 查阅。写 SwiGLU 的公式时打开。  
<https://arxiv.org/abs/2002.05202>

<a id="d2l-zh-transformer"></a>
**《动手学深度学习》中文版，Transformer 一章。** 选读。中文讲解。定义仍以 Vaswani 等为准。  
<https://zh.d2l.ai/chapter_attention-mechanisms/transformer.html>
