# 阅读清单

外部论文、文档、课程和书籍按阶段列在这里。用法有三种：

- **先读**：短，或者是该主题的规定文献。不是要求在写代码前把清单读完。
- **选读**：课程或长文，按阶段取用相关部分。
- **查阅**：写到对应主题、需要对齐定义时再打开。

**《动手学深度学习》中文版，Transformer 一章。** 选读。中文讲解。定义仍以 Vaswani 等为准。  
<https://zh.d2l.ai/chapter_attention-mechanisms/transformer.html>

<a id="pagedattention-2023"></a>
**Kwon 等，2023，PagedAttention。** 先读。KV cache 分成固定块，用块表映射到不必连续的物理块。vLLM 建在这套分页上。  
<https://arxiv.org/abs/2309.06180>

<a id="orca-2022"></a>
**Yu 等，2022，Orca。** 选读。迭代级调度：一个迭代结束就可以换请求。选择批处理把长度不同的注意力按请求分开算。  
<https://www.usenix.org/system/files/osdi22-yu.pdf>

<a id="speculative-2023"></a>
**Leviathan、Kalman、Matias，2023，Speculative Decoding。** 先读。接受率在独立同分布的假设下，一轮期望产出 `(1−α^{γ+1})/(1−α)` 个 token。  
<https://arxiv.org/abs/2211.17192>

<a id="speculative-sampling-2023"></a>
**Chen 等，2023，Speculative Sampling。** 选读。同一类验证。抽样分布与目标模型一致。  
<https://arxiv.org/abs/2302.01318>

<a id="gptq-2023"></a>
**Frantar 等，2023，GPTQ。** 先读。一次量化，用近似二阶信息决定舍入。分组是更细的缩放。  
<https://arxiv.org/abs/2210.17323>

<a id="llm-int8-2022"></a>
**Dettmers 等，2022，LLM.int8()。** 先读。absmax 缩放到 `[-127, 127]`；离群特征维留在 16 位。  
<https://arxiv.org/abs/2208.07339>

<a id="roofline-2009"></a>
**Williams、Waterman、Patterson，Roofline。** 选读。可达速度取峰值浮点和「带宽 × 运算强度」的较小者。这里链伯克利技术报告 EECS-2008-134。  
<https://www2.eecs.berkeley.edu/Pubs/TechRpts/2008/EECS-2008-134.html>

<a id="mistral-2023"></a>
**Jiang 等，2023，Mistral 7B。** 查阅。表 1 的层数、KV 头和滚动窗口。显存例子用的是这张表。  
<https://arxiv.org/abs/2310.06825>

<a id="hf-generation"></a>
**Hugging Face，生成策略。** 查阅。贪心、采样、束搜索的接口。分布的定义以课程笔记为准。  
<https://huggingface.co/docs/transformers/generation_strategies>

## 研究习惯

<a id="pineau-2021"></a>
**Pineau 等，2021，Improving Reproducibility in Machine Learning Research。** 选读。NeurIPS 2019 可复现计划的报告：代码政策、复现挑战、可复现清单。预印本公开于 2020 年。  
<https://arxiv.org/abs/2003.12206>

<a id="repro-checklist-2019"></a>
**Pineau，机器学习可复现清单 1.2 版（2019-03-27）。** 先读。训练、验证、测试怎样划分，超参数怎样选，跑了多少次，计算设备是什么。  
<https://www.cs.mcgill.ca/~jpineau/ReproducibilityChecklist-v1.2.pdf>

<a id="neurips-2019-cfp"></a>
**NeurIPS 2019 征稿说明。** 查阅。当年要求回答可复现清单，并试行代码提交。  
<https://neurips.cc/Conferences/2019/CallForPapers>

<a id="neurips-checklist"></a>
**NeurIPS 现行论文清单。** 查阅。在 2019 年的可复现条目之外，还写入伦理和更广的报告项。  
<https://neurips.cc/public/guides/PaperChecklist>

<a id="bouthillier-2019"></a>
**Bouthillier、Laurent、Vincent，2019，Unreproducible Research is Reproducible。** 选读。固定种子能重跑出同一个数；换种子之后，排序仍可能变。  
<https://proceedings.mlr.press/v97/bouthillier19a.html>

<a id="dodge-2019"></a>
**Dodge 等，2019，Show Your Work。** 选读。验证集上最好成绩的期望怎样随尝试次数变化。  
<https://arxiv.org/abs/1909.03004>

<a id="henderson-2018"></a>
**Henderson 等，2018，Deep Reinforcement Learning that Matters。** 查阅。超参数、种子、环境非确定性和代码库都会进入「是否更好」的比较。预印本公开于 2017 年。  
<https://arxiv.org/abs/1709.06560>

<a id="melis-2018"></a>
**Melis、Dyer、Blunsom，2018，On the State of the Art of Evaluation in Neural Language Models。** 选读。超参数搜索的预算对齐之后，普通 LSTM 可以和当时更复杂的模型处在同一档。预印本公开于 2017 年。  
<https://arxiv.org/abs/1707.05589>
