# 研究习惯

读论文是这条路线的工作方式，不是读完所有阶段之后的选修。从第一周起就按固定的问法做第一遍，深度随着主线增加。

| 项 | 内容 |
| --- | --- |
| 前置 | 无。公式看不懂时，第一遍只要求指出看不懂的那一节 |
| 建议顺序 | 先读方法笔记，再从阅读清单选一篇「先读」。三遍法里的第三遍只给准备实现或准备依赖的论文 |
| 现在就能读 | [01-怎样读一篇论文](01-怎样读一篇论文.md)，[阅读清单](阅读清单.md) |

## 完成时你能做什么

- 至少写过 3 篇论文笔记，写法见 [怎样读一篇论文](01-怎样读一篇论文.md)。每篇能指出主张、假设和不确定的点，并且每条主张能指回论文里的位置。
- 为一篇准备依赖的论文写下最小核对实验：数据多小、看哪个数、什么结果说明自己理解错了。做不到时写明卡在算力、数据或代码，不把计划写成结论。
- 阅读清单里标为「先读」的材料都读过。

## 外部材料

论文、文档、课程和书籍列在 [阅读清单](阅读清单.md)，每条注明用途。博客和图示用来看结构。笔记里的主张要能指回论文或官方文档。
