## 本篇要回答的问题

1. 五个配对差的均值、样本标准差、均值的标准误，各自除以谁？同一张表上忽略配对，标准误会从约 `0.0707` 变成多少？
2. 均值是 `-0.16` 时，`1.96`、自由度 4 的 `2.776`、以及 `2.132`，哪几个区间包含 0？均值是 `-0.3` 时，t 区间不含 0，为什么「至少低 0.2」仍被推翻？
3. 两边标准误都是 `0.1`、均值之差是 `-0.45` 时，为什么各自的 t 区间重叠，差的 t 区间仍然不含 0？把没有共用种子的两列按位置相减，标准误变成多少？
4. 五次里最好的一次、删掉一次没有有限损失之后的均值、五个独立部件里至少一次区间不含 0 的概率，各把哪一条事先写的线换掉了？

## 表上的 ± 要写明是哪一个数

[最小可核对实验](02-最小可核对实验.md) 把一句主张收成声明、因变量、基线、变量和消融。固定一个种子，得到的是这一次运行的数。主张若是「换种子之后仍然更好」，一次运行没有回答它。Bouthillier、Laurent、Vincent 把这两件事分开：种子固定，同一次运行可以重跑出同一个数；换一个种子，排序仍可能换。他们的图以论文为准，这里不搬。

Pineau 的可复现清单要求写：评估跑了多少次，中心和变化是多少（例如均值和标准差），以及误差条。标准差和误差条不是同一个数。`±` 后面不写是哪一个，这格就没有填完。

本篇把一次消融的五次种子算成这几个数。消融仍是只改一个部件，其余设置不动。学习率若只在新部件上重搜过，差里面就还有搜索。那一格怎样拆，见最小核对里的四格和 `15/16`。这里的因变量是验证集上、按被监督 token 平均的 NLL，对数是 ln。差一律是改动减基线。负的差表示改动的 NLL 更低。

下面的数是为了把除法和区间算完而设的，不是某次训练的输出。论文表格里的分数仍以那篇论文为准。

用标准误乘一个事先指定的分位数，得到的区间也叫置信区间。后文就称区间。评估笔记在题数上用 `1.96`。本篇的 `n` 是种子数，不是题数。五次种子、每次 100 题，不是 `n = 500`。

## 五个配对的差

配对是指同一个种子编号跑两遍：初始化、数据顺序和优化器用这一个种子，只把部件从基线换成改动。一对差来自同一个种子。评估笔记的一对来自同一道题。两处不要合成一个 `n`。

| 种子 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| 基线 | 1.9 | 2.2 | 2.5 | 2.3 | 2.1 |
| 改动 | 1.6 | 2.0 | 2.4 | 2.3 | 2.2 |
| 差 | -0.3 | -0.2 | -0.1 | 0.0 | 0.1 |

基线的均值是 `(1.9 + 2.2 + 2.5 + 2.3 + 2.1) / 5 = 2.2`。改动的均值是 `(1.6 + 2.0 + 2.4 + 2.3 + 2.2) / 5 = 2.1`。五个差的均值是 `-0.1`，等于 `2.1 - 2.2`。

差相对 `-0.1` 的偏离是 `-0.2, -0.1, 0, 0.1, 0.2`。

```text
平方和 = 0.04 + 0.01 + 0 + 0.01 + 0.04 = 0.10
s² = 0.10 / 4 = 0.025
s = sqrt(0.025) ≈ 0.1581
SE = sqrt(0.025 / 5) = sqrt(0.005) ≈ 0.0707
```

`s²` 除以 `n - 1 = 4`。这是统计笔记里的样本方差。`s ≈ 0.1581` 是这五个差彼此散开的尺度，用来描述再来一个种子时差的起伏。`SE ≈ 0.0707` 是这五个差的均值的标准误，用来描述这个均值再抽五次会怎样晃。`± 0.1581` 和 `± 0.0707` 回答的不是同一句。清单里的「标准差」对上 `s`，「误差条」若画的是均值的不确定性，对上 `SE` 或下面的区间，而不是把 `s` 再叫做标准误。

平方和若除以 `n = 5`，得到 `0.02`。再用它做标准误：`sqrt(0.02 / 5) = sqrt(0.004) ≈ 0.0632`。它是 `0.0707` 的 `sqrt(4/5) ≈ 0.8944` 倍。统计笔记已经算过：除以 `n` 的方差估计期望偏小。种子只有 5 个时，标准误用除以 4 的 `s²`。

### 忽略配对会把标准误算大

基线五个数相对 `2.2` 的平方和是 `0.20`，`s² = 0.05`，`SE = sqrt(0.05 / 5) = 0.1`。改动五个数相对 `2.1` 的平方和是 `0.40`，`s² = 0.10`，`SE = sqrt(0.10 / 5) = sqrt(0.02) ≈ 0.1414`。

把两边当成没有配对的两次独立实验，差的均值的标准误是

```text
sqrt(0.1² + 0.02) = sqrt(0.01 + 0.02) = sqrt(0.03) ≈ 0.1732
```

配对之后的标准误约是 `0.0707`。忽略配对，标准误放到约 `0.1732`。这张表上差更稳。配对本身不保证标准误变小：两个序列负相关时，配对的标准误会更大。评估笔记里，同一批题上忽略协方差也会把标准误算大。种子上的配对用的是同一条恒等式，`n` 换成种子数。

## 分位数要事先写死

区间是 `均值 ± 分位数 × SE`。分位数在看见这五个差之前写下来。自由度取 `n - 1 = 4`。NIST 手册的 t 表里，自由度 4 的一行，`0.975` 列是 `2.776`，`0.95` 列是 `2.132`。双侧 95% 用 `2.776`，双侧 90% 用 `2.132`。Student 1908 给出的是这个分布。本篇不推密度，乘法就用表上的 `2.776` 和 `2.132`。这张表对应的模型是：五个差独立，来自同一个正态，标准差未知、用 `s` 估计。差明显不对称，或者种子之间还共享别的随机性，覆盖率就对不上表。评估笔记的题数是 100，那里用正态的 `1.96`。五个种子仍用 `1.96`，区间会偏窄。

`SE` 先不收成四位，乘完再收。下面半宽都是这样来的。

```text
2.776 * sqrt(0.005) ≈ 0.1963
1.96 * sqrt(0.005) ≈ 0.1386
2.132 * sqrt(0.005) ≈ 0.1508
```

均值 `-0.1` 时，三个区间约是

```text
2.776：[-0.2963, 0.0963]
1.96：[-0.2386, 0.0386]
2.132：[-0.2508, 0.0508]
```

三个都包含 0。点估计是负的，这张表在这三条事先可以写出的线下，都还不能把改动排在基线前面。

把五个差各再减 `0.06`，得到 `-0.36, -0.26, -0.16, -0.06, 0.04`。这 `0.06` 是为了落在两个分位数之间而设的。偏离仍是 `-0.2, -0.1, 0, 0.1, 0.2`，所以 `s` 和 `SE` 不变。均值变成 `-0.16`。

```text
2.776：[-0.3563, 0.0363]，包含 0
1.96：[-0.2986, -0.0214]，不含 0
2.132：[-0.3108, -0.0092]，不含 0
```

事先写的是双侧 95% 的 t 区间，这张表没有过 0。换成 `1.96`，或者改口说当初要的是 90%，区间就不含 0。分位数是看见上端大于 0 之后改的，改的是线，不是这五个差。最小核对要求推翻条件写在跑之前，这里的分位数就是那条线的一部分。

有人把「区间不含 0」叫做显著。在本篇，这个词只表示：在事先写定的分位数下，区间落在 0 的一侧。它不是「零假设为假」的概率，也不量出差有多大。Wasserstein、Lazar 的 ASA 声明把这两件事和「过了一道阈值」分开。本篇不把区间再换算成一个 p 值。

## 过了 0，还要看事先写的幅度

五个差改成 `-0.5, -0.4, -0.3, -0.2, -0.1`。均值是 `-0.3`。偏离仍是 `-0.2, -0.1, 0, 0.1, 0.2`，`SE` 仍约是 `0.0707`。

```text
2.776：[-0.4963, -0.1037]
1.96：[-0.4386, -0.1614]
```

两个区间都不含 0。事先若写的是「均值更低」，按 `2.776` 这张表过了 0。事先若写的是「均值至少低 0.2」，也就是整个区间要落在 `-0.2` 或更低，上端 `-0.1037` 仍高于 `-0.2`，这句被推翻。`1.96` 的上端 `-0.1614` 也高于 `-0.2`。过了 0 和过了 `-0.2` 是两道线。幅度线同样要在看见结果之前写。

## 各自的区间重叠

第一张表的两行共用种子，分位数是 `2.776`。这一节的十次没有共用。基线是一套五个种子，改动是另一套五个种子。仍是为了做算术而设的 NLL。分位数仍用 `2.776`，不用上一节已经标成偏窄的 `1.96`。

|  | 五次 NLL | 均值 |
| --- | --- | --- |
| 基线 | 1.90, 2.10, 2.20, 2.30, 2.50 | 2.20 |
| 改动 | 1.35, 1.85, 1.85, 1.85, 1.85 | 1.75 |

两边相对各自均值的平方和都是 `0.20`，`s² = 0.05`，`s = sqrt(0.05) ≈ 0.2236`，`SE = sqrt(0.05 / 5) = 0.1`。半宽是 `2.776 × 0.1 = 0.2776`。

```text
基线：[1.9224, 2.4776]
改动：[1.4724, 2.0276]
```

两段在 `[1.9224, 2.0276]` 上重叠。

均值之差是 `1.75 - 2.20 = -0.45`。种子没有配对，差的标准误是

```text
SE = sqrt(0.1² + 0.1²) = sqrt(0.02) ≈ 0.1414
2.776 * sqrt(0.02) ≈ 0.3926
区间 ≈ [-0.8426, -0.0574]
```

区间不含 0。各自的区间重叠，没有推出差的区间包含 0。

两边标准误都是 `0.1` 时，两道界可以写死。差的区间不含 0，当差的绝对值大于 `2.776 * sqrt(2) * 0.1 ≈ 0.3926`，这就是上面的半宽。各自的区间重叠，当差的绝对值小于 `2.776 * (0.1 + 0.1) = 0.5552`。`0.45` 比 `0.3926` 大，比 `0.5552` 小，所以两件事同时发生。若差只有 `0.30`，上端约是 `-0.30 + 0.3926 = 0.0926`，区间仍包含 0，和重叠放在一起看不出这道缝。`0.45` 是放进这道缝里的。各自的区间互不重叠，比「差的区间不含 0」更严：绝对值要大过 `0.5552` 才互不重叠，大过 `0.3926` 就足以让差的区间不含 0。看见重叠就写成没有过线，会把 `0.45` 这种已经不含 0 的差说错。

把上面两行按书写顺序相减，得到 `-0.55, -0.25, -0.35, -0.45, -0.65`。均值仍是 `-0.45`。平方和是 `0.10`，`s² = 0.025`，`SE = sqrt(0.005) ≈ 0.0707`。它是 `sqrt(0.02)` 的一半，因为 `sqrt(0.02) / sqrt(0.005) = 2`。表上的左右位置不是配对。这次减法把标准误缩了一半，区间会显得更窄。窄是因为按位置对齐，不是因为实验共用了种子。

先把 `sqrt(0.02)` 收成 `0.1414` 再乘 `2.776`，半宽约 `0.3925`，端点约 `-0.8425` 和 `-0.0575`。正文用没有收成四位的标准误去乘。评估笔记里对 `sqrt(0.006)` 有过同一种差。

## 最好的一次、失败的一次、五个部件里的一次

第一张表的五个差是 `-0.3, -0.2, -0.1, 0.0, 0.1`。最小的是 `-0.3`，均值是 `-0.1`。报告 `-0.3`，回答的是五次里最低的那一次。报告 `-0.1`，回答的是这五次的平均。Reimers、Gurevych 写的是：只比较一个分数，得不出方法高低已经确定的结论。文中的分数以论文为准，这里不搬。`-0.3` 就是这样一个单独的分数。事后挑最低的一次，种子是看见结果之后选的。严格为负的差有 3 个，`0` 不是负的。事先若写「五个种子里至少四个差为负」，`3 < 4`，这句被推翻。数符号和看均值的区间是两套线。

第五次若没有得到有限的 NLL，五次的均值就不存在。只对前四次 `-0.3, -0.2, -0.1, 0.0` 取平均，得到 `-0.15`。事先若写「五次都有限才报告均值」，这次没有均值可报。事先若写「只对有限的那几次取平均，并另报失败次数」，报的是 `-0.15` 和 `1/5`。看见失败之后再选其中一句，规则参加了挑选。`-0.15` 也不是五次的均值。

五个部件若各做一次同样的区间，再只留下不含 0 的那个，挑选已经用过这次机会。假定五次检验独立，而且每一次在零假设下有 `1/20` 的概率让区间不含 0。至少一次不含 0 的概率是

```text
1 - (19/20)^5 = 723901/3200000 ≈ 0.2262
```

独立是这行算术的假设。五个部件共用同一批种子时，独立性不成立，`0.2262` 不能直接套上去。它只说明：五个里面挑一个不含 0 的，比事先指定的那一个更容易看见「过线」。最小核对里四个学习率的 `15/16` 是另一笔账，那里每一次超过基线的概率设成 `1/2`。两个分数不能互相代替。

种子要记进记录的，是你点名固定的那一个生成器。哪些操作仍不确定，以 PyTorch 的 randomness 说明为准。本篇不抄那一页的环境变量。一次真实运行要留下的其余字段，仍是系统工程里实验记录那一篇的内容。那些字段里要能找出：种子编号、每次的差、`±` 是 `s` 还是标准误、分位数是 `2.776` 还是别的、幅度线是 `0` 还是 `-0.2`。

## 容易做成的无效报告

- `±` 后面不写是样本标准差还是均值的标准误。
- 五个种子仍用 `1.96`。t 区间包含 0，仍写成过了线。
- 看见 95% 的 t 区间包含 0，再改用 `1.96` 或 `2.132`。
- 两个方法各自的区间重叠，就写成差没有过线。
- 种子没有共用，按表上的左右位置相减，把标准误缩到独立公式的一半。
- 只报五次里最低的那一次差。
- 一次没有有限的 NLL，把剩下四次的 `-0.15` 写成五次的均值，也不写 `1/5` 失败。
- 五个部件里只留下区间不含 0 的那个。
- 区间过了 0，就写成已经达到「至少低 0.2」。
- 把题数和种子数乘成一个 `n`，放进同一个标准误。

## 练习

### 练习 1：五个配对差的三个尺度

- 目标：均值、`s` 和 `SE` 分开写。忽略配对时用独立公式。
- 限制：纸笔。用正文第一张表的五个差，以及基线平方和 `0.20`、改动平方和 `0.40`。
- 题面：差的均值、平方和、`s²`、`s`、`SE` 各是多少？平方和除以 5 之后的标准误约是多少，它是 `SE` 的多少倍？忽略配对时，差的标准误约是多少？
- 完成标准：均值 `-0.1`，平方和 `0.10`，`s² = 0.025`，`s ≈ 0.1581`，`SE ≈ 0.0707`。除以 5 的标准误约 `0.0632`，倍数约 `0.8944`。忽略配对约 `0.1732`。

<details>
<summary>参考解答</summary>

偏离 `-0.2, -0.1, 0, 0.1, 0.2`，平方和 `0.10`。`0.10 / 4 = 0.025`，`sqrt(0.025) ≈ 0.1581`，`sqrt(0.025 / 5) ≈ 0.0707`。`0.10 / 5 = 0.02`，`sqrt(0.02 / 5) = sqrt(0.004) ≈ 0.0632`，`sqrt(4/5) ≈ 0.8944`。`sqrt(0.01 + 0.02) = sqrt(0.03) ≈ 0.1732`。

</details>

### 练习 2：三道分位数，两道幅度

- 目标：分位数和幅度都按事先写的线判断。
- 限制：纸笔。半宽沿用正文：`2.776` 约 `0.1963`，`1.96` 约 `0.1386`，`2.132` 约 `0.1508`。
- 题面：均值 `-0.16` 时，三个区间的端点约是多少，哪几个包含 0？均值 `-0.3` 时，`2.776` 的区间端点约是多少？它是否包含 0？上端是否仍高于 `-0.2`？
- 完成标准：`-0.16` 的三个区间约是 `[-0.3563, 0.0363]`、`[-0.2986, -0.0214]`、`[-0.3108, -0.0092]`。只有 `2.776` 的那个包含 0。`-0.3` 的 t 区间约是 `[-0.4963, -0.1037]`，不含 0，上端高于 `-0.2`。

<details>
<summary>参考解答</summary>

`-0.16 - 0.1963 = -0.3563`，`-0.16 + 0.1963 = 0.0363`。`-0.16 - 0.1386 = -0.2986`，`-0.16 + 0.1386 = -0.0214`。`-0.16 - 0.1508 = -0.3108`，`-0.16 + 0.1508 = -0.0092`。`-0.3 - 0.1963 = -0.4963`，`-0.3 + 0.1963 = -0.1037`。`-0.1037 > -0.2`。

</details>

### 练习 3：重叠和按位置相减

- 目标：各自的区间、差的区间、按位置相减的标准误是三个数。
- 限制：纸笔。用正文没有共用种子的两行。分位数 `2.776`，半宽 `0.2776`。差的标准误用 `sqrt(0.02)`，不要先收成四位。
- 题面：两个各自的区间是否重叠？差的区间端点约是多少，是否包含 0？`0.45` 落在 `0.3926` 和 `0.5552` 的哪一侧？差若只有 `0.30`，上端约是多少？按书写顺序相减之后，标准误约是多少？它是独立公式的多少分之一？先把标准误收成 `0.1414` 再乘 `2.776`，半宽约是多少？
- 完成标准：重叠。差的区间约 `[-0.8426, -0.0574]`，不含 0。`0.45` 大于 `0.3926`、小于 `0.5552`。差为 `0.30` 时上端约 `0.0926`，区间包含 0。按位置相减的标准误约 `0.0707`，是独立公式的一半。先收四位再乘，半宽约 `0.3925`。

<details>
<summary>参考解答</summary>

`[1.9224, 2.4776]` 与 `[1.4724, 2.0276]` 在 `1.9224` 到 `2.0276` 上重叠。`2.776 * sqrt(0.02) ≈ 0.3926`，端点 `-0.45 ± 0.3926`。`2.776 * 0.2 = 0.5552`。`-0.30 + 0.3926 = 0.0926`。五个位置差的平方和是 `0.10`，`sqrt(0.025 / 5) ≈ 0.0707`，`sqrt(0.02) / sqrt(0.005) = 2`。`2.776 * 0.1414 = 0.3925264`，收成四位是 `0.3925`。

</details>

### 练习 4：最低的一次和失败的一次

- 目标：挑种子和删失败都要能指回事先的规则。
- 限制：纸笔。差是 `-0.3, -0.2, -0.1, 0.0, 0.1`。第五次没有有限的 NLL。
- 题面：最低的差是多少？严格为负的有几个？「至少四个种子上差为负」是否被推翻？只对前四次取平均，均值是多少？这个 `-0.15` 在哪一条事先写明的规则下可以报告，还要同时报告什么？
- 完成标准：最低是 `-0.3`。严格为负的是 3 个，`3 < 4`，那句被推翻。四次均值是 `-0.15`。只有事先写了「只对有限的那几次取平均，并另报失败次数」才报告它，同时报告 `1/5`。它不是五次的均值。

<details>
<summary>参考解答</summary>

五个数里最小是 `-0.3`。负的是前三个，`0` 和 `0.1` 都不是严格的负。`(-0.3 + -0.2 + -0.1 + 0) / 4 = -0.6 / 4 = -0.15`。

</details>

### 练习 5：五个部件里至少一次

- 目标：把「挑一个不含 0 的」和事先指定的一次分开。
- 限制：纸笔。五次检验独立，每一次在零假设下让区间不含 0 的概率是 `1/20`。
- 题面：五次都含 0 的概率是多少？至少一次不含 0 的概率是多少，约到四位是多少？为什么五个部件共用同一批种子时，不能把这个数直接当成那次实验的概率？它和四个学习率的 `15/16` 差在哪一个假定？
- 完成标准：`(19/20)^5 = 2476099/3200000`。至少一次是 `723901/3200000 ≈ 0.2262`。共用种子时独立性不成立。`15/16` 把每一次超过基线的概率设成 `1/2`，不是 `1/20`。

<details>
<summary>参考解答</summary>

`19^5 = 2476099`，`20^5 = 3200000`。`3200000 - 2476099 = 723901`。`723901/3200000 = 0.2262190625`，四位是 `0.2262`。`1 - (1/2)^4 = 15/16` 用的是另一个概率。

</details>
