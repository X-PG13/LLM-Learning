## 完成时你能做什么

- 把最小二乘写成 `XᵀX β = Xᵀy`，说明列满秩时解唯一，并说明 2-范数下 `κ(XᵀX) = κ(X)²`。
- 用链式法则把 `p(x₁,…,xₙ)` 写成条件概率的乘积。
- 写出 `H(p, q) = H(p) + KL(p‖q)`。`p` 固定时，比较两个 `q` 只需比较交叉熵。
- 对 Bernoulli 样本写出极大似然 `k/n`，并说明 Categorical 的平均负对数似然就是经验分布与模型的交叉熵。
- 在 `Y` 取 0 和 2 各一半、样本大小为 2 时，穷举样本均值的偏差和方差，并比较除以 `n` 与除以 `n - 1` 的方差估计的均方误差。
- 说明用全部数据的均值再划分训练和测试时，这个均值用了测试点，测试平方和会变小。
- 说明一步梯度下降在沿梯度反方向移动参数。非凸目标上，这一步的损失下降不代表全局最优。
- 不看笔记重做线性代数、概率和统计笔记里的练习。

## 这一阶段不追求

公理化的线性代数、测度论概率、把 Boyd 全书做完，以及为了通信系统去学信道容量。信息论只取熵、交叉熵和 KL，因为语言模型的损失就是它们。

## 后面几篇要回答的问题

- 优化：凸意味着局部最小就是全局最小。SGD、动量、Adam 的更新式在 [深度学习的优化笔记](../05-深度学习/02-优化.md)。凸与非凸的定义，以及「带 KL 惩罚的目标」怎样读，留在这一篇。
- 信息论：交叉熵读成用 `q` 给来自 `p` 的样本编码的平均长度。`H(p, q) = H(p) + KL(p‖q)` 和 `0 ln 0 = 0` 已经在概率笔记里使用。
