## 完成时你能做什么

- 把最小二乘写成 `XᵀX β = Xᵀy`，说明列满秩时解唯一，并说明 2-范数下 `κ(XᵀX) = κ(X)²`。
- 用链式法则把 `p(x₁,…,xₙ)` 写成条件概率的乘积。
- 写出 `H(p, q) = H(p) + KL(p‖q)`。`p` 固定时，比较两个 `q` 只需比较交叉熵。
- 说明一步梯度下降在沿梯度反方向移动参数。非凸目标上，这一步的损失下降不代表全局最优。
- 不看笔记重做线性代数开篇的练习。

## 这一阶段不追求

公理化的线性代数、测度论概率、把 Boyd 全书做完，以及为了通信系统去学信道容量。信息论只取熵、交叉熵和 KL，因为语言模型的损失就是它们。

## 后面几篇要回答的问题

这些问句固定后续笔记的范围，避免写成另一门数学系课程。

- 概率：给定前缀，下一个 token 的分布是条件分布。期望和方差在说什么；Bernoulli、Categorical、高斯各自适合什么数据。
- 统计：极大似然在最大化什么；用全量数据估计均值再划分训练测试，估计量和评价分别被污染了什么。
- 优化：凸意味着局部最小就是全局最小；神经网络的损失一般不凸。SGD、动量、Adam 各自利用了梯度的哪一种历史。约束优化只要求能读懂「带 KL 惩罚的目标」这一句。
- 信息论：熵是分布自身的不确定性；交叉熵是用 `q` 给来自 `p` 的样本编码的平均长度；KL 是二者之差。`0 ln 0` 按 0 处理。
