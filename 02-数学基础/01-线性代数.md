## 本篇要回答的问题

1. 点积同时编码了夹角和长度，相似度为什么不能只看点积的大小？
2. 矩阵乘法作用在向量上时，列向量分别是什么？
3. 秩亏意味着哪一个方向上的信息被变成了 0？
4. 最小二乘的正规方程从哪一条正交条件来，为什么实现时往往不直接形成 `XᵀX`？
5. 低秩分解为什么能把参数量从 `d_out * d_in` 变成 `r * (d_out + d_in)`？

## 向量

一个向量是一组有序数。在模型里它有时是一条样本的特征，有时是一个方向。把 `u = (u₁, u₂)` 画在平面上时，它是从原点指向这个坐标的箭头。

长度用欧氏范数：

```text
‖u‖ = sqrt(u₁² + u₂² + … )
```

两个向量相加是对应坐标相加，数乘是把每个坐标乘上同一个数。只由这两种运算得到的结果，仍然在原来的直线或平面上。这就是后面说「线性」时的范围。

## 点积

```text
u · v = u₁v₁ + u₂v₂ + …
       = ‖u‖ ‖v‖ cos θ
```

`θ` 是二者的夹角。`cos θ` 只保留方向关系：同向为 1，垂直为 0，反向为 -1。点积本身还会被长度放大。所以两个很长但几乎垂直的向量，点积可以大于两个很短但同向的向量。

例子：`u = (1, 0)`，`v = (1, 1)`。

```text
u · v = 1
‖u‖ = 1
‖v‖ = sqrt(2)
cos θ = 1 / sqrt(2) ≈ 0.7071
```

注意力分数里会出现 `q · k`。它是未归一化的方向相似度，长度会把分数放大。缩放点积把点积除以 `sqrt(d_k)`，手算见 [自注意力与 Transformer 块](../06-大语言模型/02-自注意力与Transformer.md)。

## 矩阵是线性变换

`m × n` 矩阵把 `n` 维向量变成 `m` 维向量。看一个 `2 × 2` 的例子：

```text
A = | 2  1 |
    | 1  2 |
```

标准基 `e₁ = (1, 0)` 被送到第一列 `(2, 1)`，`e₂ = (0, 1)` 被送到第二列 `(1, 2)`。任意向量 `(x, y) = x e₁ + y e₂` 被送到 `x * 第一列 + y * 第二列`。列就是基向量的像。

线性层沿用 [记号约定](../记号约定.md)：`W` 的形状是 `(out, in)`，列向量满足 `y = W x`，所以 `W` 的第 `j` 列就是输入轴 `eⱼ` 的像。按批写成行向量时，同一次乘法是 `y = x @ W.T + b`。论文里若把权重定义成右乘、列数对应输出，那是转置后的存法，引用时要写明。

计算特征值。解 `det(A - λI) = 0`：

```text
A - λI = | 2-λ   1 |
         |  1   2-λ |

(2-λ)² - 1 = λ² - 4λ + 3 = (λ - 1)(λ - 3)
```

特征值是 3 和 1。

- `λ = 3`：`(A - 3I)(x, y) = 0` 给出 `y = x`。方向 `(1, 1)` 被拉长 3 倍：`A(1, 1) = (3, 3)`。
- `λ = 1`：`y = -x`。方向 `(1, -1)` 长度不变：`A(1, -1) = (1, -1)`。

特征值描述的是「哪些方向只被伸缩、不被旋转到别的方向」。它要求方阵，而且不是每个方阵都有足够的特征向量来拼成一套完整的坐标。长方形的数据矩阵不要去找特征值。

## 秩、列空间和零空间

秩是线性无关的列的个数，也是列空间的维数。列空间是所有 `A x` 能到达的向量。零空间是被 `A` 送到 0 的那些 `x`。

秩 1 的例子。取 `u = (1, 2)`，`v = (3, 4)`，定义 `A = u vᵀ`：

```text
A = | 3  4 |
    | 6  8 |
```

第二列是第一列的 `4/3` 倍，列空间是 `u` 所在的那条直线。零空间里有一个容易检查的向量 `(4, -3)`：

```text
A | 4 | = | 3*4 + 4*(-3) | = | 0 |
  |-3 |   | 6*4 + 8*(-3) |   | 0 |
```

这个方向上的输入被丢掉了。秩亏就是有信息被线性变换变成 0，而且这个丢掉是永久性的：后面再乘别的矩阵，也找不回已经变成 0 的那一部分。

## 投影与最小二乘

要用一条直线 `y = a + b x` 拟合三个点 `(0, 1)`、`(1, 2)`、`(2, 2)`。把参数写成 `β = (a, b)`，设计矩阵的每一行是 `(1, xᵢ)`：

```text
X = | 1  0 |     y = | 1 |
    | 1  1 |         | 2 |
    | 1  2 |         | 2 |
```

没有一条直线能同时穿过三个点，所以不存在 `β` 使 `Xβ = y`。最小二乘选择的 `β` 让残差 `y - Xβ` 的长度最小。几何上，`Xβ` 是 `y` 在 `X` 的列空间上的投影，残差垂直于每一个列。垂直就是和每一列的点积为 0，写成矩阵是：

```text
Xᵀ (y - Xβ) = 0
Xᵀ X β = Xᵀ y
```

这就是正规方程。用微积分看同一件事：`f(β) = ‖Xβ - y‖²` 的梯度是 `2 Xᵀ(Xβ - y)`，令梯度为 0 得到同一方程。

本例里：

```text
XᵀX = | 3  3 |     Xᵀy = | 5 |
      | 3  5 |           | 6 |

3a + 3b = 5
3a + 5b = 6
```

两式相减得 `2b = 1`，所以 `b = 1/2`。代回得 `3a + 3/2 = 5`，`a = 7/6`。

三个预测值是 `7/6`、`5/3`、`13/6`。残差是：

```text
1 - 7/6 = -1/6
2 - 5/3 =  1/3
2 - 13/6 = -1/6
```

和常数列 `(1, 1, 1)` 的点积：`-1/6 + 1/3 - 1/6 = 0`。和 `x` 列 `(0, 1, 2)` 的点积：`0 + 1/3 + 2*(-1/6) = 0`。正交条件和方程的解对上了。

`X` 的两列不成比例，秩为 2，`XᵀX` 可逆，解唯一。列满秩是这条唯一性的条件。

## 条件数

2-范数条件数 `κ(A) = σ_max / σ_min`，其中 `σ` 是奇异值，并且 `σ_min > 0`。条件数大，表示输入或右端项的一点扰动会被放大到解里。

继续用前面的对称矩阵 `A = [[2, 1], [1, 2]]`。它正定，奇异值就是特征值 3 和 1，所以 `κ(A) = 3`。

```text
AᵀA = A² = | 5  4 |
           | 4  5 |
```

`AᵀA (1, 1) = (9, 9)`，`AᵀA (1, -1) = (1, -1)`。特征值是 9 和 1，`κ(AᵀA) = 9 = 3²`。

一般地，列满秩矩阵满足 `κ(AᵀA) = κ(A)²`。先把正规方程形成 `AᵀA` 再求解，会把问题的敏感程度平方。三个点的例子数值很乖，分数解看不出病态。实现最小二乘时优先用 QR 或 SVD。线性回归那一篇会把这件事接回模型，而不是在这里展开数值库。

## SVD 在本篇的位置

任意实矩阵都能写成 `A = U Σ Vᵀ`。

- `U` 的列彼此正交，是左奇异向量。
- `V` 的列彼此正交，是右奇异向量。
- `Σ` 的对角元是非负奇异值，按从大到小排。

秩等于非零奇异值的个数。只保留前 `r` 个奇异值，得到的矩阵是所有秩不超过 `r` 的矩阵里，在谱范数和 Frobenius 范数意义下离 `A` 最近的一个。这是 Eckart–Young–Mirsky 定理，本篇不证明，只把它当作低秩近似的依据。

特征值分解不是这条定理的替代品：长方矩阵没有特征值分解，有些方阵也没有完整的特征基。PCA 可以分解协方差矩阵的特征值，也可以对中心化后的数据矩阵做 SVD。数值实现更常走 SVD。步骤留到无监督笔记。

## 低秩与参数量

若 `ΔW = B A`，其中 `B` 是 `d_out × r`，`A` 是 `r × d_in`，则 `ΔW` 的秩不超过 `r`。参数个数是 `r * (d_out + d_in)`，而完整矩阵是 `d_out * d_in`。秩「不超过」是因为 `B` 或 `A` 自己也可能秩亏。

取一个常见的隐藏维度做比例：`d_out = d_in = 4096`，`r = 8`。

```text
完整矩阵：4096 * 4096 = 16_777_216
低秩：    8 * (4096 + 4096) = 65_536
比例：    65_536 / 16_777_216 = 1/256 ≈ 0.3906%
```

这就是 LoRA 一类方法省参数的线性代数原因：训练时更新的是低秩因子，而不是整张权重。怎么初始化和怎么加回原权重，是语言模型阶段的笔记，不在这里。

## 这些对象后面会再出现

| 对象 | 在哪里用 |
| --- | --- |
| 点积与夹角 | 注意力分数 |
| 矩阵乘、列是基的像 | 线性层 |
| 零空间、秩亏 | 判断一次线性变换丢掉了哪些方向 |
| 列空间上的投影、正规方程 | 线性回归 |
| 条件数 | 正规方程的数值稳定性；优化里不同方向曲率差很大 |

## 容易算错的地方

- 相似度要比较的是夹角时，先除以两个范数。只排序点积，等于把长度也比进去了。
- 方阵才谈特征值。`3 × 5` 的数据矩阵用奇异值描述它把 5 维压到 3 维的方式。
- 正规方程的解在精确算术下满足残差正交。用 `AᵀA` 的显式矩阵去算，条件数被平方，小例子上的分数不能代表生产代码的做法。
- `ΔW = BA` 的秩是「不超过 `r`」。把参数量公式背成总是恰好秩 `r`，会在因子退化时判断错。

## 练习

### 练习 1：把点积和夹角分开

- 目标：同一对向量能同时报出点积和余弦。
- 限制：纸笔。
- 题面：`u = (3, 0)`，`v = (1, 1)`。计算 `u·v`、两个范数和 `cos θ`。再与正文中 `u = (1, 0)`、`v = (1, 1)` 的余弦比较。
- 完成标准：能说明哪一个量变了、哪一个量没变。

<details>
<summary>参考解答</summary>

`u·v = 3`，`‖u‖ = 3`，`‖v‖ = sqrt(2)`，`cos θ = 3 / (3 sqrt(2)) = 1/sqrt(2)`。

余弦与正文例子相同，因为 `(3, 0)` 与 `(1, 0)` 同向。点积从 1 变成 3，变的是 `u` 的长度。

</details>

### 练习 2：用特征值预测矩阵向量乘

- 目标：沿特征方向时，乘法退化成伸缩。
- 限制：纸笔，不用计算器。
- 题面：仍取正文的 `A = [[2, 1], [1, 2]]`。计算 `A(2, 2)` 和 `A(3, -3)`。
- 完成标准：两个结果都先用特征值说出，再做一次矩阵乘法核对。

<details>
<summary>参考解答</summary>

`(2, 2) = 2(1, 1)`，特征值 3，所以 `A(2, 2) = 6(1, 1) = (6, 6)`。

`(3, -3) = 3(1, -1)`，特征值 1，所以 `A(3, -3) = (3, -3)`。

直接乘：`A(2, 2) = (4+2, 2+4) = (6, 6)`，`A(3, -3) = (6-3, 3-6) = (3, -3)`。

</details>

### 练习 3：给秩 1 矩阵找一个被丢掉的方向

- 目标：从方程读出零空间的一个向量。
- 限制：纸笔。
- 题面：`A = [[3, 4], [6, 8]]`。解 `3x + 4y = 0`，给出一个非零解，并把它乘回 `A`。
- 完成标准：乘积是零向量，并且你能指出第二行方程为什么没有新信息。

<details>
<summary>参考解答</summary>

取 `(x, y) = (4, -3)`。`3*4 + 4*(-3) = 0`。第二行是 `6x + 8y = 2(3x + 4y)`，所以它与第一行是同一个约束。`A(4, -3) = (0, 0)`。

</details>

### 练习 4：把最小二乘重做一遍

- 目标：独立得到 `a = 7/6`、`b = 1/2`，并检查残差正交。
- 限制：纸笔。做完后运行 `python3 tools/check_worked_examples.py`，确认脚本里的同一例子通过。
- 题面：点 `(0, 1)`、`(1, 2)`、`(2, 2)`，模型 `y = a + bx`。写出 `XᵀX` 和 `Xᵀy`，解 `β`，计算三个残差，再计算残差与两列的点积。
- 完成标准：点积都是 0，参数是分数而不是只保留两位小数。

<details>
<summary>参考解答</summary>

`XᵀX = [[3, 3], [3, 5]]`，`Xᵀy = (5, 6)`。解得 `a = 7/6`，`b = 1/2`。残差 `-1/6`、`1/3`、`-1/6`。与 `(1, 1, 1)` 和 `(0, 1, 2)` 的点积都是 0。脚本 `check_least_squares` 复核这些分数。

</details>

### 练习 5：低秩参数量

- 目标：会改 `r` 和隐藏维度，而不只记住 4096 和 8。
- 限制：纸笔。
- 题面：`d_out = d_in = 1024`，`r = 4`。完整矩阵有多少参数？低秩因子有多少？比例是多少？
- 完成标准：比例用最简分数。

<details>
<summary>参考解答</summary>

完整：`1024 * 1024 = 1_048_576`。低秩：`4 * (1024 + 1024) = 8192`。比例 `8192 / 1_048_576 = 1/128`。

</details>

### 练习 6：条件数被平方

- 目标：把正文的特征值计算和条件数定义连起来。
- 限制：不查笔记里的最终数字，可以查定义。
- 题面：`A = [[2, 1], [1, 2]]`。说明 `κ₂(A) = 3`，再说明 `κ₂(AᵀA) = 9`。最后用一句话写出实现最小二乘时的选择。
- 完成标准：两句都给出特征值，而不是只写结论。

<details>
<summary>参考解答</summary>

`A` 的特征值是 3 和 1，正定矩阵的奇异值与特征值相同，`κ₂(A) = 3/1 = 3`。`AᵀA` 的特征值是 9 和 1，`κ₂ = 9`。实现时用 QR 或 SVD 解最小二乘，避免显式形成正规方程。

</details>

### 练习 7：长方矩阵

- 目标：选对分解。
- 限制：口头或三行文字，不需要计算。
- 题面：一个 `3 × 5` 的矩阵，秩最多是多少？讨论它的特征值是否有定义，讨论它的奇异值是否有定义。
- 完成标准：三个问题都有明确回答。

<details>
<summary>参考解答</summary>

秩最多是 3，因为只有 3 行。特征值对这个非方阵没有定义。奇异值有定义，`Σ` 上最多 3 个非零奇异值。

</details>
