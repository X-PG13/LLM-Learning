## 本篇要回答的问题

1. 条件概率的分母是 0 时，这个条件为什么没有定义？
2. 链式法则怎样把一段 token 的联合概率写成自回归形式？
3. 期望对加法总是线性的。方差在两个量相关时，为什么不能把各自的方差直接相加？
4. Bernoulli、Categorical 和高斯的极大似然，各自把哪个量估成样本里的哪一个比例或平均？
5. 经验分布固定时，最小化交叉熵为什么就是在最小化 KL？

## 条件和乘法

概率写在有限集合上。一次实验的结果是样本空间里的一个点，事件是这些点的一个子集。`P(A)` 是事件 `A` 的概率。空事件的概率是 0，整个样本空间的概率是 1，互不相交的事件概率相加。

`P(B) > 0` 时，在 `B` 已发生的条件下 `A` 的概率是

```text
P(A | B) = P(A ∩ B) / P(B)
```

分母是 0 时，这个比没有定义：条件所假设的事情在模型里不会发生，就谈不上「在它发生的前提下」。实现里若某个前缀的概率被估成 0，后面的条件分布不是一个可以继续相乘的数，训练要避免走到这一步。

由定义直接得到乘法：`P(A ∩ B) = P(B) P(A | B) = P(A) P(B | A)`。两个方向的条件不相等。`P(A | B)` 大，只说明 `A` 在 `B` 里占的比例大，不说明 `P(B | A)` 大。

## 两个 token 的联合分布

用一个可以手算的分布贯穿后面几节。序列只有两个位置，每个位置是 `A` 或 `B`。

```text
P(x₁ = A) = P(x₁ = B) = 1/2
P(x₂ = A | x₁ = A) = 3/4    P(x₂ = B | x₁ = A) = 1/4
P(x₂ = A | x₁ = B) = 1/4    P(x₂ = B | x₁ = B) = 3/4
```

乘法给出四个联合概率：

```text
P(A, A) = (1/2) * (3/4) = 3/8
P(A, B) = (1/2) * (1/4) = 1/8
P(B, A) = (1/2) * (1/4) = 1/8
P(B, B) = (1/2) * (3/4) = 3/8
```

四项之和是 1。这四项由 `check_probability` 复核。

第二个位置的边际，用全概率公式把第一条的两种取值加起来：

```text
P(x₂ = A) = P(x₂ = A | x₁ = A) P(x₁ = A) + P(x₂ = A | x₁ = B) P(x₁ = B)
          = (3/4)*(1/2) + (1/4)*(1/2) = 1/2
```

`P(x₂ = B)` 也是 `1/2`。贝叶斯公式把联合除回这个边际：

```text
P(x₁ = A | x₂ = A) = P(A, A) / P(x₂ = A) = (3/8) / (1/2) = 3/4
```

看见第二个位置是 `A` 之后，第一个位置是 `A` 的概率从 `1/2` 变成 `3/4`。这是 `P(x₁ | x₂)`，和生成时用的 `P(x₂ | x₁)` 方向相反。语言模型生成时乘的是后一种。

## 链式法则

三个事件的乘法多写一层：

```text
P(A ∩ B ∩ C) = P(A) P(B | A) P(C | A ∩ B)
```

只要每一步的条件概率都有定义。token 序列 `x₁, …, xₙ` 是同一件事：

```text
P(x₁, …, xₙ) = P(x₁) P(x₂ | x₁) P(x₃ | x₁, x₂) … P(xₙ | x₁, …, xₙ₋₁)
```

这叫自回归分解。它是概率的等式，不是某个网络结构的假设。因果语言模型学的是右边每一项条件分布。`P(x₁)` 的条件是空前缀。空前缀在实现里要有一个明确的来源：开始符，或模型对空输入的那一次预测。换一种来源，联合概率的第一项就换了。

上面的两 token 例子就是 `n = 2` 的这条等式。`P(A, A) = 3/8` 没有别的来源，就是 `P(x₁ = A)` 乘 `P(x₂ = A | x₁ = A)`。

## 独立

`P(B) > 0` 时，若 `P(A | B) = P(A)`，则 `A` 与 `B` 独立，联合概率等于两个边际的乘积。上面的例子不独立：

```text
P(x₂ = B | x₁ = B) = 3/4
P(x₂ = B) = 1/2
P(B, B) = 3/8
P(x₁ = B) P(x₂ = B) = 1/4
```

`3/4 ≠ 1/2`，`3/8 ≠ 1/4`。条件分布随前缀改变，正是语言模型要拟合的东西。若下一个 token 与前缀独立，模型再深也只是在重复同一个边际分布。

两两独立推不出一组变量相互独立。本篇的例子用不上那一层，写到多个特征「看起来两两无关」时再回到这句话。

## 期望和方差

离散随机变量 `X` 取值 `x`，概率 `p_X(x)`。它的期望是

```text
E[X] = Σₓ x p_X(x)
```

`g(X)` 的期望是 `Σ g(x) p_X(x)`，不要先算 `E[X]` 再套 `g`，除非 `g` 是线性的。常数 `c` 和两个随机变量满足

```text
E[c] = c
E[aX + bY] = a E[X] + b E[Y]
```

第二条不需要 `X` 和 `Y` 独立。

方差是偏离期望的平方的期望：

```text
Var(X) = E[(X - E[X])²] = E[X²] - (E[X])²
```

把本例的 token 编成数：`A → 0`，`B → 1`。令 `X₁`、`X₂` 是两个位置的这个数。

```text
E[X₁] = 0*(1/2) + 1*(1/2) = 1/2
E[X₁²] = 1/2
Var(X₁) = 1/2 - (1/2)² = 1/4
```

`X₂` 的边际也是 `1/2` 对 `1/2`，所以 `E[X₂] = 1/2`，`Var(X₂) = 1/4`。

和的期望仍是 1：`E[X₁ + X₂] = 1`。和的方差要用联合分布。四种结果里，`AA` 的和是 0（概率 `3/8`），`AB` 和 `BA` 的和是 1（各 `1/8`），`BB` 的和是 2（概率 `3/8`）。

```text
E[(X₁ + X₂)²] = 0 + 1/8 + 1/8 + 4*(3/8) = 7/4
Var(X₁ + X₂) = 7/4 - 1² = 3/4
```

若两者独立，方差应是 `1/4 + 1/4 = 1/2`。实际是 `3/4`。差出来的是协方差：

```text
Cov(X₁, X₂) = E[X₁ X₂] - E[X₁] E[X₂]
Var(X₁ + X₂) = Var(X₁) + Var(X₂) + 2 Cov(X₁, X₂)
```

`X₁ X₂` 只有在 `BB` 时为 1，所以 `E[X₁ X₂] = 3/8`。`E[X₁] E[X₂] = 1/4`。协方差是 `3/8 - 2/8 = 1/8`。代回去：`1/4 + 1/4 + 2*(1/8) = 3/4`。两种算法一致。

相关的量，方差不能拆成各自方差之和。小批量梯度若来自相关样本，梯度估计的方差也不是「样本数分之一」那么简单。那是统计主题里抽样的事，这里只把恒等式钉住。

## 三个常用分布

**Bernoulli。** `X ∈ {0, 1}`，`P(X = 1) = p`，`P(X = 0) = 1 - p`，`0 ≤ p ≤ 1`。`E[X] = p`，`Var(X) = p(1 - p)`。一次二元标签、一次「这个 token 是不是结束符」，在只关心是或否时都是它。上例的 `X₁` 就是 `p = 1/2` 的 Bernoulli，方差 `1/4` 与 `p(1-p)` 一致。

**Categorical。** 取值是 `K` 个类别之一，概率 `p₁, …, p_K` 非负且和为 1。下一个 token 在词表上的分布就是 Categorical。`K = 2` 时把它编成 0 和 1，与 Bernoulli 是同一个分布。期望要先规定每个类别对应的数；类别本身没有「平均值」，除非另给分数。

**一维高斯。** 密度

```text
φ(x | μ, σ²) = (1 / sqrt(2πσ²)) exp( -(x - μ)² / (2σ²) )
```

`σ² > 0`。`E[X] = μ`，`Var(X) = σ²`。连续的测量、回归的噪声，常用它。token 的类别分布不是高斯。把离散类别硬套进高斯，类别之间的距离是你额外假定的，分布本身没有这段距离。

## 极大似然

样本独立，模型给出每个样本的概率或密度。极大似然选择让已观测样本的联合概率最大的参数。联合概率是各项的乘积，取 ln 后变成求和，最大值的位置不变。训练里写的损失通常是这个和的相反数，再除以样本数：平均负对数似然。最小化它，就是在最大化似然。

**Bernoulli。** `n` 次里有 `k` 次是 1。对数似然

```text
ln L(p) = k ln p + (n - k) ln(1 - p)
```

`0 < p < 1` 时对 `p` 求导：

```text
k / p - (n - k) / (1 - p) = 0
k (1 - p) = (n - k) p
p = k / n
```

导数在 `p` 小于 `k/n` 时为正、大于时为负，这个临界点是最大值。

手算：4 次里 3 次是 1，1 次是 0。`p̂ = 3/4`。这个值上的对数似然是

```text
3 ln(3/4) + ln(1/4) = 3 ln 3 - 4 ln 4
```

四次合计的负对数似然是 `4 ln 4 - 3 ln 3`，约为 2.2493。除以 4 得到单次的平均。

`k = 0` 或 `k = n` 时，最大值落在端点 `p = 0` 或 `p = 1`，上面的导数式只在开区间里用。端点上，观测数据的概率是 1，对数似然是 0。softmax 和 sigmoid 的输出落在开区间，训练中的 `p` 通常碰不到端点；真碰到对数里的 0，损失会变成无穷。

**Categorical。** `N` 个独立样本，类别 `k` 出现 `n_k` 次，`Σ n_k = N`。对数似然 `Σ_k n_k ln p_k`，约束 `Σ p_k = 1`，`p_k > 0`。用拉格朗日乘子 `λ` 对 `p_k` 求导：

```text
n_k / p_k - λ = 0  ⇒  p_k = n_k / λ
```

概率和为 1，所以 `λ = N`，`p̂_k = n_k / N`。极大似然就是经验频率。

手算：4 个样本，计数 `(n₀, n₁, n₂) = (2, 1, 1)`。

```text
p̂ = (1/2, 1/4, 1/4)
```

平均负对数似然：

```text
- (2/4) ln(1/2) - (1/4) ln(1/4) - (1/4) ln(1/4)
  = (1/2) ln 2 + (1/2) ln 4
  = (1/2) ln 2 + ln 2
  = (3/2) ln 2
```

`ln 4 = 2 ln 2`。数值约 1.0397。

**条件 Categorical。** 自回归模型在每个前缀下有一张自己的概率表时，同一个推导用在「这个前缀出现过的那些下一步」上，极大似然就是该前缀下的下一步频率。神经网络让不同前缀共享参数，它做不到每个前缀都刚好等于经验频率。训练目标仍然是条件负对数似然，也就是这些条件分布上的平均交叉熵。共享参数改变的是做不到的程度，不改变损失在度量什么。

## 交叉熵和 KL

分布 `p` 的熵、交叉熵和 KL：

```text
H(p) = - Σᵢ pᵢ ln pᵢ
H(p, q) = - Σᵢ pᵢ ln qᵢ
KL(p ‖ q) = Σᵢ pᵢ ln (pᵢ / qᵢ)
```

约定 `0 ln 0 = 0`。于是

```text
KL(p ‖ q) = Σᵢ pᵢ ln pᵢ - Σᵢ pᵢ ln qᵢ = -H(p) + H(p, q)
H(p, q) = H(p) + KL(p ‖ q)
```

`p` 固定时，`H(p)` 是常数。比较两个 `q`，交叉熵和 KL 同时变大或变小。KL 不对称：`KL(p ‖ q)` 和 `KL(q ‖ p)` 是两个量。

把 `p` 取成上面的经验分布 `(1/2, 1/4, 1/4)`，`q` 取成它自己。KL 是 0，交叉熵等于熵，就是上一节的平均负对数似然 `(3/2) ln 2`。极大似然把交叉熵降到了熵，不能再低。

再取一个均匀的 `q = (1/3, 1/3, 1/3)`：

```text
H(p, q) = - ln(1/3) = ln 3
KL(p ‖ q) = ln 3 - (3/2) ln 2
```

`ln 3` 约 1.0986，大于 `(3/2) ln 2`。均匀分布给这批计数的负对数似然更高，似然更低。

下一个 token 的标签是一点分布：真实类别概率为 1，其余为 0。这时 `H(p) = 0`，交叉熵、KL 和 `-ln q_y` 是同一个数。语料上的平均就是平均负对数似然。softmax 的手算和困惑度在 [Token 与下一个词](../06-大语言模型/01-Token与下一个词.md)，本篇不重复那张表。

## 高斯的均值，以及除以 n 还是 n-1

独立样本 `x₁, …, xₙ` 的高斯对数似然是

```text
ln L = -(n/2) ln(2π) - (n/2) ln(σ²) - (1/(2σ²)) Σᵢ (xᵢ - μ)²
```

对 `μ` 求导，`Σᵢ (xᵢ - μ) / σ² = 0`，所以 `μ̂` 是样本平均。对 `σ²` 求导：

```text
-n / (2σ²) + (1 / (2 (σ²)²)) Σᵢ (xᵢ - μ)² = 0
σ̂² = (1/n) Σᵢ (xᵢ - μ̂)²
```

均值的极大似然是样本平均。方差的极大似然除以 `n`，除的是样本个数，不是 `n - 1`。

手算：`1, 2, 3`。`μ̂ = 2`。平方偏差是 `1, 0, 1`，和为 2。极大似然方差是 `2/3`。把同一个平方和除以 `n - 1 = 2`，得到 1。这是另一个估计量。

两个估计量差一个确定的因子。代数恒等式：`Σ (xᵢ - μ)² = Σ (xᵢ - x̄)² + n (x̄ - μ)²`，因为偏差 `xᵢ - μ = (xᵢ - x̄) + (x̄ - μ)`，交叉项里的 `Σ (xᵢ - x̄)` 是 0。取期望，并用独立同分布时 `Var(x̄) = σ² / n`：

```text
E[Σ (Xᵢ - μ)²] = n σ²
E[n (x̄ - μ)²] = σ²
E[Σ (Xᵢ - x̄)²] = (n - 1) σ²
```

因此 `Σ (Xᵢ - x̄)² / n` 的期望是 `((n - 1) / n) σ²`，比 `σ²` 小。除以 `n - 1` 的那个估计量期望等于 `σ²`。极大似然除以 `n`，无偏的样本方差除以 `n - 1`。三个点的 `2/3` 和 `1` 是同一次平方和的两种除法，不是两次实验。

这个期望只说明平均起来偏哪边。一次样本里 `2/3` 并不「就是」真实方差的三分之二。估计量的抽样分布留在统计主题。

## 容易算错的地方

- `P(A | B)` 的分母是 `P(B)`。分子写成联合、分母写成 `P(A)`，得到的是另一个方向的条件。
- 链式法则每一项的条件必须是它前面已经写出的变量。漏掉一个条件，乘积不再等于联合概率。
- `E[X + Y] = E[X] + E[Y]` 不需要独立。`Var(X + Y) = Var(X) + Var(Y)` 需要协方差为 0。
- Categorical 的极大似然是计数除以 `N`。某类计数为 0 时，极大似然概率是 0；再拿它去算别的样本的 `-ln p`，会碰到 `ln 0`。
- `H(p, q) = H(p) + KL(p ‖ q)`。`p` 不是一点分布时，交叉熵比 KL 多一整项熵。一点分布时熵是 0，两者才相等。
- 高斯方差的极大似然除以 `n`。把 `n - 1` 的估计量叫成极大似然，导数对不上。

## 练习

### 练习 1：把四项联合概率加总

- 目标：用乘法而不是凭空填写。
- 限制：纸笔，分数。
- 题面：按正文的条件分布计算 `P(A,A)`、`P(A,B)`、`P(B,A)`、`P(B,B)`，并求和。
- 完成标准：四项是 `3/8`、`1/8`、`1/8`、`3/8`，和为 1。

<details>
<summary>参考解答</summary>

`(1/2)*(3/4) = 3/8`，`(1/2)*(1/4) = 1/8`，`(1/2)*(1/4) = 1/8`，`(1/2)*(3/4) = 3/8`。和为 `8/8 = 1`。脚本 `check_probability` 复核。

</details>

### 练习 2：说明这两个位置不独立

- 目标：用定义，而不是用「数字看起来有关」。
- 限制：纸笔。
- 题面：比较 `P(x₂ = B | x₁ = B)` 和 `P(x₂ = B)`。再比较 `P(B, B)` 和 `P(x₁ = B) P(x₂ = B)`。
- 完成标准：两处都指出不等，并写出分数。

<details>
<summary>参考解答</summary>

条件概率是 `3/4`，边际是 `1/2`。联合是 `3/8`，边际乘积是 `1/4`。两处都不相等。

</details>

### 练习 3：换一个贝叶斯方向

- 目标：分清条件的方向。
- 限制：纸笔。
- 题面：计算 `P(x₁ = B | x₂ = B)`。它和 `P(x₂ = B | x₁ = B)` 是否同一个数？和 `P(x₁ = B)` 比，信息更新了多少？
- 完成标准：结果是 `3/4`。两个条件在这个例子里数值相同，原因要说成「这一组数是对称的」，而不是「贝叶斯公式不改变方向」。

<details>
<summary>参考解答</summary>

`P(B, B) / P(x₂ = B) = (3/8)/(1/2) = 3/4`。`P(x₂ = B | x₁ = B)` 也是 `3/4`，因为本例把两个位置对称地写了。先验 `P(x₁ = B) = 1/2`，后验是 `3/4`。换一组不对称的条件概率，两个方向的条件就会不同。

</details>

### 练习 4：重算和的方差

- 目标：协方差项要出现。
- 限制：纸笔。
- 题面：`X₁, X₂` 仍是正文的 0/1 编码。计算 `E[X₁ X₂]`、协方差，以及 `Var(X₁ + X₂)`。
- 完成标准：协方差 `1/8`，方差 `3/4`。

<details>
<summary>参考解答</summary>

`E[X₁ X₂] = 3/8`，`E[X₁] E[X₂] = 1/4`，协方差 `1/8`。`1/4 + 1/4 + 2/8 = 3/4`。用 `(X₁+X₂)²` 的期望 `7/4` 减去 `1²`，得到同一个 `3/4`。

</details>

### 练习 5：Bernoulli 极大似然

- 目标：从导数得到 `k/n`，再代回对数似然。
- 限制：纸笔。对数可以留成 `ln`。
- 题面：4 次里 3 次为 1。写出 `p̂`，并把对数似然化成 `3 ln 3 - 4 ln 4`。
- 完成标准：`p̂ = 3/4`，负对数似然是 `4 ln 4 - 3 ln 3`。

<details>
<summary>参考解答</summary>

导数给出 `p = k/n = 3/4`。`3 ln(3/4) + ln(1/4) = 3 ln 3 - 3 ln 4 - ln 4 = 3 ln 3 - 4 ln 4`。负号把它变成 `4 ln 4 - 3 ln 3`。

</details>

### 练习 6：均匀分布的交叉熵更高

- 目标：把极大似然和 KL 放在同一次比较里。
- 限制：纸笔，可用 `ln 3` 和 `ln 2` 表示。
- 题面：经验分布 `p = (1/2, 1/4, 1/4)`。`q` 均匀。计算 `H(p, q)` 和 `KL(p ‖ q)`。为什么它大于 `q = p` 时的交叉熵？
- 完成标准：`H(p, q) = ln 3`，`KL = ln 3 - (3/2) ln 2`。理由是 KL 非负，且这个 `q` 不是 `p`。

<details>
<summary>参考解答</summary>

`-Σ pᵢ ln(1/3) = ln 3`。减去熵 `(3/2) ln 2` 得到 KL。`q = p` 时 KL 为 0，交叉熵等于熵。均匀分布的 KL 为正，交叉熵严格更大。

</details>

### 练习 7：同一次平方和的两种除法

- 目标：分清极大似然和无偏样本方差。
- 限制：纸笔。
- 题面：数据 `1, 2, 3`。样本均值是多少？平方偏差之和是多少？极大似然方差和除以 `n-1` 的估计各是多少？
- 完成标准：均值 2，平方和 2，两个估计是 `2/3` 和 `1`。

<details>
<summary>参考解答</summary>

均值 `(1+2+3)/3 = 2`。偏差 `-1, 0, 1`，平方和 2。除以 3 得 `2/3`，除以 2 得 1。

</details>

### 练习 8：一点分布上的三项损失

- 目标：熵为 0 时三个量重合。
- 限制：文字加一行式子。
- 题面：真实 token 的分布在类别 `y` 上为 1，模型给出 `q_y`。`H(p)`、`H(p, q)`、`KL(p ‖ q)` 各是什么？
- 完成标准：熵是 0，后两项都是 `-ln q_y`。

<details>
<summary>参考解答</summary>

一点分布的熵按 `0 ln 0 = 0` 和 `1 ln 1 = 0` 计算，是 0。交叉熵只剩下 `-ln q_y`。恒等式使 KL 等于交叉熵。

</details>
