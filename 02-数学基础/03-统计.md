## 本篇要回答的问题

1. 偏差和方差的期望，是对哪一个分布取的？一次样本上的数为什么还不是偏差？
2. 独立同分布时，样本均值的方差为什么是 `σ² / n`？第二条样本是第一条的副本时，这一步哪里失效？
3. 除以 `n` 和除以 `n - 1` 的方差估计，在四个等可能样本上的偏差、方差和均方误差各是多少？
4. 用全部数据的均值再划分训练和测试，估计量多看了哪些点，测试平方误差从多少变成多少？
5. 平均负对数似然对均值的梯度是什么？小批量梯度在估计哪一个数？

## 估计量

参数是总体分布里的一个数，例如均值 `μ`。一次实验抽出样本 `X₁, …, Xₙ`。样本的一个函数叫做统计量。拿来估计参数的统计量叫做估计量，写成 `θ̂`。样本均值

```text
x̄ = (X₁ + … + Xₙ) / n
```

是一个估计量。换一批样本，`x̄` 会换成另一个数。`x̄` 的分布叫做它的抽样分布。期望、方差都对这个分布取，不是对手头这一批数取。

手头这一批数只是抽样分布上的一个点。它离参数远，只说明这次抽中了偏离。估计量有没有偏差，要看把抽样分布上所有点平均之后还偏不偏。

下面用一个能穷举的总体。`Y` 取 `0` 和 `2`，各以 `1/2`。

```text
E[Y] = 0 * (1/2) + 2 * (1/2) = 1
E[Y²] = 4 * (1/2) = 2
Var(Y) = 2 - 1² = 1
```

偏离再算一次：`(0 - 1)² * (1/2) + (2 - 1)² * (1/2) = 1`。两种算法一致。`μ = 1`，`σ² = 1`。泛化笔记用的是同一个总体；那一篇把预测误差拆开，本篇把估计量在样本上的值写出来。

## 偏差、方差和均方误差

```text
Bias(θ̂) = E[θ̂] - θ
Var(θ̂) = E[(θ̂ - E[θ̂])²]
MSE(θ̂) = E[(θ̂ - θ)²]
```

把误差拆成两段：`θ̂ - θ = (θ̂ - E[θ̂]) + (E[θ̂] - θ)`。平方后取期望，交叉项是

```text
2 (E[θ̂] - θ) E[θ̂ - E[θ̂]]
```

后面那个期望是 0。于是

```text
MSE(θ̂) = Var(θ̂) + (Bias(θ̂))²
```

无偏是指偏差为 0，也就是 `E[θ̂] = θ`。均方误差把偏差的平方和方差加在一起。偏差为 0 的估计量，均方误差可以仍然更大。

样本大小 `n = 2`，两次抽取独立。四个样本等可能，各概率 `1/4`。

| 样本 | `x̄` | `(x̄ - 1)²` | 平方和 | 平方和 / n | 平方和 / (n - 1) |
| --- | --- | --- | --- | --- | --- |
| `(0, 0)` | 0 | 1 | 0 | 0 | 0 |
| `(0, 2)` | 1 | 0 | 2 | 1 | 2 |
| `(2, 0)` | 1 | 0 | 2 | 1 | 2 |
| `(2, 2)` | 2 | 1 | 0 | 0 | 0 |

`(0, 2)` 的均值是 1。两个偏差是 `-1` 和 `1`，平方和是 `1 + 1 = 2`。`(2, 0)` 相同。两端的样本里两个数相等，平方和是 0。

样本均值的抽样分布就是这四个数 `0, 1, 1, 2`。

```text
E[x̄] = (0 + 1 + 1 + 2) / 4 = 1
Bias = 1 - 1 = 0
Var(x̄) = (1 + 0 + 0 + 1) / 4 = 1/2
MSE = 1/2
```

偏差是 0，均方误差等于方差。标准误是抽样分布的标准差，`sqrt(1/2) ≈ 0.7071`。它是换一批样本时 `x̄` 散开的尺度。`(0, 2)` 这一次的均值是 1，这一次的 1 并不带着一份 0.7071。

独立时方差按条数缩小。概率笔记的恒等式是 `Var(X₁ + X₂) = Var(X₁) + Var(X₂) + 2 Cov(X₁, X₂)`。独立则协方差为 0，`Var(X₁ + X₂) = 1 + 1 = 2`。`x̄` 是这个和除以 2，方差再除以 4：

```text
Var(x̄) = 2 / 4 = 1/2 = σ² / n
```

第二条若是第一条的副本，样本只有 `(0, 0)` 和 `(2, 2)`，各概率 `1/2`。均值仍是 `0` 和 `2`，期望仍是 1，偏差仍是 0。方差是 `(1 + 1) / 2 = 1`。协方差等于 `Var(Y) = 1`，`Var(X₁ + X₂) = 1 + 1 + 2 = 4`，除以 4 得到 1。`σ² / n` 用了独立。相关样本上，样本均值可以仍无偏，抽样方差不再是 `σ² / n`。

## 两种方差估计

平方和除以 `n`，记为 `σ̂²`。平方和除以 `n - 1`，记为 `s²`。四个样本上：

```text
σ̂² ∈ {0, 1, 1, 0}
s²  ∈ {0, 2, 2, 0}
```

```text
E[σ̂²] = (0 + 1 + 1 + 0) / 4 = 1/2
Bias(σ̂²) = 1/2 - 1 = -1/2
```

四个偏离是 `-1/2, 1/2, 1/2, -1/2`，平方都是 `1/4`。

```text
Var(σ̂²) = 1/4
MSE(σ̂²) = 1/4 + (-1/2)² = 1/2
```

直接对真值做平均，核对交叉项没有漏：`(0 - 1)² = 1`，`(1 - 1)² = 0`，再两个相同，平均 `(1 + 0 + 0 + 1) / 4 = 1/2`。

```text
E[s²] = (0 + 2 + 2 + 0) / 4 = 1
Bias(s²) = 0
```

四个偏离是 `-1, 1, 1, -1`，平方都是 1。

```text
Var(s²) = 1
MSE(s²) = 1
```

`s²` 无偏。`σ̂²` 的期望小了 `1/2`，均方误差却是 `1/2`，小于 `s²` 的 1。无偏比较的是期望。这一组抽样分布上，带偏差的那个平均起来离 `σ²` 更近。

概率笔记已经证明：独立同分布、方差为 `σ²` 时，`E[σ̂²] = ((n - 1) / n) σ²`。证明用的是平方和恒等式和 `Var(x̄) = σ² / n`，没有用到高斯。这里 `n = 2`，`((2 - 1) / 2) * 1 = 1/2`，和四个数的平均相同。数据 `1, 2, 3` 上的 `2/3` 和 `1` 是另一次样本里的两个数，不是这个期望。

样本 `(0, 2)` 上，`σ̂² = 1`，刚好等于 `σ²`，`s² = 2`。这一次带偏差的估计量打中了真值，无偏的那个打在 2 上。打中一次不取消偏差，偏差是四个样本的平均减去 1。

若用 `x̄` 当这批样本的预测，训练均方误差就是 `σ̂²`。四个训练误差 `0, 1, 1, 0` 的平均是 `1/2`，就是泛化笔记里 `n = 2` 的期望训练误差。测试误差怎样随 `n` 变化，表留在那一篇。

## 已经得到的极大似然

概率笔记把三个极大似然推完了。本篇不再对对数似然求导，只看那些估计量的抽样分布。

**Bernoulli。** `p̂ = k / n`。它是 0-1 样本的均值，所以 `E[p̂] = p`，独立时 `Var(p̂) = p(1 - p) / n`。取 `p = 1/2`、`n = 2`，四个样本把这件事摊开：

| 样本 | `k` | `p̂` | `(p̂ - 1/2)²` |
| --- | --- | --- | --- |
| `(0, 0)` | 0 | 0 | `1/4` |
| `(0, 1)` | 1 | `1/2` | 0 |
| `(1, 0)` | 1 | `1/2` | 0 |
| `(1, 1)` | 2 | 1 | `1/4` |

```text
E[p̂] = (0 + 1/2 + 1/2 + 1) / 4 = 1/2
Var(p̂) = (1/4 + 0 + 0 + 1/4) / 4 = 1/8
p(1 - p) / n = (1/2 * 1/2) / 2 = 1/8
```

期望等于 `p`，方差等于公式。这四个样本是 0 和 1，上一节的总体是 0 和 2，两处不要当成同一批数。

**Categorical。** 概率笔记里 4 个样本、计数 `(2, 1, 1)`，极大似然是 `(1/2, 1/4, 1/4)`。类别 0 的频率 `2/4` 是四次指示变量的平均，指示变量本身是 Bernoulli。所以这一维的频率无偏，方差是 `p₀(1 - p₀) / N`，和 `k / n` 是同一个公式。`(2, 1, 1)` 是一次样本上的计数。要看偏差，得另抽许多个大小为 4 的样本再平均。拉格朗日那一步不在这里重写。

**高斯均值。** 极大似然是样本平均。无偏来自 `E[Xᵢ] = μ`，不需要密度是高斯。高斯的作用，是让这个平均成为极大似然。训练最小化的是平均负对数似然。`σ²` 固定为 1 时，概率笔记的对数似然去掉不依赖 `μ` 的项，再除以 `n` 取反，损失是

```text
L(μ) = (1 / (2n)) Σᵢ (Xᵢ - μ)²
∂L/∂μ = μ - x̄
```

梯度为 0 时 `μ = x̄`，就是那个极大似然。`σ²` 不固定时，对 `σ²` 的导数在概率笔记里，临界点是平方和除以 `n`。那个临界点就是上一节的 `σ̂²`，期望是 `((n - 1) / n) σ²`。

## 标准误和覆盖率

Wald 区间用估计量加减 1.96 倍标准误。1.96 是标准正态的 0.975 分位数。样本很大、而且标准误用对了的时候，独立同分布的样本均值接近这条正态，区间的覆盖率才接近 0.95。本篇不证明这个极限。`n = 2` 可以穷举覆盖率实际是多少。

标准误若用 `p̂(1 - p̂) / n` 代入，`p̂` 是 0 或 1 时标准误是 0，区间缩成一个点。

```text
p̂ = 0 → 区间 {0}
p̂ = 1 → 区间 {1}
```

真值 `1/2` 不在这两个点里。这两个样本各占概率 `1/4`。

`p̂ = 1/2` 时：

```text
SE = sqrt((1/2 * 1/2) / 2) = sqrt(1/8) ≈ 0.3536
1.96 * SE ≈ 0.6930
区间 ≈ [0.5 - 0.6930, 0.5 + 0.6930] = [-0.1930, 1.1930]
```

`1/2` 在里面。两个混合样本合起来概率 `1/2`。代入标准误的 Wald 区间，覆盖率是 `1/2`，不是 0.95。

若标准误用真值 `sqrt(p(1 - p) / n) = sqrt(1/8)`，半宽仍是约 `0.6930`，三个中心各得一条：

```text
p̂ = 0   → [-0.6930, 0.6930]
p̂ = 1/2 → [-0.1930, 1.1930]
p̂ = 1   → [0.3070, 1.6930]
```

三条都盖住 `1/2`，覆盖率是 1。差出来的是标准误的估计：代入把两端样本的标准误估成了 0。评估笔记里 100 题对 80 题的标准误是 `0.04`，区间是 `[0.7216, 0.8784]`；40 题全对时区间缩成 `[1, 1]`。那是同一种代入，数字不在这里重算。

## 全量均值再划分

四条已经到手的数：`0, 2, 4, 6`。前两条当训练，后两条当测试。

```text
训练均值 = (0 + 2) / 2 = 1
测试均值 = (4 + 6) / 2 = 5
全量均值 = (0 + 2 + 4 + 6) / 4 = 3
```

全量均值是两边的加权平均：`(2 * 1 + 2 * 5) / 4 = 3`。它离测试均值的距离，是训练均值那段距离乘上 `2/4`：

```text
3 - 5 = -2
(2/4) * (1 - 5) = -2
```

用一个常数 `c` 预测测试两条。概率笔记的平方和恒等式用在测试集上，测试均值是 5，余下的平方和是 `(4 - 5)² + (6 - 5)² = 2`：

```text
测试平方和(c) = 2 + 2 * (5 - c)²
```

```text
c = 1：2 + 2 * 16 = 34
c = 3：2 + 2 * 4 = 10
```

直接算：`(4 - 1)² + (6 - 1)² = 9 + 25 = 34`，`(4 - 3)² + (6 - 3)² = 1 + 9 = 10`。训练两条上：

```text
c = 1：(0 - 1)² + (2 - 1)² = 2
c = 3：(0 - 3)² + (2 - 3)² = 9 + 1 = 10
```

四条合在一起，`c = 1` 的平方和是 `2 + 34 = 36`，`c = 3` 的平方和是 `10 + 10 = 20`。全量均值把四条的平方和做到最小，这就是上一节那个梯度 `μ - x̄` 的零点，求和范围是四条。

估计量和评价各被污染了一处。

估计量。拿去当均值的数是 3，不是 1。3 用了测试两条 `4` 和 `6`。尺度也跟着换。训练两条对均值 1 的平方和是 2，除以 2 得 1，标准差是 1。四条对均值 3 的偏差是 `-3, -1, 1, 3`，平方 `9, 1, 1, 9`，和是 20，除以 4 得 5，标准差是 `sqrt(5) ≈ 2.2361`。测试两条减均值再除标准差：

```text
只用训练： (4 - 1) / 1 = 3 ， (6 - 1) / 1 = 5
用全量：   (4 - 3) / sqrt(5) = 1/sqrt(5) ≈ 0.4472
           (6 - 3) / sqrt(5) = 3/sqrt(5) ≈ 1.3416
```

后面的损失若吃这两个特征，吃到的是 `3, 5` 或约 `0.4472, 1.3416`。损失对权重的梯度是另一个函数。监督学习笔记里「先标准化再划分」说的就是这一步，那里没有这组数。

评价。报告「测试平方和是 10」，比只用训练均值的 34 小。小，是因为 3 被拉向了测试均值 5，距离变成原来的 `2/4`。只要训练均值不等于测试均值，全量均值的测试平方和就更小；两组均值相等时，两个估计量是同一个数，测试平方和相同。10 是「估计量看过测试点」之后的误差，不是「只用训练均值」这个过程的测试误差。

若这四条是独立同分布抽出的，训练均值和全量均值的期望都可以等于总体均值，两个都无偏。无偏没有取消上面两个差：全量均值仍是测试点的函数，用它算出的测试平方和在两边均值不同时一定更小。

`σ²` 固定为 1 时，平均负对数似然对 `μ` 的梯度是 `μ - x̄`。从 `μ = 0`、学习率 1 走一步，`μ` 落到对应的均值上：

```text
只用训练：梯度 = 0 - 1 = -1 ， 0 - 1 * (-1) = 1
用全量：  梯度 = 0 - 3 = -3 ， 0 - 1 * (-3) = 3
```

求和范围放进测试点，梯度里的 `x̄` 从 1 换成 3，同一步走到另一个参数。

## 小批量梯度

优化笔记把批量梯度定义成各条梯度的平均，再用 `θ ← θ - lr * g` 更新。本篇看这个平均在估计什么。

总体仍是 `Y ∈ {0, 2}`。损失用上一节的 `L`，`σ² = 1`。参数停在真均值 `c = 1` 时，一条样本的梯度是 `1 - Y`：`Y = 0` 给出 `1`，`Y = 2` 给出 `-1`。总体梯度的期望是 0。一条梯度的方差是 1。

两条独立样本的平均梯度：

| 样本 | 梯度 | 平均 |
| --- | --- | --- |
| `(0, 0)` | `1, 1` | 1 |
| `(0, 2)` | `1, -1` | 0 |
| `(2, 0)` | `-1, 1` | 0 |
| `(2, 2)` | `-1, -1` | -1 |

```text
E[ḡ] = (1 + 0 + 0 + (-1)) / 4 = 0
Var(ḡ) = (1 + 0 + 0 + 1) / 4 = 1/2
```

协方差为 0 时，`(1 + 1) / 4 = 1/2`，就是单条方差除以 2。

两条是同一条的副本时，平均梯度只有 `1` 和 `-1`，各概率 `1/2`。期望仍是 0。方差是 1。协方差是 1，`(1 + 1 + 2) / 4 = 1`。相关的小批量，梯度估计可以仍无偏，方差不是「条数分之一」。

从 `c = 1` 出发，学习率 `1/2`：

```text
独立：1 - (1/2) * {1, 0, 0, -1} = {1/2, 1, 1, 3/2}
复制：1 - (1/2) * {1, -1} = {1/2, 3/2}
```

独立的四个结果期望是 `(1/2 + 1 + 1 + 3/2) / 4 = 1`，方差是 `(1/4 + 0 + 0 + 1/4) / 4 = 1/8`。复制的两个结果期望也是 1，方差是 `(1/4 + 1/4) / 2 = 1/4`。参数的抽样方差等于学习率的平方乘梯度估计的方差：`(1/2)² * (1/2) = 1/8`，`(1/2)² * 1 = 1/4`。优化笔记用梯度 `1` 和 `3` 说明平均与求和差一个学习率；那一对梯度的期望不是 0。这里的 `1` 和 `-1` 用来看抽样方差。

## 容易算错的地方

- 一次样本上的估计不等于参数，只说明这次抽到了偏离。偏差是估计量的期望减去参数。样本 `(0, 2)` 上 `σ̂² = 1`，四个样本的平均仍是 `1/2`。
- 无偏不带来更小的均方误差。本篇 `s²` 的均方误差是 1，`σ̂²` 的是 `1/2`。
- `Var(x̄) = σ² / n` 用了独立。第二条是副本时，样本均值的方差是 1。
- 全量均值在独立同分布时仍可以无偏。估计量被污染的地方，是它用了测试点；评价被污染的地方，是测试平方和从 34 变成 10。
- `∂L/∂μ = μ - x̄` 的求和范围就是损失里的那些点。放进测试点，临界点从 1 换成 3。
- 代入的标准误是 0 时，Wald 区间是一个点。`n = 2`、`p = 1/2` 时，这种区间的覆盖率是 `1/2`。
- 本篇的偏差是 `E[θ̂] - θ`。泛化笔记的偏差是固定输入上 `f(x) - E[ŷ]`。两个差的对象不同。

### 练习 2：两种除法的均方误差

- 目标：偏差的平方和方差要加回均方误差，再用对真值的平方平均核对。
- 限制：纸笔。
- 题面：沿用练习 1 的四个样本。`σ̂²` 和 `s²` 的期望、偏差、方差、均方误差各是多少？
- 完成标准：`σ̂²` 的偏差是 `-1/2`，方差 `1/4`，均方误差 `1/2`。`s²` 的偏差是 0，方差 1，均方误差 1。

<details>
<summary>参考解答</summary>

`σ̂²` 是 `0, 1, 1, 0`，平均 `1/2`。四个 `(估计 - 1/2)²` 都是 `1/4`。`(1/2)² + 1/4 = 1/2`。直接算 `(0 - 1)²` 与 `(1 - 1)²` 的平均也是 `1/2`。`s²` 是 `0, 2, 2, 0`，平均 1，四个 `(估计 - 1)²` 都是 1。

</details>

### 练习 3：一次打中不是无偏

- 目标：把一次样本和抽样分布分开。
- 限制：纸笔。
- 题面：只看样本 `(0, 2)`。两个方差估计各是多少？哪一个等于 `σ²`？估计量 `σ̂²` 的偏差仍是多少？
- 完成标准：`σ̂² = 1`，`s² = 2`。偏差仍是 `-1/2`，因为期望要对四个样本取。

<details>
<summary>参考解答</summary>

均值是 1，平方和是 2。除以 2 得 1，除以 1 得 2。四个 `σ̂²` 的平均是 `1/2`，减去 1 得 `-1/2`。

</details>

### 练习 4：Bernoulli 的四个频率

- 目标：用抽样分布核对 `k/n`，不重推导数。
- 限制：纸笔。
- 题面：`p = 1/2`，`n = 2`。四个样本的 `p̂` 是多少？期望和方差是多少？`p(1-p)/n` 是多少？
- 完成标准：`0, 1/2, 1/2, 1`，期望 `1/2`，方差 `1/8`。

<details>
<summary>参考解答</summary>

`k` 是 `0, 1, 1, 2`。期望 `(0 + 1/2 + 1/2 + 1) / 4 = 1/2`。对 `1/2` 的平方是 `1/4, 0, 0, 1/4`，平均 `1/8`。`(1/2 * 1/2) / 2 = 1/8`。

</details>

### 练习 5：覆盖率不是 0.95

- 目标：代入标准误为 0 的样本单独算。
- 限制：纸笔。半宽可以用计算器核对到四位小数。
- 题面：练习 4 的四个样本。哪些样本的代入 Wald 区间盖住 `1/2`？覆盖率是多少？标准误改用 `sqrt(1/8)` 时，`p̂ = 0` 的区间约是多少，覆盖率变成多少？
- 完成标准：只有两个混合样本盖住，覆盖率 `1/2`。`p̂ = 0` 的已知标准误区间约是 `[-0.6930, 0.6930]`，四条都盖住。

<details>
<summary>参考解答</summary>

`p̂` 为 0 或 1 时区间是 `{0}` 或 `{1}`。`p̂ = 1/2` 时半宽约 `0.6930`，区间约 `[-0.1930, 1.1930]`。混合样本的概率是 `1/2`。已知标准误时半宽仍约 `0.6930`。`p̂ = 0` 的区间约是 `[-0.6930, 0.6930]`，`p̂ = 1` 约是 `[0.3070, 1.6930]`，中心在 `1/2` 的那条也含 `1/2`。四个样本都盖住，覆盖率是 1。

</details>

### 练习 6：全量均值的测试平方和

- 目标：估计量和评价各写一个数。
- 限制：纸笔。
- 题面：数据 `0, 2, 4, 6`，前两条训练，后两条测试。两个均值是多少？测试平方和各是多少？训练平方和各是多少？若四条独立同分布，无偏能取消哪一个差距？
- 完成标准：均值 1 和 3。测试平方和 34 和 10。训练平方和 2 和 10。无偏取消不了「3 依赖测试点」和「10 小于 34」。

<details>
<summary>参考解答</summary>

`(0+2)/2 = 1`，`(0+2+4+6)/4 = 3`。测试：`9+25 = 34`，`1+9 = 10`。训练：`1+1 = 2`，`9+1 = 10`。两个均值的期望都可以是总体均值。3 仍用到 4 和 6，测试平方和仍从 34 降到 10。

</details>

### 练习 7：梯度走到哪一个均值

- 目标：求和范围写进梯度。
- 限制：纸笔。标准差的小数可以用计算器核对到四位。
- 题面：`σ² = 1`，`L` 是平均负对数似然。从 `μ = 0`、学习率 1 出发，只用训练和用全量，各走一步落到哪里？测试两条用全量均值和 `sqrt(5)` 标准化之后约是多少？
- 完成标准：落到 1 和 3。标准化约是 `0.4472` 和 `1.3416`。

<details>
<summary>参考解答</summary>

梯度是 `μ - x̄`，在 0 处是 `-1` 和 `-3`。减去学习率乘梯度，落到 1 和 3。四条的平方和是 20，除以 4 得 5。`(4-3)/sqrt(5)` 与 `(6-3)/sqrt(5)` 约是 `0.4472` 和 `1.3416`。

</details>

### 练习 8：复制的小批量

- 目标：协方差项留在梯度的方差里。
- 限制：纸笔。
- 题面：`c = 1`，单条梯度是 `1` 或 `-1`。两条独立时平均梯度的方差是多少？两条是副本时是多少？学习率 `1/2` 之后，参数的方差各是多少？
- 完成标准：梯度方差 `1/2` 和 1。参数方差 `1/8` 和 `1/4`。

<details>
<summary>参考解答</summary>

独立的平均是 `1, 0, 0, -1`，平方平均 `1/2`。副本的平均是 `1` 或 `-1`，方差是 1。`(1/2)² * (1/2) = 1/8`，`(1/2)² * 1 = 1/4`。四个更新 `1/2, 1, 1, 3/2` 对 1 的平方平均也是 `1/8`。

</details>
