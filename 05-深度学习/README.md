## 完成时你能做什么

- 对一个两层标量网络手算梯度，并用有限差分复核到允许的误差。
- 使用统一约定：`W` 的形状是 `(out, in)`，`y = x @ W.T + b`。
- 写出 `y = x + f(x)` 时 `dy/dx = 1 + f'(x)`。`f'` 为 0 时，梯度仍经 `1` 这条路径传回。
- 说明 BatchNorm 的统计量来自批内（推理时常用滑动平均），LayerNorm 的统计量来自单个样本的特征维。
