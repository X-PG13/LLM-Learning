## 本篇要回答的问题

1. 标量损失对每个参数的偏导，为什么可以沿计算图逐段相乘？
2. 一个两层网络里，ReLU 输入为负时，前面的参数为什么这一步得不到梯度？
3. 有限差分在核对什么，它为什么不代替训练？
4. 反向模式自动微分为什么适合「损失是标量、参数很多」？
5. `y = x + f(x)` 在 `f'(x) = 0` 时，`dy/dx` 还剩下什么？

## 一个具体的网络

全部使用标量，便于手算。网络是

```text
z = w1 * x + b1
h = relu(z)
y = w2 * h + b2
L = (y - t)² / 2
```

`relu(z)` 在 `z > 0` 时等于 `z`，否则等于 0。损失带 `1/2`，是为了让 `dL/dy = y - t`，少一个常数因子。

第一组数：`x = 2`，`w1 = 1/2`，`b1 = 0`，`w2 = -3/2`，`b2 = 0`，目标 `t = 1`。

前向：

```text
z = (1/2) * 2 + 0 = 1
h = relu(1) = 1
y = (-3/2) * 1 + 0 = -3/2
L = (1/2) * (-3/2 - 1)² = (1/2) * (-5/2)² = (1/2) * (25/4) = 25/8 = 3.125
```

## 反向

标量链式法则：若 `L` 经 `y` 依赖 `h`，`h` 又依赖 `z`，则

```text
dL/dz = dL/dy · dy/dh · dh/dz
```

每一段只使用本地的导数，再乘上从损失传回来的那一个数。

```text
dL/dy = y - t = -3/2 - 1 = -5/2
dy/dw2 = h = 1          → dL/dw2 = -5/2
dy/db2 = 1              → dL/db2 = -5/2
dy/dh = w2 = -3/2       → dL/dh = (-5/2) * (-3/2) = 15/4
```

`z = 1 > 0`，所以 `dh/dz = 1`，`dL/dz = 15/4`。

```text
dz/dw1 = x = 2          → dL/dw1 = (15/4) * 2 = 15/2 = 7.5
dz/db1 = 1              → dL/db1 = 15/4 = 3.75
dz/dx = w1 = 1/2        → dL/dx = (15/4) * (1/2) = 15/8 = 1.875
```

`dL/dx` 这一行训练时通常不算进参数更新，它用来检查输入端的梯度有没有断。

这些分数由 `check_backprop` 复核。

## 有限差分

把某个参数加上很小的 `ε`，看损失变化，再除以 `ε`：

```text
(L(θ + ε) - L(θ)) / ε
```

它近似 `dL/dθ`。`ε = 10⁻⁶` 时，上面四个参数的差商与解析梯度的差在 `10⁻⁴` 量级以内（脚本的容差）。用它核对公式和实现。它每核对一个参数就要多做一次前向，不能当作训练算法。`ε` 太大则近似差，太小则浮点相减把有效数字减掉。

## ReLU 挡住梯度的例子

把 `w1` 改成 `-1/2`，其余不变。

```text
z = (-1/2) * 2 = -1
h = relu(-1) = 0
y = 0
L = (1/2) * (0 - 1)² = 1/2
```

`z < 0` 时 `dh/dz = 0`，于是 `dL/dz = 0`，`dL/dw1 = 0`，`dL/db1 = 0`。这一步，`w1` 和 `b1` 没有来自这条样本的更新方向。`w2` 的梯度是 `dL/dy * h = 0`，因为隐藏单元输出是 0。损失对 `y` 的导数是 `-1`，它传到了 `h` 的上游位置 `dL/dh = -1 * w2 = 3/2`，再往前被 ReLU 乘成 0。

这个例子里 `z` 严格小于 0，导数没有歧义。`z = 0` 时左导数是 0、右导数是 1。实现里通常把这一点的导数取 0。写测试时避开「刚好为 0」的偶然情况，或者把这个约定写成断言。

有限差分在 `w1 = -1/2` 附近移动 `10⁻⁶` 仍落在负半轴，差商为 0，与解析结果一致。

## 反向模式

向量情形下，每一层有一个 Jacobian。反向传播算的是 Jacobian 与上游梯度的乘积，不把整个 Jacobian 存下来。

损失是一个标量，参数是高维的。反向模式的代价大约是前向的一个小常数倍，不随参数个数再乘一层。前向模式则要对每个输入方向各推一次。训练选择反向模式，就是因为输出是一个损失、输入是全部参数。

自动微分核对的是「代码所实现的函数」的导数。它发现不了损失本身设错，例如标签没有错位、却仍然光滑下降。系统开篇用一个会下降的错误目标说明这件事。

## 线性层的形状

标量例子不涉及转置。进入矩阵时使用 [记号约定](../记号约定.md)：输入最后一维是 `in_features`，`W` 的形状是 `(out_features, in_features)`，`b` 的形状是 `(out_features,)`，`y = x @ W.T + b`。列向量形式就是 `y = W x + b`，`W` 的列是输入基的像。

一个形状核对，先不做梯度：批量 2，输入维 3，输出维 4。

```text
x : (2, 3)
W : (4, 3)
b : (4,)
y : (2, 4)
```

`(2, 3) @ (3, 4) + (4,)` 得到 `(2, 4)`。`W.T` 是 `(3, 4)`。形状对不上时先改形状，不要先改学习率。

## 向前看：残差和两种归一化

残差写成 `y = x + f(x)`。标量时

```text
dy/dx = 1 + f'(x)
```

即使 `f'(x) = 0`，`dy/dx` 仍是 1。损失对 `x` 的梯度留着这条直通路径。深层网络使用残差，一个原因就是避免整条链上的导数连乘变成 0。前置归一化和后置归一化把这条加法放在 LayerNorm 的哪一侧，见 [自注意力与 Transformer 块](../06-大语言模型/02-自注意力与Transformer.md)。导数结构就是这一句。

归一化的两种常见统计范围：

- BatchNorm：对一个批量里同一通道的样本计算均值和方差，推理时常用训练阶段积累的滑动平均。批量很小或样本之间不该混在一起时，这个统计不稳定。
- LayerNorm：对单个样本自己的特征维计算均值和方差，不读取批里的其他样本。

RMSNorm 不做减均值，用均方根缩放。公式留到结构笔记。现代 Transformer 使用的是 LayerNorm 这一类「不依赖批内其他样本」的归一化，而不是 BatchNorm。

## 容易算错的地方

- `L = (y - t)² / 2` 时 `dL/dy = y - t`。若损失写成 `(y - t)²` 而导数仍用 `y - t`，会差一个 2。有限差分能抓住这个常数。
- ReLU 的导数乘在上游梯度上。忘记乘，负半轴的参数仍会收到更新。
- 形状 `(batch, time, vocab)` 不是线性层的 `(batch, in)`。语言建模的三维张量在系统笔记里单独列清单，不在这里当成矩阵乘的默认形状。
- 自动微分通过，只说明实现和某段程序一致。标签定义错了，程序内部仍然自洽。

## 练习

### 练习 1：重做前向和反向

- 目标：四个参数的梯度都能手算。
- 限制：纸笔，使用分数。
- 题面：`x = 2`，`w1 = 1/2`，`b1 = 0`，`w2 = -3/2`，`b2 = 0`，`t = 1`。计算 `L`、`dL/dw1`、`dL/db1`、`dL/dw2`、`dL/db2`。
- 完成标准：`L = 25/8`，`dL/dw1 = 15/2`，`dL/db1 = 15/4`，`dL/dw2 = dL/db2 = -5/2`。

<details>
<summary>参考解答</summary>

见正文前向与反向两节。脚本 `check_backprop` 用浮点复核 3.125、7.5、3.75 和 -2.5。

</details>

### 练习 2：让 ReLU 关掉

- 目标：指出梯度在哪一段变成 0。
- 限制：纸笔。
- 题面：`w1 = -1/2`，其余与练习 1 相同。计算 `z`、`h`、`dL/dw1`、`dL/dh`。
- 完成标准：`dL/dw1 = 0`，同时 `dL/dh` 不是 0。

<details>
<summary>参考解答</summary>

`z = -1`，`h = 0`，`y = 0`，`dL/dy = -1`，`dL/dh = -1 * (-3/2) = 3/2`。`dh/dz = 0`，所以 `dL/dw1 = 0`。梯度传到了 ReLU 的输出侧，没有穿过 ReLU。

</details>

### 练习 3：写一次有限差分

- 目标：会选一个参数核对，而不是把差分当训练。
- 限制：可以运行一段短 Python。`ε = 1e-6`。
- 题面：对练习 1 的 `w1` 计算差商，和 `15/2` 比较。
- 完成标准：绝对误差小于 `1e-4`。

<details>
<summary>参考解答</summary>

脚本里的差商约为 7.5000045，与 7.5 的差远小于 `1e-4`。实现时只扰动 `w1`，其余参数保持正文的值。

</details>

### 练习 4：给网络加的偏置已经在公式里

- 目标：偏置的本地导数是 1。
- 限制：纸笔。
- 题面：在练习 1 的数字上，为什么 `dL/db2 = dL/dy`，而 `dL/db1 = dL/dz`？若把 `b2` 初始化成 0.25 而不是 0，`dL/db2` 的形式变不变，数值变不变？
- 完成标准：分开回答形式和数值。

<details>
<summary>参考解答</summary>

`y = w2 * h + b2`，所以 `dy/db2 = 1`，`dL/db2 = dL/dy`。`z = w1 * x + b1`，所以 `dz/db1 = 1`，在 ReLU 导通时 `dL/db1 = dL/dz`。形式不变。`b2` 改成 0.25 后 `y` 变了，`dL/dy = y - t` 的数值变了，因此 `dL/db2` 的数值变。

</details>

### 练习 5：反向模式的适用条件

- 目标：用输入输出的维数选择模式。
- 限制：文字。
- 题面：损失是一个数，参数有 `10⁷` 个。为什么训练用反向模式？若你要的是「每个输入特征单独对输出的敏感度」而且特征只有 5 个、参数也只有 5 个，前向模式的代价还吓人吗？
- 完成标准：第一问答出「标量输出」。第二问承认小维度时两种都可以。

<details>
<summary>参考解答</summary>

反向模式对标量输出只需要一次与前向同量级的回传，就能得到全部参数的梯度。前向模式要对每个参数方向各做一次，`10⁷` 次不可接受。输入和参数都只有 5 个时，前向模式是 5 次小计算，没有同样的障碍。选择来自维数，不来自名字。

</details>

### 练习 6：残差的直通路径

- 目标：把 `1 + f'` 用在梯度被挡住的情形。
- 限制：纸笔。
- 题面：标量 `y = x + relu(w * x)`，`x = 2`，`w = -1`。计算 `dy/dx`。
- 完成标准：结果是 1，并说明 ReLU 内部那一项的导数是 0。

<details>
<summary>参考解答</summary>

`w * x = -2 < 0`，`relu` 输出 0，对 `x` 的导数是 0。`dy/dx = 1 + 0 = 1`。

</details>

### 练习 7：读形状

- 目标：矩阵乘法之前先写形状。
- 限制：不计算数值。
- 题面：`x` 是 `(8, 16)`，`W` 是 `(32, 16)`，`b` 是 `(32,)`。`y = x @ W.T + b` 的形状是什么？若有人把 `W` 存成 `(16, 32)` 却仍调用同一行代码，会在哪一次乘法上失败？
- 完成标准：给出 `(8, 32)`，并指出 `W.T` 变成了 `(32, 16)`，与 `x` 的最后一维 16 对不上。

<details>
<summary>参考解答</summary>

约定下 `W.T` 是 `(16, 32)`，`(8, 16) @ (16, 32)` 得到 `(8, 32)`，再加 `(32,)`。若 `W` 实际是 `(16, 32)`，`W.T` 是 `(32, 16)`，`(8, 16) @ (32, 16)` 的内维 16 和 32 不一致。

</details>
