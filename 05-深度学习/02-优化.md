## 本篇要回答的问题

1. 损失对一个小批量取平均时，改成求和，等价于把学习率乘上多少？
2. 动量在梯度持续同号时，为什么同一步的参数变化比 SGD 更大？
3. 梯度是常数、矩从 0 开始时，偏差修正为什么把 Adam 的一步变成「学习率乘符号」？
4. AdamW 的权重衰减为什么没有被自适应分母除掉？
5. warmup 的乘数在 `t = 0` 是多少，余弦段在最后一步落到哪里？

## 一步在改什么

参数记为 `θ`。反向传播给出标量损失对 `θ` 的梯度 `g`。梯度下降沿梯度的反方向走：

```text
θ ← θ - lr * g
```

`lr > 0` 是学习率。损失在 `θ` 附近若能用切平面近似，这一步让切平面上的值下降。步子比近似成立的范围更大时，损失可以上升。

神经网络的损失一般非凸。一步之后损失变小，只说明这一步在下降，不说明到了全局最小。篇末用一个有两个谷底的标量函数把这句话算出来。

本篇的动量、Adam、AdamW 都按 PyTorch 的更新写。`SGD` 的 `dampening` 取默认值 0，动量项是 `μ v + g`，不是 `μ v + (1-μ) g`。Adam 的 `ε` 加在 `sqrt(v̂)` 外面。别的书把这些系数写进动量或写进平方根里时，先把公式对齐再比较数字。

## 小批量是梯度的平均

一批里每条样本有自己的梯度。本篇把批量梯度定义成这些梯度的算术平均，对应损失 `reduction='mean'`。

两条样本的梯度是 `1` 和 `3`，平均是 `2`。`θ` 从 `0` 出发，`lr = 0.1`：

```text
θ ← 0 - 0.1 * 2 = -0.2
```

若损失改成求和，梯度变成 `1 + 3 = 4`，同一步走到 `-0.4`。求和梯度是平均梯度的批量大小倍。批量大小是 2 时，求和加上原来的学习率，等于平均加上两倍的学习率。

换批量大小时要同时看平均方式。平均损失下，批量从 2 改成 8，梯度的期望尺度不变，方差通常变小。求和损失下，批量乘 4，梯度的尺度也乘 4。这时若还把学习率乘 4，步长就乘了 16。线性缩放学习率（批量乘 `k` 时学习率也乘 `k`）说的是平均梯度那一种约定；它是大批量训练里的一种做法，不是定义。

## 学习率在二次函数上的三种结局

取 `L(w) = w² / 2`，则 `dL/dw = w`。更新是

```text
w ← w - lr * w = (1 - lr) w
```

从 `w₀ = 1` 出发，`t` 步之后 `w_t = (1 - lr)^t`。

| `lr` | 前几步的 `w` | 结局 |
| --- | --- | --- |
| `1/2` | `1, 1/2, 1/4, 1/8, …` | 收敛到 0 |
| `1` | `1, 0, 0, …` | 一步到最小值 |
| `3/2` | `1, -1/2, 1/4, -1/8, …` | 正负交替，幅度减半，仍收敛 |
| `2` | `1, -1, 1, -1, …` | 在两个点之间振荡 |
| `3` | `1, -2, 4, -8, 16, …` | 幅度按 2 倍增长 |

`|1 - lr| < 1` 时收敛到 0，也就是 `0 < lr < 2`。`lr = 2` 时参数在 `1` 和 `-1` 之间振荡，损失停在 `1/2`。`lr = 3` 时损失变成 `1/2, 2, 8, 32, …`。这个函数是凸的，过大的学习率仍然会把参数甩离最小值。

## 动量

PyTorch 的 SGD 动量，`dampening = 0`、不用 Nesterov 时：

```text
v ← μ v + g
θ ← θ - lr * v
```

`v` 从 0 开始。`μ` 通常取 `0.9`。梯度同号时，`v` 把过去的梯度留住，这一步的位移比 `lr * g` 大。梯度改号时，旧的 `v` 会拖住新方向，步子变短，振荡变轻。Nesterov 在更新前先看 `θ - lr μ v` 上的梯度，本篇不手算那一种。

用同一个二次函数核对。`w₀ = 1`，`lr = 1/10`，`μ = 9/10`，`g = w`。

```text
第 1 步：v = 1，           w = 1 - (1/10)*1 = 9/10
第 2 步：v = (9/10)*1 + 9/10 = 9/5
         w = 9/10 - (1/10)*(9/5) = 18/25
第 3 步：v = (9/10)*(9/5) + 18/25 = 117/50
         w = 18/25 - (1/10)*(117/50) = 243/500
```

小数是 `0.9`、`0.72`、`0.486`。同学习率、无动量的三步是 `0.9`、`0.81`、`0.729`。三步之后动量走到 `0.486`，SGD 还在 `0.729`。这段里梯度一直为正，速度越积越大，所以走得更远。这不是「动量总是更好」，只是同号梯度时的算术。

`v` 是优化器状态，不是参数。保存检查点时若只保存 `w`，下一步会从 `v = 0` 重新积累，轨迹和不断点不同。

## Adam 的两个矩和偏差修正

Adam 为每个坐标维护梯度的一阶矩 `m` 和二阶矩 `v`，都从 0 开始。第 `t` 步（`t` 从 1 计）：

```text
m ← β₁ m + (1 - β₁) g
v ← β₂ v + (1 - β₂) g²
m̂ = m / (1 - β₁ᵗ)
v̂ = v / (1 - β₂ᵗ)
θ ← θ - lr * m̂ / (sqrt(v̂) + ε)
```

默认 `β₁ = 0.9`，`β₂ = 0.999`，`ε = 10⁻⁸`，`lr = 0.001`。除法按坐标进行。`t` 从 1 开始；`t = 0` 时分母 `1 - βᵗ` 是 0。

先令 `ε = 0`，看一个常数梯度。标量 `g` 每步都是同一个数，`m` 和 `v` 从 0 开始，可以归纳出

```text
mₜ = g (1 - β₁ᵗ)
vₜ = g² (1 - β₂ᵗ)
```

偏差修正之后 `m̂ = g`，`v̂ = g²`，所以

```text
m̂ / sqrt(v̂) = sign(g)
```

`g ≠ 0` 时，每一步参数恰好改变 `lr` 的长度，方向与 `g` 相反。梯度的大小被除掉了。SGD 的步长是 `lr * |g|`，Adam 在这个常数情形下的步长是 `lr`。

手算：`g = 1/2`，`lr = 0.001`，`β₁ = 0.9`，`β₂ = 0.999`。

```text
第 1 步：m = 0.1 * 0.5 = 0.05
         v = 0.001 * 0.25 = 0.00025
         m̂ = 0.05 / 0.1 = 0.5
         v̂ = 0.00025 / 0.001 = 0.25
         m̂ / sqrt(v̂) = 0.5 / 0.5 = 1
         θ 的变化 = -0.001
```

第 2 步 `m = 0.9*0.05 + 0.1*0.5 = 0.095`，`1 - β₁² = 0.19`，`m̂` 仍是 `0.5`。`v̂` 仍是 `0.25`。常数梯度下每一步都是这样。

若不做偏差修正，第 1 步用 `m / sqrt(v)`：

```text
0.05 / sqrt(0.00025) = 0.1 / sqrt(0.001) = sqrt(10) ≈ 3.162278
```

步长变成 `0.001 * sqrt(10) ≈ 0.003162`，是修正后的 `sqrt(10)` 倍。矩从 0 开始时，`β₂` 比 `β₁` 更接近 1，二阶矩在最初几步比一阶矩更「偏小」，不修正的话分母过小，步子过大。

`ε = 10⁻⁸` 时分母是 `0.5 + 10⁻⁸`，步长略小于 `0.001`。数量级是 `10⁻⁸` 相对 `0.5`。零梯度的坐标在下面一节单独算，那里分子是 0，`ε` 不产生位移。

## AdamW：权重衰减不进矩

耦合的 L2 把 `λ θ` 加进梯度，再送进 Adam。自适应分母会把这个加上去的项和损失梯度一起归一化。AdamW 把权重衰减从矩里拿出来，直接加在参数上。PyTorch 的顺序是先衰减参数，再用原始梯度更新矩：

```text
θ ← θ - lr * λ * θ
m、v 仍只用损失的梯度 g 更新
θ ← θ - lr * m̂ / (sqrt(v̂) + ε)
```

两式合成 `θ ← θ (1 - lr λ) - lr m̂ / (sqrt(v̂) + ε)`。`λ` 是权重衰减系数。AdamW 的默认 `λ` 是 `0.01`，和「损失里加 `0.01 ‖θ‖²`」不是同一个目标。

手算一个二维参数，`ε = 0`，`t = 1`，`lr = 0.001`，`λ = 0.01`，`θ = (1, 1)`，`g = (1/2, 0)`。

AdamW：

```text
衰减量：lr * λ * 1 = 0.00001，两个坐标一样
第一维：自适应步长 0.001，因为常数梯度情形 m̂/sqrt(v̂) = 1
         θ₀ = 1 - 0.00001 - 0.001 = 0.99899
第二维：g = 0，所以 m̂ = 0，自适应步长 0
         θ₁ = 1 - 0.00001 = 0.99999
```

耦合形式先把梯度改成 `g + λ θ = (0.51, 0.01)`。`t = 1` 且 `ε = 0` 时，每个非零坐标的 `m̂ / sqrt(v̂)` 都是 `sign(g')`，两个坐标的自适应步长都是 `0.001`：

```text
θ = (0.999, 0.999)
```

第二维的损失梯度是 0，耦合形式仍然走了完整的一个学习率。权重衰减制造了一个很小的梯度 `0.01`，Adam 把它归一化成了符号 `1`。AdamW 在这一维只走 `0.00001`。这就是「衰减被自适应分母放大」和「衰减按 `lr λ θ` 原样减去」的差别。

`ε = 10⁻⁸` 时第一维略偏离上面的小数，偏离量在 `10⁻⁸` 到 `10⁻¹¹` 这一档，脚本按公式核对。第二维在 AdamW 下分子仍是 0，结果仍是 `0.99999`。

衰减项带学习率。warmup 把 `lr` 降到 0 时，这一项也是 0。日程放大或缩小的是损失梯度和权重衰减的同一次步长。

## 学习率日程

记优化器里设置的学习率为峰值 `lr_peak`。实际使用 `lr_peak * λ(t)`。本篇的 `λ` 与 Hugging Face Transformers 4.46 里 `get_cosine_schedule_with_warmup` 在 `num_cycles = 0.5` 时一致，`t` 从 0 计：

```text
t < warmup:   λ(t) = t / warmup
t ≥ warmup:   progress = (t - warmup) / (total - warmup)
              λ(t) = max(0, 0.5 * (1 + cos(π * progress)))
```

`warmup = 4`，`total = 8`，`lr_peak = 0.001`：

| `t` | `λ(t)` | 学习率 |
| --- | --- | --- |
| 0 | `0` | `0` |
| 1 | `1/4` | `0.00025` |
| 2 | `1/2` | `0.0005` |
| 3 | `3/4` | `0.00075` |
| 4 | `1` | `0.001` |
| 6 | `1/2` | `0.0005` |
| 8 | `0` | `0` |

`t = 4` 已经不在 warmup 里：条件是 `t < 4`。它的 `progress = 0`，余弦还在峰值。`t = 6` 的 `progress = 1/2`，`cos(π/2) = 0`，乘数是 `1/2`。`t = 8` 的 `progress = 1`，`cos(π) = -1`，乘数是 0。`t = 5` 的乘数是 `1/2 + sqrt(2)/4`，留给练习。

`LambdaLR` 的说明文字写着：`last_epoch = -1` 时，初始学习率就是优化器里的那个数。PyTorch 2.5 的 `LRScheduler.__init__` 末尾会调用 `_initial_step`，而 `_initial_step` 再调用 `step`。`last_epoch` 从 `-1` 变成 `0`，学习率立刻变成 `lr_peak * λ(0)`。以这份实现为准。warmup 公式给出的第一个值是 0。训练循环应先 `optimizer.step()` 再 `scheduler.step()`。构造之后若先多调用一次 `scheduler.step()`，第一次参数更新用的是 `λ(1)`，`λ(0)` 被跳过。官方说明里的警告指的就是这个顺序。

线性 warmup 本身是大批量 SGD 里用来稳住开头几步的办法。余弦后半段来自另一种日程。换数据或换总步数，峰值和 warmup 长度都要重新看损失，不能沿用别人的步数。

## 非凸时，下降不是全局最小

```text
L(w) = w⁴ / 4 - w² / 2
L'(w) = w³ - w = w (w - 1) (w + 1)
```

`w = 1` 和 `w = -1` 处导数为 0，`L = -1/4`。`w = 0` 也是导数为 0 的点，`L = 0`，是局部的峰。两个谷底一样深。

从 `w = 1/2` 出发，`L'(1/2) = 1/8 - 1/2 = -3/8`。`lr = 0.1`：

```text
w ← 1/2 - 0.1 * (-3/8) = 0.5375
L(1/2) = -0.109375
```

`0.5375` 比 `0.5` 更靠近 `+1`，损失低于 `-0.109375`。从 `-1/2` 出发会对称地走向 `-1`。两次都在下降，落点取决于起点。损失下降不挑选「另一个同样深的谷」。

## 参考代码

动量和 AdamW 的一步。`adamw_step` 的 `step` 从 1 计。`v̂` 和 `m̂` 同时为 0 时自适应项取 0，这样 `ε = 0` 的手算能跑完；PyTorch 用 `ε > 0`，分子为 0 时结果同样是 0。

```python
def sgd_momentum(theta, grad, velocity, lr, mu):
    velocity = mu * velocity + grad
    return theta - lr * velocity, velocity


def adamw_step(theta, grad, m, v, step, lr, beta1, beta2, eps, weight_decay):
    theta = [th * (1 - lr * weight_decay) for th in theta]
    m = [beta1 * mi + (1 - beta1) * g for mi, g in zip(m, grad)]
    v = [beta2 * vi + (1 - beta2) * g * g for vi, g in zip(v, grad)]
    updated = []
    for th, mi, vi in zip(theta, m, v):
        m_hat = mi / (1 - beta1**step)
        v_hat = vi / (1 - beta2**step)
        adapt = 0.0 if m_hat == 0.0 and v_hat == 0.0 else m_hat / (v_hat**0.5 + eps)
        updated.append(th - lr * adapt)
    return updated, m, v
```

## 容易算错的地方

- 求和损失的梯度带着批量大小。只把学习率按批量线性放大，又使用求和，步长被乘了两次。
- `L(w) = w² / 2` 的梯度是 `w`，不是 `2w`。损失若写成 `w²`，梯度才是 `2w`，同样的 `lr = 2` 会对应到另一条轨迹。
- 动量缓冲 `v` 和参数是两份状态。`μ = 0.9` 时不要把更新写成 `θ - lr (0.9 g_old + 0.1 g)`，那是另一种平均。
- Adam 的 `t` 从 1 计。偏差修正的分母是 `1 - βᵗ`，不是 `1 - β`。常数梯度、不做修正时，本篇这组 `β` 的第一步大了 `sqrt(10)` 倍。
- PyTorch 的 `ε` 默认是 `10⁻⁸`，加在 `sqrt(v̂)` 外面。《动手学深度学习》的 Adam 示例把 `ε` 取成 `10⁻⁶`。常数梯度、`ε = 0` 时的符号步长不依赖这个差别；把两边的更新数字直接对比之前先对齐 `ε`。
- 耦合 L2 进 Adam 之后，很小的 `λ θ` 也可以变成长度为 `lr` 的一步。AdamW 的第二维在例子里只移动 `lr λ θ`。
- 余弦日程的 `t = warmup` 已经是峰值，不是 warmup 的最后一档 `1 - 1/warmup`。`t` 从 0 还是从 1 计，差的就是这一档。

## 练习

### 练习 1：批量的平均和求和

- 目标：把 `reduction` 换算成学习率。
- 限制：纸笔。
- 题面：梯度 `1` 和 `3`，`lr = 0.1`，`θ` 从 `0` 出发。平均梯度走一步到哪里？求和梯度走一步到哪里？求和这一步相当于平均梯度配多大的学习率？
- 完成标准：`-0.2` 和 `-0.4`。等效学习率是 `0.2`。

<details>
<summary>参考解答</summary>

平均梯度 `2`，位移 `-0.2`。求和梯度 `4`，位移 `-0.4`。`0.1 * 4 = 0.2 * 2`，等效学习率是 `0.2`，正好是批量大小 2 倍。

</details>

### 练习 2：二次函数的学习率边界

- 目标：用 `w ← (1 - lr) w` 判断收敛。
- 限制：纸笔。
- 题面：`L = w² / 2`，`w₀ = 1`。`lr` 分别取 `1/2`、`2`、`3`，写出前四步之后的 `w`（含起点共五个数），并说明哪几个会到 0。
- 完成标准：三行分别是 `1, 1/2, 1/4, 1/8, 1/16`；`1, -1, 1, -1, 1`；`1, -2, 4, -8, 16`。只有 `1/2` 收敛到 0。

<details>
<summary>参考解答</summary>

公比分别是 `1/2`、`-1`、`-2`。`|1 - lr| < 1` 才收敛。`lr = 2` 在 ±1 之间振荡，`lr = 3` 幅度指数增长。

</details>

### 练习 3：把动量的三步写成分数

- 目标：速度项要累积，不能只看当前梯度。
- 限制：纸笔。
- 题面：`w₀ = 1`，`g = w`，`lr = 1/10`，`μ = 9/10`，`v₀ = 0`。计算三步后的 `v` 和 `w`。
- 完成标准：`v` 是 `1`、`9/5`、`117/50`，`w` 是 `9/10`、`18/25`、`243/500`。

<details>
<summary>参考解答</summary>

见正文。`243/500 = 0.486`。无动量的第三步是 `729/1000 = 0.729`，因为每步只减当前 `w` 的十分之一。脚本 `check_optimizer` 用分数复核。

</details>

### 练习 4：偏差修正的第一步

- 目标：看出不修正时的倍数是 `sqrt(10)`。
- 限制：纸笔。`β₁ = 0.9`，`β₂ = 0.999`，`g = 1/2`，`ε = 0`。
- 题面：计算第 1 步的 `m`、`v`、`m̂`、`v̂`。不修正时 `m/sqrt(v)` 是多少？它和 `1` 的比是什么？
- 完成标准：修正后比值是 `1`。不修正的比值是 `sqrt(10)`。

<details>
<summary>参考解答</summary>

`m = 0.05`，`v = 0.00025`，`m̂ = 0.5`，`v̂ = 0.25`，比值 `1`。`0.05/sqrt(0.00025) = sqrt(10)`。

</details>

### 练习 5：二维的 AdamW 和耦合 L2

- 目标：零梯度的那个坐标两种算法不同。
- 限制：纸笔，`ε = 0`。
- 题面：`θ = (1, 1)`，`g = (1/2, 0)`，`lr = 0.001`，`λ = 0.01`，`t = 1`，矩从 0 开始。分别计算 AdamW 和耦合形式更新后的 `θ`。
- 完成标准：AdamW 是 `(0.99899, 0.99999)`。耦合形式是 `(0.999, 0.999)`。

<details>
<summary>参考解答</summary>

AdamW 每个坐标先减 `0.00001`。第一维再减 `0.001`，第二维自适应项是 0。耦合梯度是 `(0.51, 0.01)`，两维的 `m̂/sqrt(v̂)` 都是 `1`，各减 `0.001`。

</details>

### 练习 6：读日程表

- 目标：warmup 的边界用 `t < warmup` 判断。
- 限制：可以查正文的公式，先不要看表里的最终数字。
- 题面：`warmup = 4`，`total = 8`。计算 `λ(0)`、`λ(4)`、`λ(6)`、`λ(8)`。再计算 `λ(5)` 的精确式。
- 完成标准：`0`、`1`、`1/2`、`0`。`λ(5) = 1/2 + sqrt(2)/4`。

<details>
<summary>参考解答</summary>

`t = 0` 在 warmup 内，`0/4 = 0`。`t = 4` 的 progress 是 0，余弦乘数是 1。`t = 6` 的 progress 是 `1/2`，乘数 `1/2`。`t = 8` 的 progress 是 1，乘数 0。`t = 5` 的 progress 是 `1/4`，`cos(π/4) = sqrt(2)/2`，`0.5 * (1 + sqrt(2)/2) = 1/2 + sqrt(2)/4`。

</details>

### 练习 7：从另一个谷底旁边出发

- 目标：同一种下降可以走向不同的局部最小。
- 限制：纸笔。
- 题面：`L(w) = w⁴/4 - w²/2`，`lr = 0.1`，起点 `w = -1/2`。走一步之后的 `w` 是多少？它更靠近 `-1` 还是 `+1`？
- 完成标准：`w = -0.5375`，靠近 `-1`。并说明 `L(-1) = L(1) = -1/4`。

<details>
<summary>参考解答</summary>

`L'(-1/2) = -1/8 + 1/2 = 3/8`。`w ← -1/2 - 0.1*(3/8) = -0.5375`。两个端点的损失都是 `1/4 - 1/2 = -1/4`。这一步的下降走向负的那一个。

</details>

### 练习 8：检查点里缺了速度

- 目标：优化器状态和参数一起才决定下一步。
- 限制：纸笔，沿用练习 3 的前两步。
- 题面：动量已经走到第二步，`w = 18/25`，`v = 9/5`。若此时把 `v` 丢掉、当成 0，下一步的 `w` 是多少？不断点的第三步 `w` 是多少？
- 完成标准：丢掉速度后 `w = 81/125`。不断点是 `243/500`。

<details>
<summary>参考解答</summary>

`g = 18/25`。`v` 被重置为 0 后再更新，`v = 18/25`，`w = 18/25 - (1/10)*(18/25) = 162/250 = 81/125 = 0.648`。不断点的第三步是 `243/500 = 0.486`。同样的参数，速度不同，落点不同。

</details>
