1. sigmoid 的导数最大是多少？四层都停在这个最大值上，梯度被乘成原来的多少？跑到饱和区又是多少？
2. Xavier 和 ReLU 的 He 初始化，各自把权重的方差设成什么？PyTorch `nn.Linear` 的默认均匀边界是哪一个？
3. 同一个向量，LayerNorm 和 RMSNorm 差在哪一步？

## 一层感知机在做什么

一层线性变换再接一个逐元素函数，就是多层感知机的一块。`W1` 的形状是 `(d_hidden, d_in)`，`W2` 的形状是 `(d_out, d_hidden)`：

```text
h = φ(x @ W1.T + b1)
y = h @ W2.T + b2
```

`φ` 作用在每个坐标上，坐标之间不混合。混合只发生在矩阵乘里。反向传播开篇用标量把 ReLU 的导数乘进链式法则；本篇用一个二维的前向说明「哪一个坐标被关掉」。

`x = (1, -1)`，`b1 = 0`，

```text
W1 = | 1   1 |
     | 1  -1 |

x @ W1.T = (1 - 1, 1 - (-1)) = (0, 2)
```

ReLU 之后是 `(0, 2)`。第一隐藏单元这一步的局部导数是 0，`W1` 的第一行收不到从它传回来的梯度。第二行的预激活是 2，导数是 1，梯度还在。这和开篇「负半轴这一步没有更新」是同一件事。

## 三种饱和，一种截断

记 `σ(z) = 1 / (1 + exp(-z))`。它的导数是

```text
σ'(z) = σ(z) (1 - σ(z))
```

`σ(1 - σ)` 在 `σ = 1/2` 时最大，最大值是 `1/4`，对应 `z = 0`。别处都更小。所以无论权重怎么取，sigmoid 一层最多把上游梯度乘 `1/4`。`L` 层都停在导数最大的这一点，乘积仍是 `(1/4)^L`。

四层：`(1/4)^4 = 1/256 ≈ 0.00390625`。

饱和时更小。`z = 5`：

```text
σ(5) = 1 / (1 + exp(-5)) ≈ 0.993307
σ'(5) = σ(5) (1 - σ(5)) ≈ 0.006648
```

四层都停在 5 上，乘积约为 `1.953 × 10⁻⁹`。损失对最底下那一层权重的梯度，在数值上已经和 0 分不出来。这就是消失：不是某一层的公式写错了，而是很多个小于 1 的因子连乘。

tanh 的导数是 `1 - tanh²(z)`。`z = 0` 时导数是 1，比 sigmoid 好；`z = 2` 时 `tanh(2) ≈ 0.9640`，导数约为 `0.0707`。离开 0 以后，多层连乘一样会消失。tanh 没有取消这个问题，只是把「导数最大的位置」从 `1/4` 抬到了 1。

ReLU 在 `z > 0` 时导数是 1，连乘还是 1；在 `z < 0` 时导数是 0，这一支直接断掉。它把「处处变小」换成了「要么原样通过，要么死掉」。死掉的单元要靠初始化、偏置和学习率，让预激活有机会为正。上面的 `(0, 2)` 就是一半通过、一半死掉。

SiLU，也叫 swish，是 `z * σ(z)`。`z = 0` 时值是 0。`z = 2` 时

```text
σ(2) = 1 / (1 + exp(-2)) ≈ 0.880797
SiLU(2) = 2 * σ(2) ≈ 1.761594
```

它在负半轴不恒为 0，梯度不一定被乘成 0。GELU 用高斯分布的累积函数：`GELU(z) = z * P(Z ≤ z)`，`Z` 是标准正态，也就是 `z * (1 + erf(z / sqrt(2))) / 2`。`z = 0` 时值是 0。`z = 2` 时这个式子约为 `1.954500`。Hendrycks 和 Gimpel 还给出一个用 tanh 的近似，同样在 `z = 2` 约为 `1.954598`。两者从第五位小数才分开；保留四位小数时，一个四舍五入成 `1.9545`，另一个成 `1.9546`。核对实现时要先问用的是 `erf` 还是 tanh 近似。

SwiGLU 的门用的是 SiLU。门控前馈的形状和手算在 [解码器结构](../06-大语言模型/07-解码器结构.md)。本篇只把 SiLU 这个函数算清楚。

## 初始化在保住哪一个矩

线性层 `y = W x`，`W` 的形状是 `(n_out, n_in)`，元素独立、均值是 0，输入坐标独立、均值是 0、二阶矩是 1。一个输出坐标的方差是

```text
Var(y_i) = n_in * Var(w) * 1
```

希望它仍是 1，就得 `Var(w) = 1 / n_in`。这是前向。反向时梯度从 `n_out` 个输出加回来，对称的要求是 `Var(w) = 1 / n_out`。Glorot 和 Bengio 取两边的折中：

```text
Var(w) = 2 / (n_in + n_out)
```

这是 Xavier。它假定中间没有把一半信号截掉的 ReLU。

ReLU 会截断。设预激活 `Z` 的分布关于 0 对称，则 `relu(Z)²` 在负半轴是 0，在正半轴等于 `Z²`，两边的二阶矩一样多，所以

```text
E[relu(Z)²] = (1/2) E[Z²]
```

`E[Z²] = n_in * Var(w)`。要让 ReLU 之后的二阶矩仍是 1：

```text
(1/2) * n_in * Var(w) = 1
Var(w) = 2 / n_in
```

这是 He 初始化在 `fan_in`、ReLU 下的方差。对称性是假设：预激活若整体偏到正半轴，截掉的就不是一半。

均匀分布 `U(-a, a)` 的方差是 `a² / 3`。把方差设成目标值，解出 `a`：

```text
Xavier：a = sqrt( 6 / (n_in + n_out) )
He：    a = sqrt( 6 / n_in )          # ReLU，fan_in
```

`n_in = 4`，`n_out = 2`。

| 方案 | 半宽 `a` | 方差 `a² / 3` |
| --- | --- | --- |
| Xavier | `sqrt(6 / 6) = 1` | `1/3` |
| He，ReLU | `sqrt(6 / 4) = sqrt(3/2) ≈ 1.224745` | `1/2` |

PyTorch 的 `kaiming_uniform_(..., nonlinearity="relu", mode="fan_in")` 用的就是这个 He 边界：`gain = sqrt(2)`，`bound = gain * sqrt(3 / fan_in) = sqrt(6 / fan_in)`。`xavier_uniform_` 用的是 Xavier 边界。

`nn.Linear` 的默认初始化不是其中任何一个。`reset_parameters` 调用 `kaiming_uniform_` 时传入 `a = sqrt(5)`。默认的非线性分支把这个 `a` 当成 leaky ReLU 的负斜率，增益变成 `sqrt(2 / (1 + 5)) = sqrt(1/3)`，边界再乘 `sqrt(3 / fan_in)` 之后正好是

```text
1 / sqrt(fan_in)
```

文档里把同一件事写成 `U(-sqrt(k), sqrt(k))`，`k = 1 / in_features`。`fan_in = 4` 时半宽是 `1/2`，方差是 `(1/2)² / 3 = 1/12`。

把这个默认方差放进第一层。输入关于 0 对称、二阶矩是 1 时：

```text
E[relu(Z)²] = (1/2) * n_in * (1 / (3 n_in)) = 1/6
```

第一层之后，二阶矩变成原来的 `1/6`。若后面每一层仍假设预激活关于 0 对称，从而继续只留下一半二阶矩，三层就是 `(1/6)³ = 1/216 ≈ 0.004630`。这是连乘模型，不是恒等式：ReLU 的输出并不对称，第二层的预激活往往不再满足「正负两半的二阶矩一样多」。它仍然说明默认方差会把信号按层压小。深层 ReLU 网络要显式换成 He，或者换成下面的归一化，不能靠 `nn.Linear` 的默认值。

反向传播开篇的标量网络把权重手写成 `1/2` 和 `-3/2`，那是为了让分数好看，不是初始化方案。

## LayerNorm

LayerNorm 对单个样本自己的特征做，不读取批里的其他样本。特征有 `n` 个，均值和方差都除以 `n`，不是 `n - 1`。`ε ≥ 0` 加在根号里，避免除以 0。可学习的 `γ`、`β` 再做逐坐标的缩放和平移；它们的形状和被归一化的那一维相同。

```text
μ = (1/n) Σ x_i
σ² = (1/n) Σ (x_i - μ)²
y_i = γ_i * (x_i - μ) / sqrt(σ² + ε) + β_i
```

`ε = 0`，`γ = 1`，`β = 0`，`x = (1, 3, 5)`。

```text
μ = 3
σ² = ((-2)² + 0² + 2²) / 3 = 8/3
2 / sqrt(8/3) = 2 * sqrt(3/8) = sqrt(3/2)
```

偏离是 `-2, 0, 2`，所以结果是 `(-sqrt(3/2), 0, sqrt(3/2))`。`sqrt(3/2) ≈ 1.224745`。写出来是

```text
LayerNorm(1, 3, 5) = (-sqrt(3/2), 0, sqrt(3/2)) ≈ (-1.224745, 0, 1.224745)
```

中间那个坐标正好是均值，归一化之后是 0。减均值会把「全体加上同一个常数」消掉：`(1, 3, 5)` 和 `(0, 2, 4)` 的差是常数 1，LayerNorm 的输出相同。

加上 `γ = (1, 1, 2)`，`β = (0, 0, 1)`：

```text
(-sqrt(3/2), 0, 2 * sqrt(3/2) + 1) ≈ (-1.224745, 0, 3.449490)
```

`γ` 和 `β` 是参数。把它们固定成 1 和 0 只是手算时的选择，训练里它们会被更新。PyTorch `LayerNorm` 的默认 `ε` 是 `10⁻⁵`。手算用 0，是为了让 `sqrt(8/3)` 不要再套一层小修正；和默认实现对比数字之前先把 `ε` 对齐。

自注意力笔记里对 `(1, 3)` 算过一次：均值 2，方差 1，结果 `(-1, 1)`。那是同一个定义在两个坐标上的特例。

## RMSNorm

RMSNorm 不减均值。它用均方根做尺度：

```text
RMS(x) = sqrt( ε + (1/n) Σ x_i² )
y_i = γ_i * x_i / RMS(x)
```

通常没有 `β`。`ε = 0`、`γ = 1` 时，仍取 `x = (1, 3, 5)`。

```text
(1² + 3² + 5²) / 3 = 35/3
RMS = sqrt(35/3) ≈ 3.415650
y ≈ (0.292770, 0.878310, 1.463850)
```

和 LayerNorm 的 `(-1.224745, 0, 1.224745)` 不是同一个向量。差来自两处：没有减去 3，尺度用的是 `sqrt(35/3)` 而不是 `sqrt(8/3)`。`(0, 2, 4)` 的 RMS 和 `(1, 3, 5)` 不同，输出也不再相同。LayerNorm 对平移不敏感，RMSNorm 敏感。

PyTorch `RMSNorm` 不传 `ε` 时，用计算浮点类型的机器精度：float32 大约是 `1.19 × 10⁻⁷`，不是 LayerNorm 的 `10⁻⁵`。两个模块的默认 `ε` 不能互相抄。

现代 decoder 里常见的前置归一化，用的就是这一类不依赖批内其他样本的归一化。RMSNorm 比 LayerNorm 少一次减均值。块里把它放在子层前面还是后面，见下一节。

## BatchNorm 读取的是整批

BatchNorm 对一个特征，跨过这一批样本做均值和方差。两个样本 `x¹ = (1, 2)`，`x² = (3, 6)`，`ε = 0`，`γ = 1`，`β = 0`。特征 0 的两个数是 1 和 3：

```text
均值 2，方差 (1 + 1) / 2 = 1
归一化：-1 和 1
```

特征 1 的两个数是 2 和 6：

```text
均值 4，方差 (4 + 4) / 2 = 4，标准差 2
归一化：-1 和 1
```

两个样本变成 `(-1, -1)` 和 `(1, 1)`。

若改成 LayerNorm，每个样本自己归一化。`(1, 2)` 的均值是 `1.5`，方差是 `0.25`，标准差 `0.5`，结果 `(-1, 1)`。`(3, 6) = 3 * (1, 2)`，中心化和尺度都放大 3 倍，结果仍是 `(-1, 1)`。两个样本在 LayerNorm 之后相同，在 BatchNorm 之后一个是 `(-1, -1)`，一个是 `(1, 1)`。统计范围不同，函数就不同。

评估时不能再依赖「刚好和谁分在同一批」。训练中维护每个特征的滑动平均。PyTorch 的更新和优化器里的动量不是同一个系数方向：

```text
running ← (1 - momentum) * running + momentum * 这一批的统计量
```

默认 `momentum = 0.1`，滑动均值从 0 开始。第一批均值 2，第二批均值 6：

```text
第一批之后：0.9 * 0 + 0.1 * 2 = 0.2
第二批之后：0.9 * 0.2 + 0.1 * 6 = 0.78
```

评估用 `0.78`，不是 6，也不是两批放在一起的均值 4。`0.78` 还带着初值 0 的权重。短短两批之后，滑动平均离数据很远；要用它做评估，得先让它在训练里走够。推理时若仍用当前批的方差，批大小变成 1 时方差是 0，输出被 `ε` 撑住，和训练时的函数不再是同一个。

## 残差放在归一化的哪一侧

反向传播开篇已经有标量式子：`y = x + f(x)` 时 `dy/dx = 1 + f'(x)`。`f'` 为 0，梯度仍是 1。归一化插进来以后，这条 1 还在不在，取决于它在加法的里面还是外面。

前置，也就是先归一化再进子层：

```text
y = x + f(Norm(x))
```

对 `x` 求导，第一项是单位阵。`f` 若是常数，第二项是 0，`y` 就等于 `x`。取 `x = (1, 3, 5)`，`f` 恒为 0：前置的输出仍是 `(1, 3, 5)`，长度的平方是 `1 + 9 + 25 = 35`。

后置，先做残差再归一化：

```text
y = Norm(x + f(x))
```

单位阵乘在 `Norm` 的雅可比里面，不再原样留在外面。`f` 仍为 0 时，输出就是 `Norm(x)`。LayerNorm 把 `(1, 3, 5)` 变成 `(-sqrt(3/2), 0, sqrt(3/2))`，长度的平方是 `3/2 + 0 + 3/2 = 3`，原来的 35 没有留下来。每一层后置都会把尺度重新拉回归一化的输出，跳连本身的大小过不了这一层。

自注意力笔记用常数子层 `f = (1/2, -1/2)` 和 `x = (1, 3)` 算过前置 `(1.5, 2.5)`、后置 `(-1, 1)`。那里比较的是两个结构的前向值。本篇补的是：`f' = 0` 时，前置的雅可比里还有 `I`，后置没有单独的 `I`。子层会读取归一化结果时，前置和后置的加法项本身就不同。用 RMSNorm 算的那一组数在 [解码器结构](../06-大语言模型/07-解码器结构.md)。

## 参考代码

`ε = 0`、`γ = 1`、`β = 0`。`layer_norm` 的方差除以 `n`。

```python
import math


def layer_norm(x):
    n = len(x)
    mu = sum(x) / n
    var = sum((v - mu) ** 2 for v in x) / n
    scale = math.sqrt(var)
    return tuple((v - mu) / scale for v in x)


def rms_norm(x):
    n = len(x)
    rms = math.sqrt(sum(v * v for v in x) / n)
    return tuple(v / rms for v in x)
```

## 容易算错的地方

- sigmoid 的导数没有大于 `1/4` 的地方。四层都取到这个上限，乘积仍是 `1/256`。
- `nn.Linear` 的默认半宽是 `1/sqrt(fan_in)`，方差 `1/(3 fan_in)`。它不是 Xavier 的 `2/(n_in+n_out)`，也不是 ReLU 的 `2/n_in`。
- He 的 `2` 来自 ReLU 丢掉一半二阶矩。没有 ReLU 时仍用 `2/n_in`，前向方差会变成 2。
- LayerNorm 除以 `n`，不是样本方差的 `n - 1`。`(1, 3)` 的方差因此是 1，不是 2。
- RMSNorm 不减均值。`(1, 3, 5)` 的结果不是 LayerNorm 那个关于 0 对称的向量。
- LayerNorm 的默认 `ε` 是 `10⁻⁵`。PyTorch `RMSNorm` 不传 `ε` 时用的是浮点机器精度，大约 `10⁻⁷` 这一档。
- BatchNorm 的滑动更新是 `(1 - momentum) * old + momentum * batch`。`momentum = 0.1` 时，新批次只占一成。
- 后置归一化把残差的 `I` 乘进 `Norm` 的雅可比。`f = 0` 并不能让输出等于 `x`。

## 练习

### 练习 1：四层 sigmoid 的乘积

- 目标：上限 `(1/4)^L` 和饱和区分开算。
- 限制：纸笔。导数用 `σ(1 - σ)`，不要背一个近似小数当定义。
- 题面：四层的预激活都是 0，导数的乘积是多少？都是 5 时，`σ(5)` 和 `σ'(5)` 大约是多少，四层乘积在哪一个数量级？
- 完成标准：`1/256`。`σ(5) ≈ 0.993307`，`σ'(5) ≈ 0.006648`，四层乘积约为 `1.953 × 10⁻⁹`。

<details>
<summary>参考解答</summary>

`σ(0) = 1/2`，导数 `1/4`，四次相乘是 `1/256`。`σ(5) = 1/(1+e^{-5})`。四层乘积是这个导数的四次方。脚本 `check_activation_norm` 用未舍入的 `exp` 复核。

</details>

### 练习 2：三个初始化的半宽

- 目标：从方差走到均匀分布的边界，并认出默认值。
- 限制：纸笔。`n_in = 4`，`n_out = 2`。
- 题面：Xavier、ReLU 的 He、`nn.Linear` 默认值，三个半宽各是多少？输入对称时，默认值配上 ReLU，第一层把二阶矩乘上多少？若每一层都继续假设预激活对称，三层之后是多少？这个连乘缺了什么？
- 完成标准：`1`、`sqrt(3/2)`、`1/2`。第一层 `1/6`。对称假设下三层 `1/216`。ReLU 的输出不对称，所以第二层起这个假设不再自动成立。

<details>
<summary>参考解答</summary>

Xavier 的 `6/(4+2) = 1`。He 的 `6/4 = 3/2`。默认边界 `1/sqrt(4) = 1/2`，方差 `1/12`。输入对称时，`(1/2) * 4 * (1/12) = 1/6`。再乘两次是 `1/216`，但那要求每一层的预激活仍然对称。ReLU 之后这个对称性没有了。

</details>

### 练习 3：LayerNorm 与平移

- 目标：减均值会消掉公共常数。
- 限制：纸笔，`ε = 0`，`γ = 1`，`β = 0`。
- 题面：计算 `LayerNorm(1, 3, 5)`。再说明 `LayerNorm(0, 2, 4)` 为什么和它相同。`γ = (1, 1, 2)`、`β = (0, 0, 1)` 时第三个坐标是多少？
- 完成标准：`(-sqrt(3/2), 0, sqrt(3/2))`。第三个坐标是 `1 + 2 sqrt(3/2)`。

<details>
<summary>参考解答</summary>

均值 3，方差 `8/3`，偏离 `-2, 0, 2` 除以 `sqrt(8/3)` 得到 `-sqrt(3/2), 0, sqrt(3/2)`。`(0, 2, 4)` 只比原向量小 1，均值和每个偏离一起移动，比值不变。仿射之后第三坐标是 `2 * sqrt(3/2) + 1`。

</details>

### 练习 4：RMS 不减均值

- 目标：用同一个向量把两种归一化分开。
- 限制：纸笔，`ε = 0`，`γ = 1`。
- 题面：`RMSNorm(1, 3, 5)` 的均方根是多少？三个坐标写成 `x_i / sqrt(35/3)`。它和练习 3 的 LayerNorm 在哪个坐标上符号就不同？
- 完成标准：均方根 `sqrt(35/3) ≈ 3.415650`。第一个坐标 LayerNorm 为负，RMSNorm 为正。

<details>
<summary>参考解答</summary>

平方和 35，除以 3 再开方。`1 / sqrt(35/3) ≈ 0.292770`，接着是约 `0.878310` 和 `1.463850`。LayerNorm 的第一个坐标是 `-sqrt(3/2) < 0`。

</details>

### 练习 5：一批和一层

- 目标：统计范围决定输出。
- 限制：纸笔，`ε = 0`，`γ = 1`，`β = 0`。
- 题面：样本 `(1, 2)` 和 `(3, 6)`。按特征做 BatchNorm，两个样本各变成什么？按样本做 LayerNorm，两个样本各变成什么？
- 完成标准：BatchNorm 是 `(-1, -1)` 和 `(1, 1)`。LayerNorm 都是 `(-1, 1)`。

<details>
<summary>参考解答</summary>

特征 0 的标准差是 1，特征 1 的标准差是 2，于是两个样本的两个坐标都被送到 `±1`，而且同一特征同号。LayerNorm 看到的是每个样本内部的两个数，`(3, 6)` 是 `(1, 2)` 的 3 倍，标准化后重合。

</details>

### 练习 6：滑动均值还记得初值

- 目标：评估用的均值不是最后一批的均值。
- 限制：纸笔。`momentum = 0.1`，初值 0。
- 题面：两批的特征均值依次是 2 和 6。两批之后的滑动均值是多少？它离「两批合在一起的均值 4」有多远？
- 完成标准：`0.78`。与 4 相差 `3.22`。

<details>
<summary>参考解答</summary>

`0.2` 之后是 `0.9 * 0.2 + 0.6 = 0.78`。初值 0 还占着 `0.9² = 0.81` 的权重，所以 0.78 离 4 很远。

</details>

### 练习 7：前置还留着长度

- 目标：`f = 0` 时两种结构的输出不同。
- 限制：纸笔。`Norm` 取练习 3 的 LayerNorm。
- 题面：`x = (1, 3, 5)`，`f` 恒为 0。前置 `x + f(Norm(x))` 和后置 `Norm(x + f(x))` 各是什么？两者长度的平方各是多少？
- 完成标准：前置 `(1, 3, 5)`，平方和 35。后置 `(-sqrt(3/2), 0, sqrt(3/2))`，平方和 3。

<details>
<summary>参考解答</summary>

前置在 `f = 0` 时就是 `x`。后置是 LayerNorm，两个非零坐标的平方各是 `3/2`，和为 3。单位阵在前置里没有被归一化吃掉。

</details>

### 练习 8：SiLU 和 GELU 在 2 处

- 目标：激活的数值能对上定义，而不是只记得名字。
- 限制：可以查 `exp` 和 `erf`，先写出式子。
- 题面：计算 `SiLU(2)`。精确 GELU 在 2 处约是 `1.954500`，tanh 近似约是 `1.954598`。未舍入时从第几位小数开始不同？四舍五入到四位之后呢？
- 完成标准：`SiLU(2) ≈ 1.761594`。未舍入从第五位不同。四位小数分别是 `1.9545` 和 `1.9546`。

<details>
<summary>参考解答</summary>

`2 / (1 + exp(-2)) ≈ 1.761594`。`1.954500` 和 `1.954598` 的前四位小数都是 9、5、4、5，第五位才是 0 和 9。四舍五入到四位时，后者进成 `1.9546`。实现若混用两种 GELU，这一位就会对不上。

</details>

## 本篇之外

dropout 的保留概率、早停用哪一条曲线，以及嵌入表怎样初始，不在本篇。优化器假定本篇的前向已经把尺度放在合理的范围里。注意力块里把 RMSNorm 放在子层前的数，以及 RoPE、SwiGLU、GQA 的公式，见 [解码器结构](../06-大语言模型/07-解码器结构.md)。本篇的导数、边界、两种归一化和滑动均值由 `check_activation_norm` 复核。
